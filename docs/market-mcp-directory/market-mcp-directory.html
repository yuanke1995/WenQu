SCOPE
做什么
  • 市场新增「MCP 服务」页签：浏览 / 搜索 / 详情 / 一键安装
  • 官方目录由管理员新增、编辑、上下架
  • 安装后提示并可跳转 MCP 页查看连接状态
DATA
数据口径
  • item_type = mcp，复用现有市场表，不建新表
  • payload 仅存 { url, type, requiresAuth }
  • 凭据（headers）永不进入市场；item_key = 服务名
API
接口复用
  • 列表 / 详情 / 安装沿用现有市场端点
  • 新增管理员端点：POST /market/mcp、PUT /market/mcp/{id}
  • 安装落 c_ai_user_mcp，启用并后台连接
BOUNDARY
明确不做
  • 不允许普通用户上架 MCP（防内网地址外泄/SSRF 放大）
  • 不做 OAuth、stdio、游客/分享面
  • 目录改动不覆盖已安装用户的服务配置

介绍配置

能做什么

把 GitHub 上的仓库、Issue、Pull Request 与代码检索接入对话。可以让模型直接查某个仓库的最近提交、某个 Issue 的讨论上下文，或跨仓库搜代码。

适合谁

  • 经常在对话里查开源项目实现细节的同学
  • 需要汇总 Issue / PR 进展、写周报的项目成员

安装后

服务会出现在「智能体 → MCP 外部工具」，工具自动注册给模型。首次连接若失败，可在 MCP 页展开失败卡查看原因。

该服务需要认证请求头。目录只下发地址与传输类型，不含任何凭据；安装后请在「MCP 外部工具 → 编辑 → 认证与请求头」补充 Personal Access Token。
安装即复制：目录后续修改不会覆盖你的服务配置。
