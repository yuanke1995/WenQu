# 常见问题 FAQ

## 对话与问答

**Q：回答里没有 [N] 引用角标？**
检索未召回足够相关的块，或命中块被相关分门（重排分 0.6 / 融合分 0.5）拦下。可在问答页展开「检索状态行」看命中情况；持续不准时用检索调试与评估页定位，见《检索原理与调参》。

**Q：换一个智能体要新建会话吗？**
不用。选谁作答从下一问起立即生效，旧会话照常继续。真正决定「这一问查哪些资料」的是模型：它手上没有对应资料、而某位助手的职责范围明显对得上时，会把那一问派给那位助手去查（对方带着自己勾选的知识库查一遍，把结论和引用交回来）。

**Q：重新生成会丢掉上一版回答吗？**
旧答案软删除，可在「按消息组删除/撤销」里恢复；30 天保留期后物理清理。

**Q：怎么让 AI 忘掉我告诉它的事？**
个人设置 → 我的记忆：查看（含来源会话）、编辑、删除，或手动添加。

**Q：@ 文档和 @ 知识库有什么区别？**
@ 文档把该文档内最相关的块前置注入上下文（最强指定）；@ 知识库把检索收窄到该库。

## 知识库与文档

**Q：上传支持哪些格式？解析失败怎么办？**
docx / pdf / xlsx / txt / md / csv 与网页 URL。失败看文档列表的失败原因：文件损坏/加密、超大截断、视觉模型不可用（扫描件 OCR 需要）等，修复后点「重解析」。

**Q：改了知识库的分块参数，为什么存量文档没变化？**
库级解析参数只对其后解析/重解析的文档生效，需对存量文档手动重解析。

**Q：换绑向量模型会怎样？**
触发本库全量重嵌入（与块数成正比），期间向量检索降级关键词路、语义缓存清空。避免业务高峰操作。

**Q：为什么我的知识库别人搜不到？**
未配置共享 = 私有（仅自己可见）；检索可见性 = 库允许 且 文档允许。需要共享在库/文档的「共享范围」里配置。

**Q：《问渠使用手册》这个库为什么不能编辑/删除/上传？**
官方内置库：内容随版本自动同步，全员只读。想让智能体用它，在智能体的知识库范围里勾选即可。

## 智能体与工具

**Q：工具/沙盒开关打开了还是不执行？**
确认两级都开：系统设置「工具调用」总开关 + 对应子开关（沙盒另有 provisioner 与访问令牌配置）。

**Q：工具执行前弹出确认卡是什么机制？**
有副作用的沙盒/MCP 工具可配置「执行前确认」：批准/拒绝/超时按拒绝，防误操作。

**Q：MCP Server 连不上？**
按三层取证：核对配置 → curl 直探端点 initialize（带 `Accept: application/json, text/event-stream`）→ 看服务端日志异常根因（初始化与 tools/list 串行，超时按两请求计）。

## 管理与运维

**Q：登录后一直跳回登录页？**
`AI_JWT_SECRET` 未固定，服务重启后旧令牌全部失效。设固定 ≥32 位串即可（多副本必须一致）。

**Q：启动直接失败？**
先查 `DB_PASSWORD`——必填缺失会 fail-fast；再看数据库与 Redis Stack（向量索引依赖）连通性。

**Q：设置页改的参数什么时侯生效？**
多数保存即生效；解析类参数需重解析/新上传；`vision.timeoutMillis` 需重启。详见《系统配置说明》。

**Q：保存设置时报「这些项系统不认」，结果一个参数都没改，为什么？**
提交里有一项不在可保存的配置项清单里（多半是页面版本比后端旧，或这项已经改名/取消）。这时整笔都不保存，而不是把认得的先写进去再报成功——否则你会看到「已保存」但实际没动。刷新设置页重新改一遍即可；若确认这项该能改，说明系统缺了它的定义，需要补进配置项清单。

**Q：回答下面那行黄色提示（本轮降级说明）刷新后还在吗？**
在。它随这条回答一起留存，回看历史时同样能看到「这一轮没咨询成其他助手 / 没检索到资料 / 回答被截断」这类事实，不会刷新一次就当没发生过。要不要显示这些提示，由系统设置里的「检索调试入口」开关统管；关掉时回答区不显示任何降级提示。

**Q：怎么评估和优化检索质量？**
检索评估页从历史问答生成评估集，多参数组对比 recall@k / MRR；`POST /api/ai/debug/retrieval` 分步调试；数据看板有热门/无命中问题与知识缺口一键补块。
