# 系统配置说明

行为参数统一在「系统设置」页维护（存 `c_ai_config`，保存即生效）。部署连接不放进设置页：数据库/Redis 走 `DB_*`/`REDIS_*`，沙盒连接走 `SANDBOX_*`，外部 OCR 服务走 `OCR_*`，密钥路径等也走环境变量/yml。两类配置的边界见下。

## 配置语义

- 设置项 schema 唯一定义源是 `config-schema.json`（后端据此校验 + 下发前端渲染设置页）
- **敏感项按后缀判定**（`.apiKey` / `.clientSecret` / `.token`）：RSA 加密入库，页面仅回显 `****后4位`，「恢复默认」会跳过敏感项
- 多副本部署时动态配置经 Redis pub/sub 广播即时生效，另有 5 分钟兜底轮询
- 「恢复分组默认」把该组恢复为出厂默认值

## 9 个导航分组（15 个配置面板速览）

| 分组 | 关键内容 |
|------|----------|
| 对话模型 | 回答行为（引用一致性自检）、长期记忆平台总闸、超时与等待（标准 / 长任务 / 无人值守三档一键写齐四个超时，也可逐项微调）、消息图片与附件限制。**模型与网关不在本页**——登记在「智能体 → 模型供应商」 |
| 检索设置（RAG） | 四个页签：**检索**（关键词引擎、融合权重与阈值、重排）、**上下文**（知识块填充与单文档/单库配额）、**文档解析**（分块/结构切分/OCR/父子分块）、**图片描述**（视觉开关、提示词、并发、缓存）；模型按知识库绑定 |
| 工具调用 | 问渠工具总开关；沙盒 API 与工作流节点、沙盒脚本、联网搜索等部署/安全相关开关；知识检索、产物交付、内置工具、智能体咨询、任务清单随总开关启用，由智能体三态设置或平台停用名单限定；大输出留存与 MCP 引用注册为固定行为。三个页签：**总开关与子工具**（底部是只读的工具名册，按族分组）、**联网搜索**、**技能**（停用清单从当前可用技能里多选；底部是只读的技能名册，按来源分组并标出停用状态） |
| API 密钥 | 对外问答密钥的签发 / 编辑（名称与有效期）/ 吊销 / MCP 授权 |
| 接口限流 | 限流总开关（打开后按用户、无身份按 IP 限频，超限返回 429）；每分钟次数不在本页配置 |
| 定时任务 | 索引对账、自动体检、会话/图片/产物清理、解析队列并发与重试、网页刷新、工作流治理 |
| 沙盒 | 工作区共用目录、命令超时、空闲回收；连接地址/令牌/回调地址/虚拟根走环境变量 |
| MCP 服务（双向） | 服务端开关、超时、允许来源（空=仅本机回环） |
| 调试设置 | 检索调试入口（同时管回答区的归属徽标 / 路由提示 / 降级提示显隐）、框架引擎的推理步数上限与状态存储 |

> 单点登录（OIDC 多认证源）不在系统设置里：改为平台级「单点登录」管理页（管理员），可配多个 IdP 并逐项配置（issuer/clientId/clientSecret/scopes/重定向/前端基址 等，clientSecret RSA 加密仅回显后 4 位）；成员管理页可按账号解绑单点登录。

> 深度思考不设全局面板：思考强度、窗口档位在对话页按模型选择（见《对话与问答》）。

## 个人设置的内容

有两处：**默认聊天模型**在「个人设置 → 默认模型」；**自动提炼记忆**的开关在「个人设置 → 我的记忆」——与沉淀下来的记忆内容同面板，只关自动提炼、不关提起。

这两处修改后立即生效，面板没有单独的保存按钮。默认聊天模型仅在会话未选定模型时生效（如新会话的第一问）；会话选定模型后（手动选择，或每轮结束时记录该轮实际生效的模型），后续轮次沿用会话的模型，修改个人默认不影响已有会话。

**平台侧的固定口径**：相关建议固定 3 条；新会话空态不展示示例问题卡；没挑助手时由工作区或平台的默认智能体作答；技能只有管理员能停（对全平台停）；工具执行上限只有系统设置里的**平台上限**，个人没有自己那份。

**模型类没有个人默认槽位**：向量 / 视觉模型归知识库绑定（向量空间与库索引一一对应），重排归知识库/智能体检索设置绑定，问答对生成与 GraphRAG 抽取跟随「库主」的个人默认聊天模型（GraphRAG 优先用库级绑定的抽取模型）。「平台内置向量化模型」是管理员在系统设置登记的全平台键（用平台自己的 Key），作为全体用户记忆语义能力的兜底，不是个人项。聊天默认模型在个人设置上方面板。

## 生效时机（易踩坑）

- **需重解析/新上传才生效**：`chunk.maxSize`、结构感知切分、标题层级等解析参数——它们只影响之后的解析，存量文档需手动重解析
- **需重启**：`vision.timeoutMillis`（视觉客户端启动时构建）
- **其余保存即生效**：检索、重排、上下文、工具、限流、记忆等绝大多数项
- **停用或删除供应商/模型不会自动改动选过它的地方**：知识库的向量 / 图谱 / 重排 / 解析模型、文档的图片理解模型、定时任务与工作流节点里选的模型、个人默认模型、系统配置槽位、公开分享链接的游客模型、历史会话记住的模型，都可能还指着它
- **停用后去哪改**：停用成功的当场列出还在用它的位置，逐条点「去修改」直接打开能改它的那个框（知识库配置弹窗、任务/工作流编辑器、公开发布弹窗、系统设置对应参数），并把要改的那一项亮一下；关掉弹窗后卡片上仍留着「停用后仍有 N 处在用它的模型 · 查看引用」，随时回得来。对话页与个人设置会把不能用的那一项在原地标红并写出原因，问答时自动改用可用的那个并留一条说明；清单里的「历史会话」支持一次清除这些会话的选择
- 切换**向量模型**必然触发全量重嵌入（与知识块数成正比，万级块可达数十分钟），期间向量检索降级关键词路，避免业务高峰操作
