# 系统配置说明

行为参数统一在「系统设置」页维护（存 `c_ai_config`，保存即生效）。部署连接不放进设置页：数据库与 Redis 走 `DB_*` / `REDIS_*`，沙盒连接走 `SANDBOX_*`，外部 OCR 服务走 `OCR_*`，框架工作区与密钥路径走环境变量或 yml。两类配置的边界见下。

## 配置语义

- 设置项 schema 的唯一来源是 `config-schema.json`：后端据此校验并下发前端渲染设置页，**schema 缺失即启动失败**。提交项中存在 schema 未定义的键时整笔拒绝保存，而不是先写入可识别的项再报成功
- **179 项参数**分布在 15 个配置面板、左侧 **10 个导航项**（`联网搜索`、`技能` 并入「工具调用」页签，`上下文`、`文档解析`、`图片描述` 并入「检索设置」页签，导航不单列）
- 另有约 33 项**内部键**只在代码默认值中登记、不进设置页（如断线重连开关、每分钟限流次数、沙盒 provisioner 连接与输出上限、OCR 服务地址等），避免把运维细节摊给使用者
- 每项标注层级：**必需（8 项）/ 调优（66 项）/ 工程排障（105 项）**；设置页默认折叠低层项，悬停参数旁的 `?` 可查看该参数的作用说明
- **敏感项按后缀判定**（`.apiKey` / `.clientSecret` / `.token`）：RSA 加密入库，页面仅回显 `****后4位`，「恢复分组默认」会跳过敏感项
- 多副本部署时动态配置经 Redis pub/sub 广播即时生效，另有 5 分钟兜底轮询补齐订阅断线期间错过的变更
- 改动后由页头「保存配置（N 项改动）」一次性提交；「恢复本组默认」把该组恢复为出厂默认值（定时任务、API 密钥、调试设置三组不提供整组恢复）

## 配置的四种归属

| 归属 | 内容 |
|------|------|
| 平台全局 | 设置页里除个人专属项以外的全部参数 |
| 个人覆盖 | 「个人设置」中的**默认聊天模型**与**自动提炼记忆**开关（不占设置页）；`/api/ai/user/settings` 是 schema 标记 personal 字段的覆盖通道，当前没有此类字段 |
| 个人专属 | **默认重排模型**（`rerank.model`：设置页里唯一没有全局槽位的一项，只对登记人可见可用）；个人 MCP 服务、个人供应商、个人技能、工作流凭据按登记人归属 |
| 资源级绑定 | 知识库的向量 / 视觉 / OCR / 重排 / 图谱抽取模型与解析、检索参数；文档的图片理解模型与共享范围；智能体的人设、资料范围、能力开关、权限档位、工具确认模式、步数上限、目标模式开关；会话的模型与上下文窗口档位 |

## 10 个导航项一览

| 导航项 | 关键内容 |
|------|----------|
| **对话模型**（12 项） | 回答行为（引用一致性自检）、记忆与上下文（长期记忆平台总闸、提炼节流、记忆上限 tokens）、超时与等待（**耐心档位**：标准 / 长任务 / 无人值守 三档一键写齐回答超时、审批等待、提问等待、计划批准等待四个值，也可逐项微调）、消息图片与附件限制。**模型与网关不在本页**——登记在「智能体 → 模型供应商」 |
| **检索设置（RAG）**（4 页签） | **检索与重排**（关键词引擎与连接、融合权重、两道阈值、重排开关与窗口）、**上下文**（知识块填充上限与单文档 / 单库配额）、**文档解析**（上传上限、分块与结构感知、问答对、父子分块、PDF 引擎与 OCR、图片处理）、**图片描述**（视觉开关、提示词、并发、调用参数、描述缓存）；模型按知识库绑定 |
| **工具调用**（3 页签） | **总开关与子工具**（问渠工具总开关、知识检索命中数、沙盒与沙盒脚本及其额度、权限档位默认值与平台上限、平台停用工具名单、执行预算与助手咨询、输出留存与引用；页底是按族分组的只读工具名册）、**联网搜索**（服务商与连接、行为与配额、安全）、**技能**（平台停用清单从当前可用技能中多选、允许远程安装的域名；页底是按来源分组并标出停用状态的技能名册） |
| **API 密钥** | 对外问答密钥的签发 / 编辑（名称与有效期）/ 吊销 / 共享范围 / MCP 授权，「如何使用」示例与接入地址，以及 **MCP 调用审计**（入站与出站） |
| **接口限流**（1 项） | 限流总开关（打开后按用户限频、无身份按 IP，超限返回 429）；每分钟次数为内部键，不在本页 |
| **定时任务**（56 项，3 页签） | **参数配置**按 14 节展开：启动自愈与索引对账、自动体检与线上采样、聊天图片清理、会话参数与清理、文档名缓存、产物清理、定时执行智能体、网页源定时刷新、GraphRAG、文档解析队列、任务执行日志、工作流运行治理、站内通知（含**推送到浏览器**那两条）、智能体配置版本。**运行状态**是调度中心的实时快照（每个任务的间隔、上次执行与结果，可就地调 41 项、可暂停与立即触发）。**执行日志**分页列出有信息量的执行 |
| **沙盒**（5 项） | 工作区共用目录总闸、工作区上传上限、命令超时、空闲回收、轮次租约期限；连接地址 / 令牌 / 回调地址 / 虚拟根走环境变量 |
| **MCP 服务（双向）**（3 项） | 对外提供端点开关、等待超时（默认 180 秒，最小 30 秒）、允许的 Origin（空 = 仅本机回环） |
| **调试设置**（10 项） | 检索调试入口（同时管回答区的归属徽标、路由提示与降级提示显隐）、框架引擎推理步数上限、框架工作区目录与 Redis 前缀、会话事件日志归档与换代。引用一致性自检建议生产保持开启 |
| **目标模式**（20 项，3 节） | **推进与轮次**（自动推进轮数上限 40、下一轮间隔、完成检查次数上限、连续核验失败上限）、**预算与恢复**（Token 预算 200 万、时长预算 2 小时、工具调用预算 400 次、瞬时错误重试、崩溃恢复次数、退避基数与上限、软预算阈值 0.8；四项硬预算**填 0 = 该项不限制**）、**调度与核验**（批量认领、worker 数、调度节拍、执行租约、心跳失效阈值、待恢复宽限、文件证据是否查宿主存在性） |

> 统一认证源不在系统设置里：在「权限管理 → 认证源」页签维护（管理员），四类——OIDC / SAML（登录认证）、SCIM / LDAP（账号供给与目录同步），每源独立启停；`clientSecret`、`bindPassword`、`spPrivateKey`、SCIM Bearer 等敏感字段 RSA 加密入库、回显只给掩码。成员管理页可按账号逐源解绑身份。详见《团队与权限》的「认证方式」。

> 深度思考不设全局面板：思考强度与上下文窗口档位在对话页按模型选择（见《对话与问答》）。历史压缩由框架按模型窗口自动触发，没有开关。

## 个人设置的内容

分五组：**个人资料**（头像上传与 emoji 图标、昵称）、**默认模型**（聊天模型，选完即存、无保存按钮）、**我的记忆**（自动提炼开关、`MEMORY.md` 查看编辑与清空、按天查看与删除日账、按上限裁剪、全部清除）、**分享管理**（本人生效中的会话分享，含访问次数、预览、换链接、停止与清除记录）、**账号安全**（修改密码，改成功后需重新登录）。

默认聊天模型仅在会话未选定模型时生效（如新会话的第一问）；会话选定模型后（手动选择，或每轮结束时记录该轮实际生效的模型），后续轮次沿用会话的模型，修改个人默认不影响已有会话。

**平台侧的固定口径**：相关建议固定 3 条；新会话空态不展示示例问题卡；没挑助手时由工作区或平台的默认智能体作答；技能的平台停用只有管理员能执行（对全平台停）；工具执行上限只有系统设置里的**平台上限**，个人没有自己那份。

**模型类没有个人默认槽位**：向量 / 视觉 / OCR 模型归知识库绑定（向量空间与库索引一一对应），重排归知识库或平台默认，问答对生成与 GraphRAG 抽取跟随「库主」的个人默认聊天模型（GraphRAG 优先用库级绑定的抽取模型），记忆提炼复用本轮会话模型。「平台内置向量化模型」是管理员登记的全平台键（使用平台自己的 Key），作为全体用户记忆语义能力的兜底，不是个人项。

## 生效时机（需留意的例外）

- **需重解析或新上传才生效**：分块大小、重叠、结构感知切分、标题层级、问答对与父子分块等解析参数——它们只影响之后的解析，存量文档需手动重解析
- **需重启**：`vision.timeoutMillis`（视觉客户端启动时构建）、工作流并发上限与排队容量、目标模式调度 worker 数
- **其余保存即生效**：检索、重排、上下文、工具、限流、记忆、通知等绝大多数项
- **停用或删除供应商 / 模型不会自动改动选过它的地方**：知识库的向量 / 图谱 / 重排 / 解析模型、文档的图片理解模型、定时任务与工作流节点里选的模型、个人默认模型、系统配置槽位、公开分享链接的游客模型、历史会话记住的模型，都可能还指着它
- **停用后去哪改**：停用成功时当场列出还在使用它的位置，逐条点「去修改」直接打开能改它的那个框（知识库配置弹窗、任务 / 工作流编辑器、公开发布弹窗、系统设置对应参数），并把要改的那一项高亮；关掉弹窗后供应商卡片上仍留着「停用后仍有 N 处在用它的模型 · 查看引用」，随时回得来，清单里的「历史会话」支持一次清除这些会话的选择。对话页与个人设置会把不能用的那一项在原地标红并写出原因，问答时自动改用可用的那个并留一条说明
- **切换向量模型**必然触发该库全量重嵌入（与知识块数成正比，万级块可达数十分钟），期间向量检索降级关键词路；重嵌入只在知识库编辑里换绑模型时按库触发，没有平台级重嵌入口，建议避开业务高峰
