# 智能体

「智能体」页包含六个 Tab：**模型供应商 · 智能体 · 技能 Skills · MCP 外部工具 · 工作流 · 定时任务**。Tab 清单与顺序由菜单数据驱动，可逐项授权；其中技能与 MCP 由每个人各自管理。

> 问渠工具总开关（`tool.enabled`）默认开启；沙盒与沙盒脚本（`tool.sandbox.enabled` / `tool.runcode.enabled`）默认关闭，需管理员在系统设置「工具调用」显式开启。

## 配置一个智能体

配置分四节，右侧常驻「生效摘要」列出该助手与全局不同的地方，可逐项恢复跟随。

- **运行方式**：问答助手 / 子智能体 / 工作流 三选一。选择工作流后，回答由工作流产出，人设、资料与工具由该工作流配置决定；作为子智能体时可选择被委派后的执行方式（见下文）
- **身份与角色**：图标（默认标、问渠品牌标或 emoji）、名称、描述、System Prompt。人设与回答风格写在这里；引用、图片、追问等平台规则由系统固定注入。智能体**不绑定模型**——回答使用哪个模型由对话页选择或「个人设置 → 默认模型」决定
- **资料范围**：全部知识库 / 指定知识库（可再用检索标签收窄）/ 不使用。指定知识库内含官方内置的《问渠使用手册》，勾选后即可回答问渠的使用问题。**该项定义的是「被委派查询」时的资料范围**：对话页直接提问的那一轮会在你有权访问的全部库中检索；把某一问委派给该助手时，只在它勾选的库内检索
- **能力开关**（七项）：知识库检索、内置高频工具、产物交付、技能 Skills、MCP 外部工具、联网搜索、目标模式。除目标模式只有开 / 关外，其余每项都可留「跟随全局」，只把该助手需要例外的项改为开启 / 关闭 / 指定；选定技能或 MCP 后下方展开可选清单，技能行可直接「查看正文」
- **高级设置**（默认折叠）：**权限档位**（决定可改动范围）、**工具执行确认**（有副作用的调用先请求确认；留空 = 跟随档位）、**单轮工具步数上限**（留空 = 跟随系统设置，0 = 不限制）、**检索重排覆盖**、**工具黑名单**、**子智能体委派关系**（可把该助手转成工作流）
- **配置历史**：每次保存生成版本快照，抽屉内按字段列出「旧 → 新」差异，可回滚到任一版本；回滚产生新版本，不改写历史

列表按运行方式分组（问答助手 / 子智能体 / 工作流），卡片标出「默认」「内置」「已发布」与共享范围；动作包括配置、共享、发布、设为默认（管理员）与删除。无管理权的助手显示「仅可使用」。

## 这一问由谁回答

对话页不需要先选择助手：未选择时使用默认助手（工作区里则用该工作区的默认助手），选择后从下一问起生效，**更换助手不需要新建会话**。

跨主题的问题由模型自行分工——当前助手没有对应资料、而某位助手的职责范围明显匹配时，会把该问**委派给该助手查询**：对方在自己的知识库范围内执行一条完整子轮，返回结论与可点开的引用，回答仍由当前助手汇总。每轮最多委派几位、单次委派超时多久，在「系统设置 → 工具调用 → 执行预算与助手咨询」中调整；免登录分享页与被委派的助手本身不再向外委派。

返回的资料需再按**本轮问题**的相关度阈值与引用配额过滤，才进入引用面板——子轮的相关度判定针对子轮问题，不适用于父轮面板，两侧各按自己的问题打分，才能避免出现「子轮判定相关、父轮却全是无关知识块」。未通过过滤的条数会以「另有 N 处未通过校验」如实告知模型，模型不会在正文中引用它们。

该次委派也保留在本轮回答的执行过程中：点开「委派助手执行」卡片，可见**委派给它的问题**、**对方的完整回答**（长回答先折叠一段，可展开看全文）与**它所依据的资料**。资料编号与右侧引用面板是同一套编号，可点开原文；刷新、换设备后同样在。未成功的那一次也保留一行原因（超时或报错），不会缺少卡片。

## 多智能体并行编排

- 主智能体可把复杂问题**并行委派**给多个子智能体，各按自己的知识库范围与角色视角处理，再汇总作答
- **被委派时的执行方式**（在子智能体配置的「运行方式」下选择，不选就按系统默认执行，选框上会标出当前默认档位）：
  - **检索要点**：只检索资料并返回要点，更快、开销更小；该子智能体自己的工具、技能与沙盒均不参与
  - **全循环**：按一次完整问答执行——用自己的知识库检索、用自己的工具与沙盒处理，可生成文件并交付。代价是每委派一次等于执行一轮问答，因此按角色逐个开启
  - 编排卡片会标出哪一支是全循环、执行了几步工具、交付了什么
- 全循环分支**执行中即可查看当前动作**：卡片标题行末尾实时显示正在执行的第几步（哪个工具、用什么参数）。撞上限后仍被派发的调用同样计入步数。这串实时步骤不随消息保存，刷新后保留的是总步数与该分支返回的全文
- 被委派的分支不会向用户提问，也不会创建任务清单：缺少信息时按资料中最合理的方案完成，并把假设写入结论。其交付的产物与引用的资料都归入当前这轮对话，同样可点开查看来源
- 每轮委派了几位、还有几位在执行、最长一支执行了多久，见**对话页顶栏的子智能体状态条**：点开是「这一轮派出去的助手」清单，一支一行（委派对象、问题内容、当前步数、各自耗时），点击其中一行定位到回答里对应的卡片。单支完成后该行替换为其结果，未完成的同样保留一行原因，不会从清单中消失
- 需要看单次委派的用量：「使用统计」页的**这些用量花在什么地方**按用途分项记账——对话问答、子智能体分支、检索词改写、历史压缩、引用自检等各有自己的额度，其中「子智能体分支」就是被委派执行的那些轮

## 公开发布

智能体卡片可公开发布，生成 `/s/{token}` 免登录链接与 iframe 嵌入代码（宽高可调）。发布弹窗可分别控制：

- **游客能力**：是否允许选择对话模型、是否开放该智能体的 MCP 端点
- **游客输入**：是否允许发图、是否允许上传文档附件

游客侧工具收窄为知识检索与内置项，不泄露内部工具与私人数据，也不携带发布者的个人记忆；停用或撤销立即失效。

## 定时执行

智能体可按 cron（5 段：分 时 日 月 周 + 时区）或固定间隔自动执行，结果落进该任务的专属会话并留执行记录；可立即执行一次。调度中心先推进 `next_run_at` 再执行（单实例防重复），同一任务串行防重叠；每人可建的任务数有上限。

## 工具执行确认

沙盒与 MCP 类有副作用工具可按智能体配置「执行前确认」（人在回路：批准 / 拒绝，超时按拒绝）或「禁用」（不向模型暴露这两类工具）。留空 = 跟随权限档位：只读调研逐项确认、常规不强制、全自主直接执行。联网搜索默认自动执行；管理员在系统设置开启其「纳入执行审批」后，同样受「执行前确认」约束（「禁用」不影响联网搜索的启停）。审批卡随流式对话弹出，批准后继续执行。

## 智能体提问

问题不明确时，智能体会先出一张提问卡，作答后才继续。卡上的题目有两种作答方式：

- **未标记的（多数）**：单选。点一条候选即选中，再点另一条即替换；也可以在最后一行自行填写，填完按 Enter 确认该题
- **标了「可多选」的**：可同时勾选多项。点一下勾选、再点一下取消，最后一行自填的内容可与勾选项并存。这类题目勾完需**点「提交」**——系统无法判断勾选何时完成，不会自动送出

整卡均为单选时，全部答完自动提交；卡内只要有一题可多选，就一直等待手动提交。未作答的题目一律不自动选择。默认等待 10 分钟（系统设置「对话模型 → 超时与等待」的「提问等待」可调，也可用「耐心档位」一次写齐）。这期间关闭页面、换设备都不影响该轮：重新进入该会话，卡片仍在原处、各题的勾选状态照原样保留，可继续作答；不在会话页时铃铛也会提示「智能体提问待答」。

超时或点「忽略」都**不会自动选择答案**——智能体只知道「该题未作答」，然后基于已有信息继续，或把候选写进正文再问一次。需要指定推进方向时，直接作答，或选择候选中的「（推荐）」项。

卡片上还有一枚「停止本轮」，与「忽略」是两件事：忽略表示该题不回答、本轮继续执行；停止表示终止本轮。停止后该卡定格为「未作答」，已产出的正文与过程按「已停止本轮」保留，该会话随即可继续提问——不会因为存在未作答的卡片而阻塞下一问。
