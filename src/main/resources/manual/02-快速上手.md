# 快速上手

从零到第一次带引用的回答，大约五分钟。

## 1. 登录

访问部署地址（默认 `http://localhost:5800/chat`），首次使用按引导创建管理员账号；接入 OIDC 后可单点登录。

## 2. 绑定问答模型（管理员）

模型不走本地部署，在「系统设置 → 智能问答模型」登记 OpenAI 兼容网关即可：

1. 填网关地址与 API Key（Key 经 RSA 加密入库，页面只回显掩码）
2. 按类型登记模型：问答 / 视觉 / 向量（重排可选）
3. 在各绑定入口选择模型引用

> 模型配置**无全局兜底**：聊天模型缺失或引用无效时会显式报错引导选择，不会静默回落。个人级供应商只有登记人自己可见可用。

## 3. 建知识库、传文档

1. 进入「知识库」→ 新建知识库 → 选择向量模型（必填；每人另有一个系统预置的默认库「问渠」）
2. 上传文档（docx / pdf / xlsx / txt / md / csv），或粘贴网页 URL 导入
3. 上传只登记解析任务，后台解析队列按并发逐个执行：解析 → 分块 → 向量化 → 关键词索引；进度在文档列表实时可见

## 4. 提问

回到「对话」直接提问。回答句末的 `[N]` 角标即引用溯源：点开可看来源知识块全文与原文图片；回答下方的检索状态行可展开查看全部命中来源。

## 5. 进阶

- 「智能体」页配置人设 / 知识库范围 / 工具集，把通用助手变成专属助手
- 工具与沙盒默认关闭，在系统设置显式开启后，智能体可执行 shell、读写文件、交付产物
- 定时任务让智能体按 cron 自动执行；工作流用画布编排复杂流程

|------|------|----------|
