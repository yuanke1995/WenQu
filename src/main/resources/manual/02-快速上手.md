# 快速上手

按下面五步操作，约五分钟内可得到第一条带引用的回答。

## 1. 登录

访问部署地址（默认 `http://localhost:5800/chat`），首次使用按引导创建管理员账号。接入统一认证源后，可在登录页选择对应的认证源直接登录（认证源由管理员在「权限管理 → 认证源」维护，支持 OIDC / SAML，可配置多个）。

## 2. 绑定模型（管理员）

模型不需要本地部署，在「智能体 → 模型供应商」登记 OpenAI 兼容网关即可：

1. 填网关地址与 API Key（Key 经 RSA 加密入库，页面只回显掩码），必要时调整补全与向量路径
2. 按类型登记模型：**聊天 / 视觉 / 向量 / 重排 / OCR / 语音 / 全模态 / 其他**。对话类模型需声明上下文窗口与最大输出（可登记「最小~最大」区间供使用者下调档位）；如实登记输入与输出单价，费用统计才有数值可算。全模态模型按对话模型同等可用
3. 到「个人设置 → 默认模型」选定个人默认聊天模型；对话页可随时切换，切换结果记在该会话上
4. 在各绑定入口选择模型引用：知识库编辑里绑定向量（必选）、重排、视觉、OCR 与图谱抽取模型；平台默认重排模型与评估评判模型在系统设置登记

> 模型缺失或引用无效时会明确提示并引导到可修改的位置，不会静默改用其它模型。个人供应商只有登记人自己可见可用。

## 3. 建知识库、传文档

1. 进入「知识库」→ 新建知识库 → 选择向量模型（必填；系统已为每人预置默认库「问渠」）
2. 上传文档（docx / pdf / xlsx / ppt / pptx / txt / md / csv），或粘贴网页 URL 导入
3. 上传只登记解析任务，后台解析队列按并发逐个执行：解析 → 分块 → 入库 → 向量化 → 关键词索引；进度、失败原因与队列状态（排队 / 执行）在文档列表实时可见

## 4. 提问

回到「对话」直接提问。回答句末的 `[N]` 角标即引用溯源：点开可看来源知识块全文与原文图片；回答下方的检索状态行可展开查看全部命中来源。

## 5. 进阶

- **智能体**：配置人设、知识范围与能力开关，把通用助手变成专属助手；跨主题的问题会由模型委派给职责对口的助手查询
- **工作区**：把同一件事的对话、文件与产物集中管理，并共享一份约定（见「工作区」）
- **长任务**：需要先确认方案时用 `/plan`；需要助手自己往下推进、做完即停时用 `/目标`
- **沙盒与代码执行**：默认关闭。知识检索与内置工具默认可用，但让助手执行命令、读写沙盒文件、交付产物这类高风险能力需在系统设置显式开启，并受权限档位约束
- **技能与 MCP**：在「智能体 → 技能 / MCP 外部工具」装配能力；同事上架的技能、应用模板与工作流可在「市场」一键安装
- **自动化**：定时任务让智能体按 cron 自动执行；工作流用画布编排复杂流程

| 登录 | /chat | 进入对话页 |
| 绑聊天模型 | 智能体 → 模型供应商 · 个人设置 → 默认模型 | 对话能正常回答 |
| 绑向量模型 | 新建知识库弹窗 | 知识库卡片显示模型名 |
| 传文档 | 知识库 → 文档管理 | 文档状态「已入库」 |
| 验证溯源 | 对话提问 | 回答句末出现 `[N]` 角标 |
| 侧栏引导退场 | 侧栏底部「配置引导」 | 必配项全部完成后该入口自动消失 |
