# 工作流

可视化工作流把「检索、生成、分支、调用、审核」编排成可重复运行的流程。DSL（JSON）是唯一真源：画布只是编辑器，引擎只认 DSL；结构校验 fail-loud。

## 11 类节点

| 节点 | 说明 |
|------|------|
| 开始 / 结束 | 入参定义与出参收集；结束节点 `answer` 可作为 chatflow 的回答 |
| LLM | 调用问答模型（模型引用过判权），token 流式透传 |
| 知识库检索 | 按库界检索知识块 |
| 条件分支 | SpEL 安全求值（禁 `T()` 与构造器） |
| HTTP 请求 | SSRF 逐跳内网校验、2MB 读取上限 |
| 代码执行 | Python/Node 走 Docker 沙盒，非 0 退出码 fail-loud |
| 子智能体 | 复用完整问答管线，临时会话跑完即删 |
| 人工审核 | 流程挂起 → 审批卡裁决 → 按快照续跑，已完成节点短路回放零重复消耗 |
| 循环 | maxLoops 编译期/运行期双闸 |
| 模板转换 | 变量拼装 |

变量引用统一写法 `{{nodeId.key}}`。

## 画布编辑器

节点面板拖拽添加、右键快捷菜单、连线校验（禁自环、禁非法回跳、条件出边选分支）、属性抽屉按类型渲染表单。

**画布内调试**：填入参 → 同步运行 → 逐节点 trace 回放染色（成功/失败/待审核 + 耗时）→ 点节点看输入输出与 token。运行历史可整体回放任一次 run；**每次运行锁定当时 DSL 快照**，改画布不影响已跑的 run。

## 发布与版本

- 草稿可继续改，**发布**冻结成一版；回滚 = 以历史 DSL 再发一版
- 运行读已发布快照，fail-loud：未发布/已下线的工作流不执行

## 对外触发

- **API 触发**：`POST /api/ai/v1/workflows/{id}/run`，持 API Key（`X-Api-Key` 头）触发**已发布**版本；含人工审核节点的工作流一律拒绝 API 触发。按 runId 可查运行结果
- **chatflow 绑定**：智能体绑定已发布工作流后，对话由工作流驱动，结束节点 `answer` 出参即回答，LLM 节点流式透传

## 运行历史

运行列表 + 节点级 trace 回放；待审批的运行可在历史页就地裁决。
