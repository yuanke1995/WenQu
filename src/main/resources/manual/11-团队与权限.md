# 团队与权限

## RBAC 两级管控

- **角色-菜单**：控制侧边栏入口（对话/智能体/知识库/我的产物/成员管理/数据看板/检索评估/权限管理/系统设置）
- **角色-API**：端点白名单，后端 fail-closed（普通用户仅开放问答链路，管理端点 403）
- 内置角色：`superadmin`（全部权限，含最后一名保护）/ `admin`（管理端全量）/ `user`（问答与个人资源）；管理员判定 = admin/superadmin 或角色 admin_flag
- 新增内置菜单默认对普通角色不可见，需在「权限管理」为角色勾选

## 资源可见性

所有资源（知识库/文档/智能体/工作流/API Key）的数据按 userId 隔离：

- **创建者** → 可管理（创建者短路，不套角色上限）
- **他人** → 仅按资源显式配置的共享范围可见；普通用户对别人的知识库**封顶只读**
- **share_config 未配置 = 私有**；已配置按声明的 scope（全局 / 指定部门 / 指定用户），管理范围不得宽于阅读范围
- **管理员级不再有全量短路**：与普通用户同口径，只有创建者与显式共享范围内可见可管
- **检索可见性两级判定**：文档可见 = 所属库允许 且 文档自身允许（未配置=跟随库）
- **个人默认库「问渠」**：各成员的私有库，仅本人可见可用（不可删除）
- **官方内置库**：《问渠使用手册》 createdBy=system，共享范围为全员只读——所有人可检索可读，无人可改

## 认证方式

- **本地账号**：PBKDF2 密码哈希 + 失败锁定
- **OIDC 单点登录**：标准授权码；自动建档，`oidc_sub` 唯一索引防账号漂移；分离部署必填 `frontendBaseUrl`
- 登录令牌为 JWT（`AI_JWT_SECRET` 签名；留空则每次启动随机生成，重启后已发令牌全部失效）

## 审计与防护

- 管理操作打 `[AUDIT]` 审计日志（上传/删除/导入等）
- 问答/上传按用户（无身份按 IP）Redis 固定窗口限频，Redis 不可用自动放行
- 上传魔数校验、产物文件名白名单净化、图片 HMAC 签名 URL
- 模型 API Key RSA 加密入库 + 掩码回显；RSA 密钥文件不入库、不打进构建产物
