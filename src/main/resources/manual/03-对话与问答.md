# 对话与问答

对话页是日常使用的主入口，支持流式回答、引用溯源、深度思考与多模态输入。

## 流式回答

回答经 SSE 逐段下发，可随时点「停止生成」——**中止同样留痕**：已产出的正文、已执行的工具与用量都会落库，不会因为中止丢失一轮。回答进行中可以继续输入：新发的内容先排在输入框上方，点该条上的「立即发送」即作为**插话**送进正在跑的这一轮，在下一次调用模型前生效，不需要等本轮答完再重问；按 `Ctrl` / `⌘` + `Enter` 发送时，该句入队后立即执行「立即发送」。该句显示在本轮实际插入的位置，即若干步骤之间。未赶上本轮的内容在本轮结束时自动补发一次。中断、超时、刷新页面或换设备之后，本轮的过程、计划与待裁决的卡片均可原样恢复。

## 引用溯源

- 回答句末的 `[N]` 角标 → 弹窗展示来源知识块全文（图文交错）+ 关联截图
- 回答下方有**检索状态行**，可展开查看全部命中来源与摘要，条目点击进同一溯源弹窗
- 外部来源（联网搜索 / MCP 工具返回的网页）与知识库来源**共用同一套编号**：引用面板显示站点名、标题、摘要与外链，相关度优先按重排分展示
- 命中的文档图片经相关性校验后按编号位置级插入回答，点击可看原图
- 引用一致性自检（默认开）：生成后校验每条 [N] 引用是否被引用内容支撑，剔除语义不符的引用并重编编号

回答没有引用角标时，通常是检索未召回足够相关的知识块（相关性阈值会过滤弱相关内容），可参考《检索原理与调参》。

## 回答里的代码块

每段代码标题栏的右上角有若干动作，按语言自动出现：**复制**（每种代码块都有）；**预览**（HTML / SVG，在弹层内查看渲染效果，弹层按整页尺寸提供，因此布局与响应式表现可见，右上角还可「新窗口打开」）；**在云端沙盒中运行**（Python / Node / Shell，在隔离沙盒中执行，不影响本机环境，输出回填在该段代码下方）。

两类代码块在回答生成后直接渲染成图，不需要点按钮：

- **统计图**（语言标 `echarts`）：代码块内容是一份 ECharts option（JSON 格式），在回答中原位渲染为交互图表——折线图、柱状图、饼图、散点图均支持，可悬浮查看数值、可点图例开关系列，配色跟随界面的亮暗主题；图下方可展开查看原始 option。
- **示意图**（语言标 `mermaid`）：流程图、时序图、甘特图等，原位渲染成矢量图，同样可展开看源码。

option 不是合法 JSON 或缺 `series` 字段时，该位置显示失败原因与源码，不留空白画布。

预览仅在回答正文提供。知识块原文、技能正文中的 HTML 只提供复制——这类代码来自上传的内容，不随查看者的点击执行。

## 回答交付的产物

助手输出清单、表格、网页或代码后，该条回答末尾按生成顺序列出这些产物，每条有两个动作：**预览** 和 **下载**。

**预览**以整屏打开，按文件类型采用不同视图：

- **网页**（`.html` / `.htm`）按真实渲染展示，顶栏可切换**视口宽度**：自适应 / 375 / 768 / 1440，也可自行填写数值。选 375 时页面按手机宽度重新排版，与真机布局一致；旁边的**缩放**（适合宽度 / 50% / 75% / 100%）只缩小画面以放进屏幕，不改变页面自身的排版宽度。
- **Markdown、文本与代码**（`.md`、`.txt`、`.json`、`.py`、`.java`、`.css` 等）就地排版：Markdown 按标题、表格、代码块渲染，代码带高亮和复制按钮。
- **分隔符表**（`.csv`、`.tsv`）显示为只读表格，行数写在表格下方；首行按表头显示，超过 300 行只列前 300 行。
- **图片**铺满整屏，点击在「适合屏幕」与 1:1 之间切换，用于查看字号与锯齿；**PDF** 使用内置阅读器。
- 顶栏固定提供「新标签」，用于在新标签页查看完整页面。按住 Ctrl（Mac 为 ⌘）点击「预览」，或用鼠标中键点击，同样在新标签页打开。

**Excel（`.xlsx` / `.xls`）和压缩包（`.zip`）只提供下载**：这类内容无法在页面内还原排版，因此不提供「预览」入口。

两个上限：单份产物最大 1MB；文本类预览只读取前 256KB，超出时该屏写明后半部分内容未取回，完整内容请下载查看。

一个已知限制：**同批交付的几份文件互相引用时（例如网页里写 `./style.css`、`./logo.png`）无法预览整体效果**。产物逐份独立存储，文件名前各带一串随机字符，网页按相对路径找不到这些文件。需要单份可直接查看的网页，让助手把样式和图片内联进同一份 HTML。

同一批产物还有两个汇总位置：PC 右侧状态栏的「产物」卡，手机上的「状态与来源」面板，两处的预览与下载和回答中一致。需要长期保留、改名或变更归属时，使用侧栏的「我的产物」。

「我的产物」只列**助手主动交付**的产物。在沙盒中生成、但未交付的文件不出现在这里——这类文件在右侧状态栏的「沙盒文件」卡中，可逐个打开、下载，或存为产物（存为后与这里的条目等同）。见 `09 技能与沙盒`。

一轮回答被**推理步数上限**或**单轮工具步数上限**截断时，回答下方会出现一行说明（刷新后仍在）：本轮的执行预算按步计，到达上限即停止，不会把全部步骤执行完。出现该说明后，发送「继续」即可接着执行；已生成的文件不会丢失，在「沙盒文件」卡中查看。两道闸都在系统设置里：前者是「调试设置 → 框架引擎推理步数上限」（限模型调用几轮），后者是「工具调用 → 工具步数上限」（限工具调用几次，智能体可各自覆盖）；两处填 **0 = 不限制**。长任务被截断优先调大前者，再调后者。

## 引用资料（`@` 或「+」面板的「引用」页）

四类内容可以在提问时指定给助手，**只对当轮生效**，下一轮自动清空：

- **知识库** —— 本轮检索限定在所选库内；
- **文档** —— 该文档的相关内容直接带入本轮上下文，适用于「按这份文档回答」；
- **智能体** —— 本轮强制向该助手咨询一次（由对方带自己的知识库检索），回答仍由当前助手汇总；
- **技能** —— 所选技能的正文逐字带入本轮，即要求按该流程执行。

两个入口是同一块面板：在输入框打 `@` 后继续输入即筛选，`Enter` 选中；或点输入框左下的 `+` 进入「引用资料」页选择。四类各占一个页签，页签上标着可选数量，搜索框对当前页签生效。键盘：`↑↓` 选择、`Enter` 确认、`Tab` 退回上一级、`Esc` 关闭。

选中内容以标签形式排在输入文本中间，点标签上的 × 可移除；一轮最多引用 10 个知识库/文档/智能体，智能体每轮限一个（再选即替换），技能单独计最多 3 个。

## 深度思考

开启后思维链**按轮就地展示**：模型每推理一次，回答流程中增加一行「深度思考」，点开查看该段内容——先推理再调工具、推理后继续生成的，各段位置独立，不会集中在回答顶部。是否开启由对话页决定，系统不自行判断哪一轮需要思考；登记为「恒思考」的模型即使关闭仍会先推理一次，该段同样出现在对应位置。

悬浮模型行弹出的设置面板可按模型调整**思考强度**与**上下文窗口档位**：模型登记了「最小窗口~窗口」区间时，窗口档位可在区间内选择（默认取上限）。档位**跟着这条对话走**——刷新、换设备、隔天再打开都还是这一档，改动从下一句提问起生效。窗口决定检索资料的填充量（预算 = 窗口 × 安全系数 − 最大输出），也决定长对话什么时候开始折上下文：窗口越大，越早的轮次还能逐字留着。

## 上下文压缩（长对话）

对话里的内容接近窗口容量时，早期轮次被折叠为一份**早期对话摘要**继续随上下文携带，近期问答逐字保留，避免超出模型上下文后丢失早期信息。折叠时机由模型窗口推导（见上一节），没有开关；一次长任务里可以折叠多次。折叠发生时回答区会画一条「已压缩上下文」，点开看的就是当前生效的那份摘要。

- **界面标识**：对话流中出现一条居中的 **「已压缩上下文」** 分隔线，标出本次压缩发生在对话的哪个位置。该分隔线**保留在会话中**，刷新页面、换设备后仍在原处
- **压缩过程有进度提示**：轮内自动压缩时，本轮顶部状态行显示 **「正在压缩上下文」**（该阶段约二十余秒持续有输出，不会静默），完成后该回答上方留下「已压缩上下文」分隔线；手动 `/compact` 不在任何轮内执行，完成后分隔线直接出现在对话流末尾
- **查看摘要内容**：点分隔线旁的「查看摘要」，弹窗显示摘要全文与规模（tokens 数、逐字保留的最近问答轮数），可一键复制
- **原文保留**：压缩只改变送入模型的内容，问答原文仍完整保留在会话中，向上滚动可回看
- **手动压缩**：在输入框打 `/compact` 回车（移动端在「模型与思考」面板点**压缩上下文**）。不依赖阈值触发，完成后显示**为后续腾出约多少 tokens**
- **指定摘要要求**：打 `/compact 只保留结论和数字，忽略寒暄`，或在摘要弹窗点**带要求重新压缩**填写一句——该句直接作为本次摘要的要求
- **最近内容不参与压缩**：最近 2 轮问答始终逐字保留。会话过长时一次压缩无法全部完成，会提示"可再次执行 /compact 继续"
- **容量占用**：上下文容量明细按 AgentScope 的消息结构分类——系统提示词、历史对话、本轮提问、检索资料、工具结果、思考内容、工具声明，可据此判断窗口被检索资料还是被工具输出占用（PC 悬浮输入框右下的容量圆环，移动端在「状态与来源」里查看）。压缩后的历史归入「历史对话」一段，不单列摘要

## 过程独白与消息时间线

工具模式下模型的推理/试错独白与正文分流，前端灰字原位展示；整轮「文本段 + 工具段 + 产物段」编为消息时间线随消息落库——刷新页面后仍是交错的实时过程视图。

- **配图随回答保留**：回答中插在某个步骤上的文档截图，刷新页面、换设备、打开分享链接后仍在原位，无需重新提问才有图

- **每轮只报一个总耗时**：执行中回答末尾显示一行「正在溯源，用时 12 秒 …」，秒数递增表示仍在执行；本轮完成后该行替换为本轮总览并回到回答最上方——「已完成，用时 6 分 26 秒」。该数值为从发出提问到完成的实际墙钟时间（回答提问卡、批准计划卡的等待时间也计入，悬停提示单独给出其中的等待时长）。该行右侧有折叠三角时，表示本轮执行过工具，点开逐步列出执行了哪几步、每步查询了什么。耗时只在这一行显示，工具卡与「执行了 N 个操作」行不带时长。
- **完成后思考与操作折叠为一条总览**：整条回答只剩最上方那一行，展开后回到上述交错的实时过程视图，正文不受展开/收起影响。刷新页面、换设备后形态一致，总耗时同样保留。
- **无耗时记录时不显示数字**：早期会话未记录该值，该行只显示「已完成」，不会显示为「0 秒」——"未记录"与"执行了 0 毫秒"是两件事。

## 下一步建议

最新一轮回答的末尾会给出「接下来可以」若干条可点击的追问方向，点击即按该方向发问，不需要重新输入。这一排**只跟在最新一轮之后**：历史轮次的建议内容已被后续提问覆盖，再展示可点击的问句会遮挡正文，且容易误点重发。因此向上翻阅历史时只看到问答本身，继续提问在最后一轮操作。


## 计划模式（先出计划，再执行）

适用于「先确认执行方案，再决定是否执行」的场景。桌面在输入框打 `/plan`（或 `/计划`）回车开启（也可以点「+」→ 快捷命令 → **计划**），手机点「+」→ 本轮模式 → **计划模式**开关；也可以 `/计划 任务` 直接发送任务并先出计划。开启后输入框出现「计划」标记（桌面位于输入框正文内，手机位于输入框上方），删除该标记即关闭（再打一次 `/plan` 同样关闭）。

该开关只对**下一轮**生效：发送后标记随附件、引用一并清除，之后各轮按普通问答执行；需要再次先出计划要重新开启（同一份计划的反复修改不需要重开，用计划卡的「继续对话」）。开关状态保存在本机浏览器，桌面与手机同源共享。

**计划与目标一轮只能用一个**：每一轮提问要么走计划模式（先出计划卡），要么走目标模式（设定目标后自动续跑）。开启一边时，另一边已挂载的标记会自动清除；挂着「目标」标记时发送的那一轮不会带上计划，反之亦然。

- 该轮先产出**执行计划**卡（生成中 → 待确认），此时输入框换成计划确认栏：
  - **1. 确认**：按这份计划开始执行；
  - **2. 继续对话**：填写修改意见（Enter 直接发送，Shift+Enter 换行）——意见作为一条正式用户消息在同一会话中继续，本版计划作废（卡片标「已被取代」），模型按意见生成下一版，可反复修改；
  - **取消**：本轮停止，卡片定格「未批准」。
- 挂起的计划有倒计时（默认 10 分钟），超时按未批准收尾、本轮停止
- 未开启计划模式时，模型也可以自行判断是否先出计划（框架的 `plan_enter` 工具）；是否进入完全由模型决定
- 计划卡随消息落库：刷新页面、换设备后仍在原处，可继续裁决；右栏「计划」卡列出本会话每轮生成的计划，点击定位到那一轮；卡内「修改记录」可回看各版计划与修改意见
- 计划描述的是**交付物**：形态是什么、包含哪些部分、关键选择是什么、以什么方式呈现。指代交付物时只出现其名称（如「单个网页文件 index.html」），不出现沙盒或服务器上的文件路径，也不出现工具名与命令——这些属于内部实现，与判断计划是否符合预期无关

## 目标模式（长任务自动续跑，完成即停）

适用于一轮问答无法完成、需要助手自行推进的长任务。目标模式**只维护三件事**：目标内容、当前轮次、停止条件。不含验收标准、逐条确认或人工检查环节。

入口是 `/目标`（桌面在输入框打 `/目标` 或从 `/` 面板选「目标」；手机点「+」→ 本轮模式 → **定为目标**）。也可以直接 `/目标 做一个问渠官网`。**输入目标后回车即开始**，不弹表单、不追问。

- **目标与计划的分工**：计划描述执行方案，目标描述要达成的结果与当前轮次。两个模式**互斥**，一轮只用一个：定目标时已挂载的「计划」标记会自动清除（开启计划开关时定目标同理），不会同时生效
- **自动续跑**：每轮结束后助手继续下一轮，不需要点「继续」，也不中途请求确认
- **完成即停**：助手判定任务完成时，会在回答最后一行写「【目标完成】」，目标随即转为「已完成」并停止续跑；未写该行表示尚未完成，系统自动开下一轮
- **受阻即停**：遇到权限、资料缺失等无法自行解决的阻塞时，助手写「【目标受阻】原因」，目标转为「已暂停」并把原因显示在目标条上，可以改目标、继续或删除
- **四项硬预算兜底**：轮数（默认 40）、工具调用（默认 400 次）、token（默认 200 万）、机器时长（默认 2 小时）任一项用满即停，目标条写明是哪一项用满、已执行多少轮，进度与已生成内容全部保留，可点「继续」接着跑。四项都在**系统设置 → 目标**里改，**填 0 = 该项不限制**；正常结束路径仍是助手自报完成
- 可执行的操作只有三个：**改目标**（点编辑键就地修改该句，从下一轮起生效）、**停止/继续**（停止后进度全部保留，可随时继续）、**删除**（目标从界面移除，已生成的内容与产物全部保留）
- 进行中的目标常驻在**输入框内的一行**：左侧是「目标」标记与目标原文，右侧是停止/继续、编辑、删除三个图标键。已执行轮数与停止原因：桌面悬停在目标原文上查看，手机显示在该行下方第二行小字里
- 目标**完成或删除后该行移除**——不再需要处理任何事。结果保留在右栏「目标」面板（手机在「状态与来源」里）
- 定目标时会在**对话里留下一条记录**（气泡上方有一枚 `/goal` 标记，正文即当时的目标原文）：这条「当初交付了什么」长期可见。它是一条指令，不占用问题的复制 / 编辑重发入口
- 在会话里插话时目标让位（优先处理该句），这句答完后目标自动接上，不需要手动点继续
- 刷新页面、换设备后上述各处都仍在——目标存储在服务端，不依赖页面保持打开

目标模式**没有平台级开关**，也没有验收标准、逐条确认、候选提议这类环节。管理员可调的只有上面那四项硬预算，外加一项「预算用到几成开始在提示里要求收敛」的软阈值，都在**系统设置 → 目标**。关闭入口只有一处：**智能体设置中该助手自己的「目标模式」开关**——关闭后界面入口与目标面板同时不出现，引擎也不再向助手注入目标上下文。

## 多模态输入

图片和文件都能直接**粘贴**进输入框（`Ctrl` / `Cmd` + `V`），也可以拖进来，或点「+」→ 上传文件选：

- **图片**（一轮最多 5 张）：经视觉模型理解后参与回答；鼠标悬停在图片上可查看大图
- **文件**（一轮最多 5 个、单个不超过 15MB）：PDF / Word / Excel / PPT 与文本、代码类文件，读出正文后作为该问的材料
- 粘贴较长文本时不占用输入框：自动收为一张「粘贴的文本」附件，点击查看全文
- 附件、图片、技能、@ 引用、# 历史引用都排在输入文本中间，位置随文字一起移动；按 `Backspace` 或点其上的 × 即移除该条
- **整体复制**：在输入框全选后复制，粘贴到外部得到纯正文；粘回问渠输入框会连同附件一起还原，无需重传
- 附件上显示上传进度和失败原因；未完成时点发送会被拦截并说明原因，不会静默漏带
- 编辑重发时附件默认随该问再次携带。上传的文件按保留期（默认 24 小时）清理，过期或当初未留存原件的标为「已过保留期」/「不可重发」，重发时重新上传即可

## 智能体绑定规则

- 会话**不锁定**智能体：未选择时使用默认助手，选择后从下一问起生效，更换不需要新建会话；问题涉及其他领域时，模型会把该问派给职责对口的助手查询（见「智能体」篇）
- 绑定的智能体不可用时 fail-loud 明确提示，不静默换人

## 会话管理

置顶 / 收藏 / 重命名 / 搜索（标题与内容全文匹配）/ 批量删除 / 清空；会话可导出 Markdown；对回答可**重新生成**（软删旧答案，可撤销）、赞/踩反馈；支持按消息组删除与撤销删除。逻辑删除超过保留期（默认 30 天）的会话与消息会被物理清理，保留期即「撤销删除」窗口。

导出的 Markdown 是一份自包含文件，发给他人同样能看到图与图表：正文中的图片转成内嵌数据；`echarts` 统计图按当前主题的配色绘制成图片原位放入正文，原始配置收在文末「图表源码」一节（该文件放回问渠打开时，配置会重新渲染成图）；`mermaid` 示意图保留源码围栏，主流阅读器可自行渲染。无法渲染的图（option 不合法）保留原围栏，数据不丢失。

## 模型选择与「这个模型不能用了」

输入框上方的模型胶囊决定该问使用哪个模型：在某个会话中选择过一次，即记录在该会话上（刷新、换设备后仍在）；未选择时使用「个人设置 → 默认模型」。

如果该模型后来被停用或已从模型列表移除，界面不会等到提问失败才提示：

- 胶囊直接变红并写出原因（例如「deepseek-v4-pro 所在的供应商已停用」）。打开列表时该项排在最前、标灰、不可点击，下方照常列出可切换的模型
- 照常发问可以正常回答：该问自动改用你的默认模型，并在回答上方留一条「已清除这个会话的选择，本轮改用某某回答」的说明；需要其他模型时在胶囊里重新选择一次
- 未设置默认模型时不自动猜测：停止该轮并说明在哪里选择、在哪里设置
- 个人设置里的默认模型本身被停用时，同样在原地标红说明，修改后立即生效
- 重新生成、失败自动重试都沿用该问原本使用的模型，不会改动会话上记录的选择

这一轮为什么没答出来（模型不可用、额度不足、被限流、上一轮还在跑、服务内部异常）会留在对话里，不会刷新一次就当没发生过：回答说到一半被打断，原因跟在回答末尾；什么都没产出，原因写在那一句提问下面。隔天回来仍然看得见，在那一句上改一改重发即可。

## 用户长期记忆

问答完成后异步提炼可长期保留的用户信息（事实与偏好、工作背景、明确要求记住的内容），写入用户自己的记忆文件，并在后续问答中引用——跨会话连续，同一工作区内的会话共用同一份记忆。不需要自动提炼时，可在「个人设置 → 我的记忆」关闭「自动提炼记忆」：关闭只停止后续提炼，已记录的内容仍会被引用；要清除已记录的内容，直接在对话中让助手修改或删除。系统设置里还有一道平台总闸，两处都开启才会提炼。公开分享页与对外 API 链路不携带个人记忆。
