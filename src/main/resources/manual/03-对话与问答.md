# 对话与问答

对话页是日常使用的主入口，支持流式回答、引用溯源、深度思考与多模态输入。

## 流式回答

回答经 SSE 逐段下发，可随时点「停止生成」——**跑到一半停也留痕**：已产出的正文、已跑过的工具与用量都会落库，不会因为中止而丢一轮。回答进行中还能直接续话：输入框发出去的内容先排在输入框上方，点那条上的「立即发送」就把它作为**插话**送进正在跑的这一轮（下一步生效，不用等它答完再重问一遍）；这句会长在回答里它真被听到的那个位置，夹在中间那几步之间。没赶上这一轮的会在这轮结束时自动接着发一次，不会说了等于没说。中断、超时、刷新页面或换设备之后，本轮的过程、计划与待裁决的卡片都能原样接回。

## 引用溯源

- 回答句末的 `[N]` 角标 → 弹窗展示来源知识块全文（图文交错）+ 关联截图
- 回答下方有**检索状态行**，可展开查看全部命中来源与摘要，条目点击进同一溯源弹窗
- 外部来源（联网搜索 / MCP 工具返回的网页）与知识库来源**共用同一套编号**：引用面板显示站点名、标题、摘要与外链，相关度优先按重排分展示
- 命中的文档图片经相关性校验后按编号位置级插入回答，点击可看原图
- 引用一致性自检（默认开）：生成后校验每条 [N] 引用是否被引用内容支撑，剔除语义不符的引用并重编编号

没有看到引用角标？通常是检索未召回足够相关的块（相关分门会拦掉弱相关内容），可参考《检索原理与调参》。

## 回答里的代码块

每段代码标题栏的右上角有若干动作，按语言自动出现：**复制**（每种代码块都有）；**预览**（HTML / SVG，在弹层里看渲染效果，弹层按整页尺寸给，所以布局与响应式看得出，右上角还能「新窗口打开」）；**在云端沙盒中运行**（Python / Node / Shell，跑在隔离沙盒里、不动你本机，输出回填在这段代码下方）。

预览只出现在回答正文。知识块原文、技能正文里贴的 HTML 只能复制——那份代码是随文档上传进来的内容，不该由看的人点一下就跑起来。

## 回答交付的产物

助手把整理好的清单、表格、网页或代码交出来时，这条回答的末尾按生成顺序列出这些产物，每条都有两个动作：**预览**（在浏览器新标签页打开）和**下载**。网页会真的渲染出来（跑在隔离环境里，碰不到你的登录状态）；Markdown、文本与代码按原样显示；图片与 PDF 用浏览器自带的查看器。表格（`.csv`、`.xlsx`）和压缩包浏览器开不了，这类只给**下载**。

同一批产物还有两个汇总位置：PC 右侧状态栏的「产物」卡，手机上的「状态与来源」面板，两处的预览与下载和回答里完全一样。想长期留着、改名或换归属，去侧栏的「我的产物」。

## 引用资料（`@` 或「+」面板的「引用」页）

四类内容可以在提问时点名给助手，**只对当轮生效**，下一轮自动清空：

- **知识库** —— 本轮检索只在你选定的这些库里找；
- **文档** —— 这篇文档的相关内容直接带进本轮上下文，适合「就按这份文档回答」；
- **智能体** —— 本轮强制向这位助手咨询一遍（它带着自己的知识库查），回答仍由当前助手汇总；
- **技能** —— 把选中的那几条技能的正文逐字带进这一轮，等于明确交代「照这个做法做」。

两个入口是同一块面板：在输入框打 `@` 直接接着打字筛选，`Enter` 选中；或点输入框左下的 `+` 进「引用资料」页用鼠标挑。四类各占一个页签，页签上标着可选数量，搜索框对当前页签生效。键盘：`↑↓` 选、`Enter` 确认、`Tab` 退回上一级、`Esc` 关闭。

选中的内容以标签排在你要问的那句话中间，点标签上的 × 可移除；一轮最多引用 10 个知识库/文档/智能体，智能体一轮只认一位（再选一个即替换），技能单独算最多 3 个。

## 深度思考

开启后思维链**按轮就地展示**：模型每想一次，回答流程里就多出一行「深度思考」，点开看那一段在想什么——先想再调工具、想完再接着写的，各归各的位置，不会全部堆在回答顶上。开与不开由你在对话页定，系统不会替你判断哪一轮该想；登记为「恒思考」的模型即使关掉也仍会先想一步，那一段照样出现在原处。

悬浮模型行弹出的设置面板可按模型调整**思考强度**与**上下文窗口档位**：模型登记了「最小窗口~窗口」区间时，窗口档位可在区间内点选（默认用上限），选择按模型记忆、下一轮发送即生效——窗口决定检索资料能塞多少（预算 = 窗口 × 安全系数 − 最大输出），也为后续长对话的上下文压缩提供容量基准。

## 上下文压缩（长对话越聊越长时）

对话长到一定程度，早期轮次会被折成一份**早期对话摘要**继续带着走，近期问答逐字保留——这样长对话不会因为超出模型上下文而"忘了前面说过什么"。默认开启，管理员可在系统设置关闭（关闭后只按预算带近期历史，更早的不带）。

- **界面上怎么认**：对话流里出现一条居中的 **「已压缩上下文」** 分隔线，线以上的早期对话已折进摘要，线以下逐字在场。这条线**留在会话里**，刷新页面、换设备后仍在原处
- **压的时候看得到进度**：手动压一次，对话流末尾先出现一条 **「正在压缩上下文」**，压完原地变成上面那条「已压缩上下文」（同一个位置，只换文案）
- **看摘要写了什么**：点分隔线旁的「查看摘要」，弹窗显示这份摘要全文与规模（多少 tokens、逐字保留最近几次问答），可一键复制
- **原文不会丢**：压缩只改变"带给模型看的内容"，问答原文仍完整留在会话里，往上翻可回看
- **想立刻压一次**：在输入框打 `/compact` 回车（移动端在「模型与思考」面板点**压缩上下文**）。不必等阈值触发，压完会告诉你**为后续腾出约多少 tokens**
- **要求摘要保留什么**：打 `/compact 只保留结论和数字，忽略寒暄`，或在摘要弹窗点**带要求重新压缩**写一句——这句话会直接进这次摘要的要求里
- **压不掉刚说的话**：最近 2 次问答始终逐字保留。会话特别长时一次压不完，会提示"可再次执行 /compact 继续"
- **占了多少额度**：上下文容量明细按 AgentScope 的消息结构分类——系统提示词、历史对话、本轮提问、检索资料、工具结果、思考内容、工具声明，一眼看出窗口是被资料吃掉还是被工具输出吃掉（PC 悬浮输入框右下的容量圆环，移动端在「状态与来源」里看）。压缩后的历史归入「历史对话」一段，不单列摘要

## 过程独白与消息时间线

工具模式下模型的推理/试错独白与正文分流，前端灰字原位展示；整轮「文本段 + 工具段 + 产物段」编为消息时间线随消息落库——刷新页面后仍是交错的实时过程视图。

- **配图跟着这条回答走**：回答里插在某个步骤上的文档截图，刷新页面、换设备、打开分享链接后仍在原位，不用重问一遍才有图

- **一轮只报一个总耗时**：还在跑的时候，回答末尾跟着出现一行「正在溯源，用时 12 秒 …」，秒在走就说明它没卡住；答完这一行换成这一轮的总览、回到回答最上面——「已完成，用时 6 分 26 秒」。这个数说的是从你发出提问到答完实际过去了多久（你回答提问卡、批准计划卡的那段时间也算在内，悬停里会单独告诉你其中等了多久）。这一轮动没动手看那一行右边有没有折叠三角，点开才逐步列出跑了哪几步、每步查了什么。整轮只有那一行报耗时，工具卡与「执行了 N 个操作」那一行不挂时长。
- **答完自动把思考与操作收成那一条总览**：整条回答只剩最上面那一行，点开才回到上面那种交错的实时过程视图，正文不受开合影响。刷新页面、换设备后仍是这个形状，那个总耗时也还在。
- **没有计时就不写数字**：早先的会话没记下这个数，那一条只说「已完成」，不会显示成「0 秒」——「没记下来」和「跑了 0 毫秒」是两件事。

## 下一步建议

最新一轮回答的末尾会给出「接下来可以」几个可点的追问方向，点一下就照它发问，不用重新打字。这一排**只跟在最新一轮后面**：往上翻历史时，早几轮的建议说的已经是你后来问过、聊过去的事，再摆一排可点的问句只会挡阅读、还容易误点重发。所以翻回前面看到的是干净的问答本身，接着往下问就在最后一轮那里点。


## 计划模式（先出计划，再执行）

适合「先看清它打算怎么做、再决定跑不跑」的场景。桌面在输入框打 `/plan`（或 `/计划`）回车开启（也可以点「+」→ 快捷命令 → 开启计划模式），手机点「+」→ 本轮模式 → **计划模式**那颗开关；也可以 `/计划 任务` 一步把任务发出去、直接出计划。开启后就多出一颗「计划」小标记（桌面长在输入框正文里，手机压在输入框上方），删掉它即关闭（再打一次 `/plan` 也是关闭）。开关状态记在本机浏览器，桌面与手机同源共享。

- 开启后，每一轮先产出**执行计划**卡（生成中 → 待确认），此时输入框换成计划确认栏：
  - **1. 确认**：按这份计划开始执行；
  - **2. 继续对话**：写下要改什么（Enter 直接送出，Shift+Enter 换行）——意见作为一条正式用户消息在同一会话里继续，本版计划作废（卡片标「已被取代」），模型带着意见重出下一版，可反复修改直到满意；
  - **取消**：本轮停止，卡片定格「未批准」。
- 挂起的计划有倒计时（默认 10 分钟），超时按未批准收尾、本轮停止
- 没开计划模式时，模型也可以自行判断是否先出计划（框架的 `plan_enter` 工具）；是否进入完全由模型决定
- 计划卡随消息落库：刷新页面、换设备后仍在原处，可继续裁决；右栏「计划」卡列出本会话每轮出过的计划，点击定位到那一轮；卡内「修改记录」可回看各版计划与你的意见
- 计划讲的是**你会拿到什么**：交付物是什么形态、包含哪些部分、关键选择是什么、会怎么让你看到它。指代交付物时只说它的名称（如「单个网页文件 index.html」），不会出现沙盒或服务器上的文件路径，也不会出现工具名与命令——那些是内部做法，不影响你判断这份计划是不是你要的东西

## 目标模式（把一件事交出去，直到有凭据）

适合「这件事要做到什么算完」的长任务：目标不是一轮问答能答完的，需要助手自己往下推，而且**完成与否不能由它自己说**。

入口是 `/目标`（桌面在输入框打 `/目标` 或从 `/` 面板选「目标」；手机点「+」→ 本轮模式 → **定为目标**，输入框里已经写着这句就直接建目标开跑，还空着则先出起草面板）。它和计划模式同一种用法：**先进入目标模式，正文前出现一颗「目标」chip（点 × 退出），写下目标后回车就开始**；也可以直接 `/目标 把竞品分析报告改到可以直接发给客户` 一步到位。**回车就开跑**，不再弹表单让你先填一遍标准。目标开始后 chip 收起，状态与验收标准在输入框上方那条和右栏「目标」面板里。

- **目标和计划不是一回事**：计划讲「打算怎么做」，目标讲「这件事什么算完、跑到第几轮了」。两者可以并存——目标已定之后，助手仍会在需要你拍板具体做法时出计划卡
- **标准可以由助手先起草**：没写标准也能开跑；助手第一轮会先提出 1–3 条「什么算完成」，提出即自动采纳，条上标着「助手起草」——你随时可以在目标卡或编辑区改、删、加。标准不是你逐条点过的，但也不是平台背着你加的：你发起这个目标，就是授权它先起草
- 开跑后助手会**跨轮自己往下推进**（不用你每轮点「继续」）：它带着「当前目标 + 还没通过验证的标准」继续做下一轮，每一轮的回答像平常一样长在对话里。**中途不会因为「还剩人工核验」停下来叫你**——人工的标准等做完了再一起交给你，途中不打断
- **完成是判定出来的，不是宣布的**：每条已确认标准都要有当前有效的验证凭据才算通过（命令退出码、产物结构、或你人工勾选）。没有凭据的条目一律算「未验」，助手说「做完了」也不算
- 助手自报做完了（或这一目标连续跑了 8 轮还在推进），目标会停在**等你检查**：这时候交付物已经齐了——先看右栏「产物」卡里的东西，再在目标卡上逐条点「达成 / 没过」。勾完自动完成；标了「没过」的条目，助手会带着你的意见接着改，改完再停下来等你检查
- 如果首轮助手没有提出（或你删光了）验收标准，目标会停在「等你核验」并提示补一条——没有可验的东西，再转下去只会没完没了地跑
- 产物被改过之后，旧的验证结论会标成**已过期**并需要重验——这是有意为之：结论是对着某个版本做的，版本变了它就不再成立
- **目标不设边界**：没有轮数、token、工具调用、机器时长任何一档上限，也没有「预算用满」那一档状态。它一直推到每条验收标准都拿到验证凭据为止；中途只有你按暂停、点就此收尾、这一轮出错（转暂停，点继续再来），或连续 8 轮还没收口（安全帽，停下来先让你检查）才会停
- 不再往前推的时候**不悄然截断**：面板与摘要条上会点名「还差哪几条没验过」，你自己决定接着推还是就此作罢
- 目标全程可**暂停 / 继续 / 编辑 / 清除**；你在会话里插话时目标会让位（先听你的），插完话可继续
- **随时能改**：点条子上的编辑键，同一条就地长开编辑区，逐条改验收标准（加一条、去掉一条、改字句；手机在底部面板里改，同一套字段同一个保存）。目标原文不在这里改——要换口径就另起一条目标（编辑区里给了那句入口），这条会按「未完成收尾」结掉，已经跑出来的内容和验证记录都还在
- 进行中的目标常驻在**输入框正上方那一条**，只说三件事：现在什么状态（进行中的目标 / 等你检查的目标 / 等你核验的目标 / 已暂停的目标 / 受阻的目标）、目标是什么、一把拉住它（右侧图标键：核验、暂停或继续、编辑、清除）。
  「跑到第几轮、卡在哪、有没有同步异常」不铺在这一条上：桌面把鼠标停在那句目标原文上就能读到，手机直接压在条子下面第二行小字里
- 目标**达成或被你清除之后这一条就撤下**——它不再需要你处理任何事。结果与证据留在右栏「目标」面板（手机在「状态与来源」里），到那时面板会自动展开：每条标准的验证结果、还差哪几条、卡住的原因、过程跳转
- 定目标那一刻会在**对话里留下一句**（气泡上方有一枚 `/goal` 标记，那句就是当时的目标原文）：目标的状态随推进会变，这句「当初把什么交出去」一直读得到。它是一条指令，不占问题的复制 / 编辑重发入口
- 刷新页面、换设备后上述各处都仍在——目标存在服务端，不依赖你那一页还开着

目标模式没有平台级开关，也**没有任何管理员旋钮**（不设轮数/token/工具/时长上限，也没有验收超时、候选提议这类参数）。要关只有一处：**智能体设置里那个助手自己的「目标模式」开关**——关掉时入口、目标面板与验收标准三处同时不出现，助手那边也看不到目标与验收标准。

## 多模态输入

图片和文件都能直接**粘贴**进输入框（`Ctrl` / `Cmd` + `V`），也可以拖进来，或点「+」→ 上传文件选：

- **图片**（一轮最多 5 张）：经视觉模型理解后参与回答；鼠标停在图片上可看大图
- **文件**（一轮最多 5 个、单个不超过 15MB）：PDF / Word / Excel / PPT 与文本、代码类文件，读出正文后作为这一问的材料
- 粘贴一大段文字不会塞满输入框：自动收成一张「粘贴的文本」附件，点它能看全文
- 附件、图片、技能、@ 引用、# 历史引用都排在你要问的那句话中间，位置随文字一起走；按 `Backspace` 或点它上面的 × 就是取消这一条
- 整条一起复制：在输入框里全选后复制，粘到别处是干净的正文；粘回问渠的输入框会连附件一起还原，不用重传
- 附件上带着上传进度和失败原因；还没传完就点发送会被拦下来说明，不会静默漏带
- 编辑重发时附件默认跟着这一问再走一遍。上传的文件按保留期（默认 24 小时）清理，过期或当初没留下原件的会标成「已过保留期」/「不可重发」，重发时重新上传即可

## 智能体绑定规则

- 会话**不锁定**智能体：不挑就用默认助手，挑了从下一问起立即生效，换人不必新建会话；问题跨到别的领域时，模型会把那一问派给职责对口的助手去查（见「智能体」篇）
- 绑定的智能体不可用时 fail-loud 明确提示，不静默换人

## 会话管理

置顶 / 收藏 / 重命名 / 搜索（标题与内容全文匹配）/ 批量删除 / 清空；会话可导出 Markdown；对回答可**重新生成**（软删旧答案，可撤销）、赞/踩反馈；支持按消息组删除与撤销删除。逻辑删除超过保留期（默认 30 天）的会话与消息会被物理清理，保留期即「撤销删除」窗口。

## 模型选择与「这个模型不能用了」

输入框上方的模型胶囊决定这一问由谁来答：在某条会话里选过一次，它就记住在这条会话上（刷新、换设备都还在）；没选过就用「个人设置 → 默认模型」里的默认模型。

如果记住的那个模型后来被停用或已从模型列表里移除，界面不会等你撞上一次失败的回答才发现：

- 胶囊直接变红并写出原因（例如「deepseek-v4-pro 所在的供应商已停用」）。点开列表时这一项排在最前、标灰、点不动，下面照常列出可以换的模型
- 照常发问也答得出来：这一问自动改用你的默认模型，并在回答上方留一条「已清除这个会话的选择，本轮改用某某回答」的说明；想换别的就在胶囊里重新选一次
- 没有设默认模型时不替你猜：会停下来说明去哪儿选、去哪儿设
- 个人设置里那个默认模型本身被停用时，同样在原地标红说明，改一次立刻生效
- 重新生成、失败自动重试都沿用这一问原本用的模型，不会顺手改动会话上记住的选择

## 用户长期记忆

问答完成后异步提炼值得长期记住的用户信息（事实与偏好、工作背景、你明确要求记住的事），写进你自己的记忆文件，并在后续问答里提起——不同会话之间是连着的，同一工作区里的会话共用同一份记忆。不想让它记，可在「个人设置 → 我的记忆」里关掉「自动提炼记忆」：关掉的只是往后再提炼，已经记下的仍会被提起；要清掉已记的内容，直接在对话里让助手改或删。系统设置里还有一道平台总闸，两处都开着才会提炼。公开分享页与对外 API 链路不携带个人记忆。
