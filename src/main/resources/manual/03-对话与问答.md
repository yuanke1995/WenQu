# 对话与问答

对话页是日常使用的主入口，支持流式回答、引用溯源、深度思考、多模态输入与长任务自动推进。

## 流式回答

回答经 SSE 逐段下发，可随时点「停止本轮」——**中止同样留痕**：已产出的正文、已执行的工具与用量都会落库，不会因为中止丢失一轮。

回答进行中可以继续输入：新发的内容先排在输入框上方，点该条上的「立即发送」即作为**插话**送进正在执行的这一轮，在下一次调用模型前生效，不需要等本轮答完再重问；按 `Ctrl` / `⌘` + `Enter` 发送时，该句入队后立即执行「立即发送」。该句显示在本轮实际插入的位置，即若干步骤之间。未赶上本轮的内容在本轮结束时自动补发一次。

中断、超时、刷新页面、换设备或换网络之后，本轮的过程、计划与待裁决卡片均可原样恢复——运行状态保存在服务端，不依赖页面保持打开。

## 引用溯源

- 回答句末的 `[N]` 角标 → 弹窗展示来源知识块全文（图文交错）与关联截图
- 回答下方的**检索状态行**可展开查看全部命中来源与摘要，条目点击进同一溯源弹窗
- 外部来源（联网搜索、MCP 工具返回的网页）与知识库来源**共用同一套编号**：引用面板显示站点名、标题、摘要与外链，相关度优先按重排分展示
- 命中的文档图片经相关性校验后按编号位置级插入回答，点击可看原图；插入位置随消息落库，刷新、换设备与打开分享链接后仍在原位
- 引用一致性自检（默认开）：生成后校验每条 `[N]` 引用是否被引用内容支撑，剔除语义不符的引用并重编编号

回答没有引用角标时，通常是检索未召回足够相关的知识块（相关性阈值会过滤弱相关内容），可参考《检索原理与调参》。

## 回答里的代码块与图表

每段代码标题栏的右上角按语言自动出现若干动作：**复制**（每种代码块都有）；**预览**（HTML / SVG，在弹层内查看渲染效果，弹层按整页尺寸提供，因此布局与响应式表现可见，右上角还可「新窗口打开」）；**在云端沙盒中运行**（Python / Node / Shell，在隔离沙盒中执行，不影响本机环境，输出回填在该段代码下方）。

两类代码块在回答生成后直接渲染成图，不需要点按钮：

- **统计图**（语言标 `echarts`）：代码块内容是一份 ECharts option（JSON 格式），在回答中原位渲染为交互图表——折线图、柱状图、饼图、散点图均支持，可悬浮查看数值、可点图例开关系列，配色跟随界面亮暗主题；图下方可展开查看原始 option
- **示意图**（语言标 `mermaid`）：流程图、时序图、甘特图等，原位渲染成矢量图，同样可展开看源码

option 不是合法 JSON 或缺 `series` 字段时，该位置显示失败原因与源码，不留空白画布。

预览仅在回答正文提供。知识块原文、技能正文中的 HTML 只提供复制——这类代码来自上传的内容，不随查看者的点击执行。

## 沙盒里的后台进程

助手把前后端服务跑起来查看效果时，起的是不会自行退出的进程；而沙盒执行一条命令到点未结束，只是**不再等待它**——进程仍然存活、端口仍然占用。检测到这类进程时，对话右侧会出现**后台进程**卡（电脑端提供），列出该沙盒中此刻仍在运行的内容：命令行、已运行时长、占用端口与进程树数量；没有可显示的内容时该卡不出现。

会话列表中，存在这类进程的会话与「正在回答」使用同一种呼吸提示，悬停说明属于哪一类。

每条右侧的**停止**会终止该进程及其全部子进程并释放端口；无法终止时明确说明有几个未能终止，已自行退出的只说明「已自行退出」。

几点边界需要知悉：

- 只列出**由本处执行产生**的进程。此前起的、以及工作流与定时任务起的进程不在这张卡上，其记录在各自的运行历史里
- 工作区开启共用目录时，同一工作区的多个会话共用一个沙盒，因此其他会话起的进程也会列出并标注「同沙盒别的会话起的」——端口由同一个沙盒占用，不可见即无法终止
- 沙盒空闲一段时间后会被回收（默认 60 分钟），容器回收后进程随之结束，该卡同时清空
- 会话列表上的提示只覆盖**后端当前认得的沙盒**：后端刚重启、或沙盒已被回收时那一行不会亮；要确认请进入对话查看右栏该卡
- 助手侧同样可见：一条命令超时退出、却仍有进程存活时，该步骤的结果会写明留下几个进程及其内容，并说明重跑会撞端口占用

## 回答交付的产物

助手输出清单、表格、网页或代码后，该条回答末尾按生成顺序列出这些产物，每条提供**预览**与**下载**。

**预览**以整屏打开，按文件类型采用不同视图：

- **网页**（`.html` / `.htm`）按真实渲染展示，顶栏可切换**视口宽度**：自适应 / 375 / 768 / 1440，也可自行填写数值；选择 375 时页面按手机宽度重新排版。旁边的**缩放**（适合宽度 / 50% / 75% / 100%）只缩小画面以放进屏幕，不改变页面自身的排版宽度
- **Markdown、文本与代码**（`.md`、`.txt`、`.json`、`.py`、`.java`、`.css` 等）就地排版：Markdown 按标题、表格、代码块渲染，代码带高亮与复制按钮
- **分隔符表**（`.csv`、`.tsv`）显示为只读表格，行数写在表格下方；首行按表头显示，超过 300 行只列前 300 行
- **图片**铺满整屏，点击在「适合屏幕」与 1:1 之间切换；**PDF** 使用内置阅读器
- 顶栏固定提供「新标签」。按住 Ctrl（Mac 为 ⌘）点击「预览」，或使用鼠标中键点击，同样在新标签页打开

**Excel（`.xlsx` / `.xls`）与压缩包（`.zip`）只提供下载**：这类内容无法在页面内还原排版。

两个上限：单份产物最大 1MB；文本类预览只读取前 256KB，超出时该屏写明后半部分未取回，完整内容请下载查看。

一项已知限制：**同批交付的几份文件互相引用时（例如网页里写 `./style.css`）无法整体预览**。产物逐份独立存储，文件名前各带一串随机字符，网页按相对路径找不到这些文件。需要单份可直接查看的网页，请让助手把样式与图片内联进同一份 HTML。

同一批产物还有两个汇总位置：PC 右侧状态栏的「产物」卡，手机上的「状态与来源」面板，两处的预览与下载和回答中一致。需要长期保留、改名或变更归属时，使用侧栏的「我的产物」。

「我的产物」只列**助手主动交付**的产物。在沙盒中生成但未交付的文件不出现在这里——这类文件在右侧状态栏的「沙盒文件」卡中，可打开、下载，或存为产物（存为后与这里的条目等同）。见《技能与沙盒》。

一轮回答被**推理步数上限**或**单轮工具步数上限**截断时，回答下方会出现一行说明（刷新后仍在）：本轮执行预算按步计，到达上限即停止。出现该说明后发送「继续」即可接着执行；已生成的文件不会丢失，在「沙盒文件」卡中查看。两道闸都在系统设置里：前者是「调试设置 → 框架引擎推理步数上限」（限模型调用几轮），后者是「工具调用 → 单轮工具步数上限」（限工具调用几次，智能体可各自覆盖）；两处填 **0 = 不限制**。

## 引用资料（`@` 或「+」面板的「引用」页）

四类内容可以在提问时指定给助手，**只对当轮生效**，下一轮自动清空：

- **知识库** —— 本轮检索限定在所选库内
- **文档** —— 该文档的相关内容直接带入本轮上下文，适用于「按这份文档回答」
- **智能体** —— 本轮强制向该助手咨询一次（由对方带自己的知识库检索），回答仍由当前助手汇总
- **技能** —— 所选技能的正文逐字带入本轮，即要求按该流程执行

两个入口是同一块面板：在输入框打 `@` 后继续输入即筛选，`Enter` 选中；或点输入框左下的 `+` 进入「引用资料」页选择。四类各占一个页签，页签上标着可选数量，搜索框对当前页签生效。键盘：`↑↓` 选择、`Enter` 确认、`Tab` 退回上一级、`Esc` 关闭。

选中内容以标签形式排在输入文本中间，点标签上的 × 可移除；一轮最多引用 10 个知识库 / 文档 / 智能体，智能体每轮限一个（再选即替换），技能单独计最多 3 个。

另有 `#` 引用历史问答：把以往对话中的具体问答带入本轮（最多 10 条，同样只对当轮生效）。

## 深度思考

开启后思维链**按轮就地展示**：模型每推理一次，回答流程中增加一行「深度思考」，点开查看该段内容——先推理再调工具、推理后继续生成的，各段位置独立，不会集中在回答顶部。是否开启由对话页决定，系统不自行判断哪一轮需要思考；登记为「恒思考」的模型即使关闭仍会先推理一次，该段同样出现在对应位置。

悬浮模型行弹出的设置面板可按模型调整**思考强度**（低 / 中 / 高 / 超高 / 极致）与**上下文窗口档位**：模型登记了「最小~最大窗口」区间时，窗口档位可在区间内选择（默认取上限）。档位**跟着这条对话走**——刷新、换设备、隔天再打开都还是这一档，改动从下一句提问起生效。窗口决定检索资料的填充量（预算 = 窗口 × 安全系数 − 最大输出），也决定长对话什么时候开始折上下文：窗口越大，越早的轮次还能逐字留着。

## 上下文压缩（长对话）

对话内容接近窗口容量时，早期轮次被折叠为一份**早期对话摘要**继续随上下文携带，近期问答逐字保留，避免超出模型上下文后丢失早期信息。折叠时机由模型窗口推导，没有开关；一次长任务里可以折叠多次。

- **界面标识**：对话流中出现一条居中的 **「已压缩上下文」** 分隔线，标出本次压缩发生在对话的哪个位置；该分隔线保留在会话中，刷新页面、换设备后仍在原处
- **进度提示**：轮内自动压缩时，本轮顶部状态行显示 **「正在压缩上下文」**，完成后该回答上方留下分隔线；手动 `/compact` 不在任何轮内执行，完成后分隔线直接出现在对话流末尾
- **查看摘要**：点分隔线旁的「查看摘要」，弹窗显示摘要全文与规模（tokens 数、逐字保留的最近问答轮数），可一键复制
- **原文保留**：压缩只改变送入模型的内容，问答原文仍完整保留在会话中，向上滚动可回看
- **手动压缩**：在输入框打 `/compact` 回车，或点开 PC 输入框右下的容量圆环、在「上下文容量」卡底部点**压缩上下文**（移动端在「模型与思考」面板）。完成后显示**为后续腾出约多少 tokens**；卡上的占用数字要到下一轮提问后才更新
- **指定摘要要求**：在「查看摘要」弹窗点**带要求重新压缩**并填一句（如「只保留结论和数字，忽略寒暄」）——该句只作用这一次压缩，之后的压缩回到默认写法
- **最近内容不参与压缩**：最近 2 轮问答始终逐字保留；会话过长时一次压缩无法全部完成，会提示可再次执行 `/compact` 继续
- **容量占用**：上下文容量明细分为系统提示词、历史对话、本轮提问、检索资料、工具结果、思考内容、工具声明七类，可据此判断窗口被检索资料还是被工具输出占用（PC 悬浮输入框右下的容量圆环，移动端在「状态与来源」里查看）。压缩后的历史归入「历史对话」一段，不单列摘要

## 过程独白与执行清单

工具模式下模型的推理与试错独白与正文分流，前端灰字原位展示；整轮「文本段 + 工具段 + 产物段」编为消息时间线随消息落库——刷新页面后仍是交错的实时过程视图。

- **每轮只报一个总耗时**：执行中回答末尾显示一行「正在溯源，用时 12 秒 …」，秒数递增表示仍在执行；本轮完成后该行替换为总览并回到回答最上方——「已完成，用时 6 分 26 秒」。该数值为从发出提问到完成的实际墙钟时间（回答提问卡、批准计划卡的等待时间也计入，悬停提示单独给出其中的等待时长）
- **展开是一行一步**：该行右侧有折叠三角时，表示本轮执行过工具；点开列出执行了什么、查询了什么，行首序号与「已执行 N 个操作」对应。该步骤之前模型思考的那一段挂在同一行行尾（写作「深度思考 N 字」，点开看全文），不单独占一行。耗时只在这一行显示，工具行不带时长
- **完成后默认折叠**：整条回答只剩最上方那一行，展开后回到交错的实时过程视图，正文不受展开/收起影响；刷新页面、换设备后形态一致
- **无耗时记录时不显示数字**：未记录该值的会话只显示「已完成」，不会显示为「0 秒」
- **工具大输出**：单次输出超出展示上限时整份留存，卡片上可「查看完整输出」读回原文或在其中检索；这些留存按保留期自动清理（默认 7 天）
- **执行过程账本**：回答的「更多」菜单里有「看这一轮的过程」，弹窗按轮列出工具步骤与耗时、审批与提问与计划三张卡、产物、子智能体编排、停止与失败原因

## 下一步建议

最新一轮回答的末尾会给出「接下来可以」若干条可点击的追问方向，点击即按该方向发问，不需要重新输入。这一排**只跟在最新一轮之后**：历史轮次的建议内容已被后续提问覆盖，再展示可点击的问句会遮挡正文，且容易误点重发。向上翻阅历史时只看到问答本身，继续提问在最后一轮操作。

## 计划模式（先出计划，再执行）

适用于「先确认执行方案，再决定是否执行」的场景。桌面在输入框打 `/plan`（或 `/计划`）回车开启（也可以点「+」→ 快捷命令 → **计划**），手机点「+」→ 本轮模式 → **计划模式**开关；也可以 `/计划 任务` 直接发送任务并先出计划。开启后输入框出现「计划」标记（桌面位于输入框正文内，手机位于输入框上方），删除该标记即关闭（再打一次 `/plan` 同样关闭）。

该开关只对**下一轮**生效：发送后标记随附件、引用一并清除，之后各轮按普通问答执行；需要再次先出计划要重新开启（同一份计划的反复修改不需要重开，用计划卡的「继续对话」）。开关状态保存在本机浏览器，桌面与手机同源共享。

**计划与目标一轮只能用一个**：每一轮提问要么走计划模式（先出计划卡），要么走目标模式（设定目标后自动续跑）。开启一边时，另一边已挂载的标记会自动清除；挂着「目标」标记时发送的那一轮不会带上计划，反之亦然。

- 该轮先产出**执行计划**卡（生成中 → 待确认），此时输入框换成计划确认栏：
  - **1. 确认**：按这份计划开始执行
  - **2. 继续对话**：填写修改意见（Enter 直接发送，Shift+Enter 换行）——意见作为一条正式用户消息在同一会话中继续，本版计划作废（卡片标「已被取代」），模型按意见生成下一版，可反复修改
  - **取消**：本轮停止，卡片定格「未批准」
- 挂起的计划有倒计时（默认 10 分钟，可调），超时按未批准收尾、本轮停止
- 未开启计划模式时，模型也可以自行判断是否先出计划；是否进入完全由模型决定
- 计划卡随消息落库：刷新页面、换设备后仍在原处，可继续裁决；右栏「计划」卡列出本会话每轮生成的计划，点击定位到那一轮；卡内「修改记录」可回看各版计划与修改意见
- 计划描述的是**交付物**：形态是什么、包含哪些部分、关键选择是什么、以什么方式呈现。指代交付物时只出现其名称（如「单个网页文件 index.html」），不出现沙盒或服务器上的文件路径，也不出现工具名与命令——这些属于内部实现，与判断计划是否符合预期无关

## 目标模式（长任务自动续跑，完成即停）

适用于一轮问答无法完成、需要助手自行推进的长任务。目标模式维护三件事：**目标内容、当前轮次、停止条件**。

入口是 `/目标`（桌面在输入框打 `/目标` 或从 `/` 面板选「目标」；手机点「+」→ 本轮模式 → **定为目标**），也可以直接 `/目标 做一个问渠官网`。**输入目标后回车即开始**，不弹表单、不追问。同一会话同时只有一条未结束目标；已有目标时先改它、继续它或删除它。

- **自动续跑**：每轮结束后由调度器继续下一轮，不需要点「继续」，也不中途请求确认
- **进展留痕**：助手每轮把计划、已确认事实、已产出文件与阶段（探索 / 规划 / 执行 / 核验 / 交付）记进这份跨轮状态，下一轮据此继续，不靠聊天记录推测进度
- **完成由证据核验判定**：助手通过「提交目标完成申请」交回结论与证据清单（产物、文件、命令或测试）。平台逐条核验后才转为「已完成」：申请必须有摘要与至少一条可解析证据；引用的产物要能在产物登记表中查到，文件证据可另查其存在性；命令与测试类证据必须带退出码且为 0。**正文中的完成自述不构成完成判定**，助手自述不作为证据
- **核验不通过就补缺口**：证据有缺口时目标继续推进并在提示里写明缺什么；连续多次核验不通过（默认 5 次）转为「已暂停」并写明缺口内容
- **受阻即停**：遇到权限、资料缺失等无法自行解决的阻塞时，助手提交受阻申请，目标转为「已暂停」并把原因显示在目标条上
- **四项硬预算兜底**：轮数（默认 40）、工具调用（默认 400 次）、token（默认 200 万）、机器时长（默认 2 小时）任一项用满即停，目标条写明是哪一项用满、已执行多少轮，进度与已生成内容全部保留，可点「继续」从当前进度续跑（预算不重置）。四项都在**系统设置 → 目标模式**里改，**填 0 = 该项不限制**；另有一项「预算用到几成开始在提示里要求收敛」的软阈值（默认八成）
- **故障自愈**：瞬时错误按退避自动重试（默认 2 次）；进程异常导致执行中断时，目标条显示「待恢复」，由心跳与租约对账后自动恢复（默认最多 3 次），超过上限转「已暂停」
- 可执行的操作只有三个：**改目标**（点编辑键就地修改该句，从下一轮起生效）、**停止/继续**（停止后进度全部保留，可随时继续）、**删除**（目标从界面移除，已生成的内容与产物全部保留）
- 进行中的目标常驻在**输入框内的一行**：左侧是「目标」标记与目标原文，右侧是停止/继续、编辑、删除三个图标键。已执行轮数与停止原因：桌面悬停在目标原文上查看，手机显示在该行下方第二行小字里；目标卡（手机「状态与来源」中）另给出阶段与预算占比
- 目标**完成或删除后该行移除**——不再需要处理任何事。结果保留在右栏「目标」面板（手机在「状态与来源」里）
- 定目标时会在**对话里留下一条记录**（气泡上方有一枚 `/goal` 标记，正文即当时的目标原文），作为「当初交付了什么」长期可见；它是一条指令，不占用问题的复制 / 编辑重发入口
- 在会话里插话时目标让位（优先处理该句），这句答完后目标自动接上，不需要手动点继续
- 刷新页面、换设备后上述各处都仍在——目标存储在服务端，不依赖页面保持打开

目标模式**没有平台级开关**，也不要求用户逐条勾选验收标准。管理员可调的只有上述预算与恢复参数，都在**系统设置 → 目标模式**。关闭入口只有一处：**智能体设置中该助手自己的「目标模式」开关**——关闭后界面入口与目标面板同时不出现，助手也不再获得目标相关能力。

## 多模态输入

图片和文件都能直接**粘贴**进输入框（`Ctrl` / `Cmd` + `V`），也可以拖进来，或点「+」→ 上传文件选：

- **图片**（一轮最多 5 张，单张默认上限 10MB）：经视觉模型理解后参与回答；鼠标悬停在图片上可查看大图。聊天模型不支持图片理解时**可见降级**：图片仍随消息展示，并向模型如实说明图片不可见，不静默丢弃
- **文件**（一轮最多 5 个、单个不超过 15MB）：PDF / Word / Excel / PPT 与文本、代码类文件，读出正文后作为该问的材料
- 粘贴较长文本时不占用输入框：自动收为一张「粘贴的文本」附件，点击查看全文
- 附件、图片、技能、`@` 引用、`#` 历史引用都排在输入文本中间，位置随文字一起移动；点其上的 × 即移除该条（退格不删标签）
- **整体复制**：在输入框全选后复制，粘贴到外部得到纯正文；粘回问渠输入框会连同附件一起还原，无需重传
- 附件上显示上传进度和失败原因；未完成时点发送会被拦截并说明原因，不会静默漏带
- 编辑重发时附件默认随该问再次携带。上传的文件按保留期（默认 24 小时）清理，过期或当初未留存原件的标为「已过保留期」/「不可重发」，重发时重新上传即可

## 智能体绑定规则

- 会话**不锁定**智能体：未选择时使用默认助手，选择后从下一问起生效，更换不需要新建会话；问题涉及其他领域时，模型会把该问委派给职责对口的助手查询（见《智能体》）
- 绑定的智能体不可用时 fail-loud 明确提示，不静默换人

## 会话管理

置顶 / 收藏 / 重命名 / 搜索（标题与内容全文匹配）/ 批量删除 / 清空；会话可导出 Markdown；可把整段对话生成**只读分享链接**（可查看访问次数、换一个链接、停止分享）；对回答可**重新生成**（软删旧答案，可撤销）并在新旧版本间切换；赞 / 踩反馈（点踩可附一句不满意的原因）；支持按消息组删除与撤销删除。逻辑删除超过保留期（默认 30 天）的会话与消息会被物理清理，保留期即「撤销删除」窗口。

左侧问题锚点轨（宽屏、两轮以上）把每轮提问做成一条刻度，悬停预览问题与回答摘录，点击直接滚到那一轮。

导出的 Markdown 是一份自包含文件，发给他人同样能看到图与图表：正文中的图片转成内嵌数据；`echarts` 统计图按当前主题的配色绘制成图片原位放入正文，原始配置收在文末「图表源码」一节（该文件放回问渠打开时，配置会重新渲染成图）；`mermaid` 示意图保留源码围栏，主流阅读器可自行渲染。无法渲染的图保留原围栏，数据不丢失。

## 模型选择与「这个模型不能用了」

输入框上方的模型胶囊决定该问使用哪个模型：在某个会话中选择过一次，即记录在该会话上（刷新、换设备后仍在）；未选择时使用「个人设置 → 默认模型」。

如果该模型后来被停用或已从模型列表移除，界面不会等到提问失败才提示：

- 胶囊直接变红并写出原因（例如「某某模型所在的供应商已停用」）。打开列表时该项排在最前、标灰、不可点击，下方照常列出可切换的模型
- 照常发问可以正常回答：该问自动改用你的默认模型，并在回答上方留一条「已清除这个会话的选择，本轮改用某某回答」的说明；需要其他模型时在胶囊里重新选择一次
- 未设置默认模型时不自动猜测：停止该轮并说明在哪里选择、在哪里设置
- 个人设置里的默认模型本身被停用时，同样在原地标红说明，修改后立即生效
- 重新生成、失败自动重试都沿用该问原本使用的模型，不会改动会话上记录的选择

这一轮为什么没答出来（模型不可用、额度不足、被限流、上一轮还在跑、服务内部异常）会留在对话里，不会刷新一次就当没发生过：回答说到一半被打断，原因跟在回答末尾；什么都没产出，原因写在那一句提问下面。隔天回来仍然看得见，在那一句上改一改重发即可。

## 待办提醒（铃铛）

需要你来处理的卡片都在铃铛上有计数：智能体提问待答、工具执行待批准、计划待确认。不在该会话页时也会提示；卡片本身随消息落库，重新进入会话仍在原处、各题勾选状态照原样保留。

跑了一分钟以上的轮次也会报：一轮跑完、一轮没跑成、跑到一半提前停了，都会给这条会话的归属人钉一条通知。**短问答不报**——答案当场就在屏幕上，再钉一条只是噪音；耗时门槛（默认 60 秒，按机器干活的时间算，等你读卡的时间不计入）在系统设置「定时任务 → 站内通知」可调，整类通知也能在那里一并关掉。一个横跨多轮的目标不逐轮报完成，只在它达成或停住时报一次，免得铃铛变成进度条。

被你自己按停的这一轮不报，那是你刚做的动作。免登录分享页里的提问不报——访客没有站内账号。

铃铛同时是**通知中心**的入口：解析完成与失败、批量解析失败、工作流失败 / 超时 / 待审批、网页源刷新失败、定时任务完成与失败、检索质量下滑、模型额度异常等异步事件都会写入站内通知。通知中心支持按类型筛选、只看未读、批量标记已读与删除，也可以**按类型静音**（只影响本人，不产生也不丢失通知）。通知条目带来源位置，点击直达对应的文档、工作流运行或会话。

## 用户长期记忆

问答完成后异步提炼可长期保留的用户信息（事实与偏好、工作背景、明确要求记住的内容），写入用户自己的记忆文件并在后续问答中引用——跨会话连续，同一工作区内的会话共用同一份记忆。

不需要自动提炼时，可在「个人设置 → 我的记忆」关闭「自动提炼记忆」：关闭只停止后续提炼，已记录的内容仍会被引用；要清除已记录的内容，直接在对话中让助手修改或删除，或在个人设置里编辑与清空。系统设置里还有一道平台总闸，两处都开启才会提炼。公开分享页与对外 API 链路不携带个人记忆。

## 移动端形态

触屏且窗口宽度较窄时，对话页自动交给移动端外壳（电脑端用鼠标操作时不会触发）。提问、回答、人在回路三张卡、上下文与产物在两端是同一套数据与判定，只是排布不同：

- 输入区左下 `+` 聚合**技能 / 引用 / 历史 / 附件**四个页签，模式开关（计划模式、定为目标）也在其中
- 「状态与来源」面板收纳**引用来源 / 上下文容量 / 产物 / 目标**，以及分享只读链接与导出 Markdown
- 长按或点选回答出现「本轮操作」：导出这轮问答、加入评测集、检索调试、看这一轮的过程、删除本轮
- 会话列表、个人设置、帮助中心、我的产物、知识库与主题切换都收在壳内菜单
- 需要完整表格、画布编辑这类宽屏操作时，页面会给出「建议用电脑访问」的引导，不会把功能做残
