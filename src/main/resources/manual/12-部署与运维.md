# 部署与运维（管理员）

## 环境变量

```bash
# 必填（缺失启动失败 fail-fast）
export DB_PASSWORD=xxx

# 基础设施（有默认值，按环境调整）
export DB_HOST=127.0.0.1  DB_PORT=3306  DB_NAME=wenqu_ai  DB_USERNAME=root
export REDIS_HOST=127.0.0.1  REDIS_PORT=6379  REDIS_PASSWORD=  REDIS_DB=0
export AI_IMAGES_DIR=./data          # 数据根目录（源文件/图片/产物/密钥）

# 安全
export AI_JWT_SECRET=xxx             # ≥32 位随机串；留空每次启动随机生成（重启后旧令牌失效）；多副本必须一致

# 仅 env/yml（不进设置页）
export AI_MEILI_KEY=xxx              # Meilisearch master key
export AI_MEILI_INDEX=ai-doc-chunks
export SPRINGDOC_ENABLED=false       # Swagger 开关（默认关）
```

启动：`mvn spring-boot:run` 或 `java -jar target/wenqu.jar`；Docker Compose 自包含（redis-stack + meilisearch + MySQL）：`docker compose up -d`。后端监听 `http://localhost:8090/ai`，健康检查 `/ai/actuator/health`。

表结构由启动自动执行 `schema.sql` 创建（幂等）；存量库缺列缺索引由 `SchemaMigrator` 启动期自动补齐。

## 多副本部署要求（摘要）

1. 数据目录必须共享（`AI_IMAGES_DIR` 指向共享存储；跨主机挂 NFS/对象存储）
2. 静态配置（env/yml）各副本一致，`AI_JWT_SECRET` 尤其必须一致；动态配置经 Redis 广播
3. 解析队列有界；总并发 = 副本数 × parse.concurrency，embedding/视觉是共享瓶颈
4. 删除在任意实例生效，其他实例解析任务由 DB 兜底秒级停止清理
5. 向量模型热切换全实例串行（Redis 分布式锁），锁持有期间向量检索自动降级关键词路
6. 多副本上线前把 `keyword.reconcileOnStartup` 与 `parse.recoverStuckOnStartup` 置 false（启动对账收敛为单点）
7. RSA 密钥文件必须共享（默认 `{AI_IMAGES_DIR}/secret/config-rsa.key`，可 `AI_CONFIG_RSA_KEY` 覆盖）

## 后台定时任务

全部集中在 ScheduleCenter：单 daemon 线程 10s 节拍轮询，间隔实时读配置（改配置即时生效、≤0 暂停），任务体提交线程池、防重叠。

| 任务 | 默认间隔 |
|------|----------|
| 关键词索引精确对账 | 1h |
| 聊天图片目录清理 | 1d |
| 检索评估自动体检 | 1d |
| 配置缓存兜底刷新 | 5min |
| 过期会话/消息清理 | 1d（保留期默认 30 天） |
| 产物超期清理 | 1d（保留 90 天） |
| 定时智能体任务 | 30s |
| 网页源定时刷新 | 60s |
| 沙盒空闲回收 | 10min（空闲 60 分钟回收） |

## 默认关闭项（安全边界）

智能体 / 工具（含沙盒）/ 技能默认全关（`agent.enabled`、`tool.*`、`skill.enabled`）；MCP 客户端无全局开关（每用户自建）；MCP 服务端 `mcp.server.enabled` 默认关。需在设置页显式开启。

## 沙盒

- provisioner：`bash deploy/sandbox-provisioner/run.sh docker-up`（127.0.0.1:8002；首次构建约 12GB 镜像）
- 设置页「沙盒 → 访问令牌」须与 provisioner 侧 `SANDBOX_PROVISIONER_TOKEN` 一致且 ≥32 字符（不足 fail-closed 拒绝启用；校验推迟到首次使用）
- 沙盒运行时依赖必须烧进镜像（容器内无 sudo）：用 `sandbox-image/Dockerfile` 派生镜像并在 `.env` 设 `SANDBOX_IMAGE`
- 沙盒持久卷在 `user-data/shared/{uid}/workspace/`，重建容器工作区不丢

## 模型兼容

- 部分网关模型返回 DashScope 原生格式（`{"text":...}`）无法解析，需用返回标准 OpenAI 格式的模型
- base-url 不含 `/v1`（后端自动补）
- 切换向量模型 = 全量重嵌入，避免业务高峰；重嵌入与并发解析撞车可能丢块，任务末尾索引对账会告警，空闲时手动补跑
