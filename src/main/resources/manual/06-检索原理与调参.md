# 检索原理与调参

问渠的问答质量由「检索 → 重排 → 上下文组装」三级决定，调参前请先理解这两条链路。

## 混合检索

一次检索并行跑两路：

- **向量路**：问题向量化后在 Redis 向量索引里召回语义近邻（每个知识库独立索引，按库绑定模型）
- **关键词路**：关键词引擎召回（默认 MySQL LIKE，零依赖；可切换 Meilisearch 获得 jieba 中文分词与相关度打分，服务不可用时自动降级回 MySQL）

两路结果按权重融合（默认向量 0.6 / 关键词 0.4，设置页可调），语义与关键词双命中叠加加分，另有标题命中奖励；向量分经归一化后参与融合。

> 融合分会因权重与阈值设定而**放大词面重叠**——仅字面重合的无关块，融合分也可能不低，因此需要重排。

## 重排与两道相关性阈值

重排（Rerank）用交叉编码器对「问题-块」逐对精算相关分，是过滤语义无关块的关键一环。**融合分与重排分是两个分值域，阈值不能混用**：

- **最低相关分**（`retrieval.minContextScore`，默认 0.6）：作用于**重排分**——相关块通常 0.5 以上，无关块趋近 0
- **融合分门（未重排）**（`retrieval.minFusionScore`，默认 0.5）：作用于**融合分**，仅在重排未启用或失败时兜底
- **单侧约束**：本轮重排实际执行过后，未经重排的候选不得经融合阈值进入上下文，防止弱相关块混入引用

**重排有两个窗口参数**（系统设置 → 检索设置 → 检索与重排，修改后即生效）：

- **少于几条不重排**（默认 6）：候选数低于该值时不执行重排，直接按融合分排序
- **重排窗口**（默认 15）：候选数超过该值时只重排头部这么多条，其余保持融合分序。配合上面的单侧约束，**窗口外的候选无法进入上下文**

出现「检索命中上百条、上下文却只有一两块」时，先用检索调试面板查看分数分布，再决定是调大窗口，还是阈值本应只放这么条数通过。窗口调大精度更高，但每次重排耗时更长。

所有把命中块送入上下文、引用面板、工具结果与工作流节点结果的路径，都先重排再按阈值过滤。「没有引用角标但回答里像有资料」通常是这两道阈值过滤掉了弱相关内容，属预期行为。**联网搜索结果与助手咨询返回的资料同样按本轮问题过这两道阈值**（服务商自带的相关度分不具相关性含义，不参与判定），被过滤的内容不进引用面板、不交给模型，过滤条数会如实写入给模型的说明。

## 其他增强

- **词面召回**：问句按中文分词切成检索词（jieba），与向量召回并行发起后再融合排序；多轮指代由对话上下文本身承担
- **GraphRAG 图谱扩展**（库级开关，默认关）：解析时抽取「主体-关系-客体」三元组入库；检索命中后，用命中块内容匹配实体 → 取一跳三元组 → 反查真实知识块，按衰减分（× 0.9）并入结果，条数由「检索图扩展上限」（默认 5）封顶。抽取规模由每批块数（默认 3）与每块三元组上限（默认 10）控制
- **父子分块**（默认开）：超长块切子块做检索索引（子块尺寸默认 400 字），命中子块返回父块完整正文
- **问答对增强**（默认开）：解析时对每块生成问答对（每块默认 2 条）并按问法向量化，不同问法也可召回；重嵌入时不重复调用模型

## 上下文组装

预算 = 模型窗口 × 安全系数（0.7）− 最大输出（窗口与最大输出按模型在「模型供应商」中声明）。命中块按相关度价值驱动填充，块内按命中位置截取片段（带 ±150 字窗口），做信息增益去冗余，历史对话按轮裁剪。填充总量由三项配额约束：知识块填充上限（默认 8）、单文档块数（默认 3）、单库块数（默认 4）。token 计数使用 cl100k BPE。

上下文窗口档位可以在对话页按会话下调（模型登记了「最小~最大」区间时），档位越高，检索资料与历史逐字保留的轮次越多。

## 调参顺序

1. **先确认分值域**：调阈值前先确认它作用在哪个分值域（重排分 / 融合分），两域分布不同
2. **用检索调试**：`POST /api/ai/debug/retrieval` 分步展示检索词元 / 关键词 / 向量 / 合并 / 重排 / 最终结果；问答页每条回答的「更多 → 检索调试」可直接查看本轮情况
3. **用检索评估**：评估页从历史问答引用回放生成评估集，多参数组对比 recall@k / MRR / 命中率，一键体检、一键应用最优组
4. **按资料类型定阈值**：手册类资料放宽阈值以保召回，法律与制度类提高阈值以保精度——这是库级参数稀疏覆盖的典型用途
5. **切换关键词引擎**（mysql ↔ meilisearch）后需全量重建一次索引；写索引随解析、编辑与删除增量同步，并有定时精确对账修复漂移
