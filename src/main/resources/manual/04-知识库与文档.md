# 知识库与文档管理

知识库是文档的容器，也是检索的作用域：检索按库隔离，不同库互不干扰；检索/解析参数随库配置。

## 知识库

- **个人默认库「问渠」**：每人一张、系统自动创建。未指定归属的上传/导入/移库都落进自己的默认库。默认库不绑定向量模型——首次使用前在知识库页自行绑定（只能绑自己登记的供应商）
- **新建知识库**：名称 + 向量模型（必填）。向量空间与索引一一对应，同库所有块必须同一向量模型
- **库级参数稀疏覆盖**：检索参数（阈值/召回数/重排等）与解析参数（分块大小/重叠/视觉模型等）留空=继承全局默认，填写=覆盖；解析参数仅对其后解析的文档生效
- **GraphRAG（可选）**：库级开关，开启后解析时抽实体关系三元组、检索时一跳图扩展；抽取模型在「知识库编辑 → GraphRAG」绑定（归库主：谁建库用谁的模型），未绑定回落系统兜底模型
- **官方内置库**：《问渠使用手册》是系统内置库，全员可读、随版本自动同步，不接受上传与编辑

## 文档上传与解析

支持格式：docx / pdf / xlsx / txt / md / csv，以及网页 URL 导入。扫描件 PDF 自动 OCR（逐页转图后走库绑定的视觉模型）。

解析链路：上传只登记持久化任务（解析队列），后台按并发抢占执行：解析 → 分块（按标题/结构感知切分）→ 增量入库 → 向量化（按库绑定模型）→ 关键词索引。队列有上限，排满会直接拒绝新上传并提示，不会先收下再丢。

- **增量重解析**：同名上传或手动重解析按内容指纹对比，未变的块保留向量，只重嵌变更处
- **解析中删除**：立即中断解析并清理产物，不留孤儿数据
- **版本管理**：每次成功解析版本号 +1 并存快照，可查看历史、一键回滚
- **知识块**：文档列表可打开知识块预览（切片列表/结构导图），支持单块编辑（自动重向量化）、停用、删除

## 网页 URL 导入

- 批量粘贴 URL（一次最多 20 个），抓取正文后按与上传完全相同的链路入库
- 仅支持公网 http/https，重定向逐跳校验防内网探测
- 源文件为 HTML 快照：重解析读快照离线提取，不重新抓网
- 可开**定时自动刷新**（文档级 cron），到期自动重抓 + 同名替换重建，失败留痕不中断

## 文档归属与共享

- **移动文档**：文档可在库之间移动；前后两库向量模型不同时自动异步迁移向量
- **共享范围**：文档未配置共享时跟随所属库（库门进了文档就可见）；显式配置则按配置独立判定。共享范围支持「全局 / 指定部门 / 指定用户」三档，管理范围不得宽于阅读范围
- **检索可见性两级判定**：文档可见 = 所属库允许 且 文档自身允许。私有库的内容不会因文档空白共享而泄露

## 常见问题速查

- 上传后一直「解析中」：看文档列表的解析进度与队列状态（排队 N / 执行 M）；服务重启残留的解析中文档会被对账复位，交队列重跑
- 解析失败：看失败原因（文件损坏/加密、超大文档截断、视觉模型不可用等），修复后点「重解析」
- 改了库级解析参数不生效：仅对其后解析/重解析的文档生效，对存量文档手动重解析
