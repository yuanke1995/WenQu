# MCP 与开放能力

问渠的开放能力覆盖「接入」（MCP Client）与「对外提供」（MCP Server / 游客分享 / API Key）两个方向。

## MCP Client：接入外部工具

在「智能体 → MCP 外部工具」登记自己的 MCP Server（streamable / sse），**按用户隔离连接池**，无全局配置。

- **服务管理**：卡片显示连接状态、传输类型与地址，可单个启用 / 停用、编辑、删除；支持批量启停与删除、整体「全部重连」与临时连通性探测。工具清单默认缓存 5 分钟，问答不再每轮远程拉取；远端新增工具最多 5 分钟后可见，需要立刻生效点「刷新」（会重建连接）
- **认证与请求头**：需要 Bearer Token / API Key 的服务，在弹窗「认证与请求头」中添加键值（也有常用预设）。请求头整块加密入库，保存后只回显键名、不回显值；编辑时不修改认证区即保持原凭据，更换时点「替换为新的请求头」，删除时点「清除凭据」。编辑态点「测试连接」会沿用已保存的凭据——先测再存
- **粘贴 JSON 导入**：添加弹窗右上角「粘贴 JSON 导入」，可直接粘贴 Claude / Cursor 配置里的 `{"mcpServers": {…}}` 片段。只导入 http(s) 地址型条目；本地进程（command / stdio）型会跳过并说明原因；预览阶段会标出重名、超配额与名称不合法
- **工具中文名**：点开服务卡片的工具清单，在每条工具右侧「起中文名」（不超过 16 字，留空保存即恢复原名）。名字按登记人归属保存，工具卡与审批卡都按它展示；未命名的工具显示原始英文名，不做自动翻译
- 登记后把 Server 挂到智能体的能力开关「MCP 外部工具」即可使用；未开启问渠工具总开关时该页会给出提示

**连接失败的排查步骤**（三层）：

1. **配置核对**：地址、传输类型、鉴权头是否与提供方一致
2. **端点直探**：用 curl 直接向 MCP 端点发 initialize（带 `Accept: application/json, text/event-stream`），确认能否完成握手
3. **服务端日志**：初始化与 tools/list 是串行两步，超时按两个请求计；日志会打印异常链根因

## MCP 调用审计（管理员）

「系统设置 → API 密钥 → MCP 调用审计」记录两个方向：

- **入站**：外部客户端调用平台端点，渠道显示「智能体端点」或「平台级」
- **出站**：模型调用你接入的外部 MCP 工具，渠道显示「出站工具」，记录工具名、耗时、成败与错误摘要，**不记录参数与返回内容**；工作流 MCP 节点的调用同样在列（没有智能体归属时该列为空）

可按渠道、工具名与结果筛选，也提供按工具 × 渠道的汇总。

## 本地统计 MCP Server（可选，开发者取数端）

问渠自带一个只读统计 MCP Server（`scripts/mcp-stats/server.py`），为「取数助手」这类对话提供本地 `wenqu_ai` 库的真实数据入口，智能体可在对话中写 SQL 查询业务数据并直接出图。

- **启动**：用 Python 运行 `scripts/mcp-stats/server.py`（依赖装进 WorkBuddy 托管 venv），监听 `127.0.0.1:8765/mcp`（streamable HTTP）
- **登记**：在「智能体 → MCP 外部工具」自行登记（每用户各自登记）：地址填 `http://127.0.0.1:8765/mcp`、类型选 streamable，挂到智能体工具集即可使用
- **能力**：`sql_query`（执行一条只读 SQL，返回 `{columns, rows, row_count}`，不带 `LIMIT` 时自动补 `LIMIT 200`）+ `db_overview`（核心表行数与时段摸底）；白名单仅 `SELECT / SHOW / DESC / EXPLAIN`，禁止一切写关键字，结果强制限量并保证 JSON 可序列化——只读取本地库，不产生任何写入
- **范围**：连接是本机回环，只适合开发机或单机部署，不要对外暴露

## MCP Server：把智能体发布为工具

- 智能体公开发布时开启 **MCP 端点**：`/ai/mcp/{token}`（Streamable HTTP，无状态），Claude Desktop / Cursor 等客户端粘贴地址即可调用该智能体。端点地址与 `mcp.json` 片段在发布弹窗中复制
- token 即凭据（与网页分享 `/s/{token}` 同源），停用分享或关掉「开放 MCP 端点」立即失效；**开启 MCP 端点依赖公开分享已开启**，否则发布时被拒绝
- 检索按发布者身份执行，能力收窄同游客模式：**沙盒、产物交付、技能执行与个人 MCP 不对外暴露**
- 总开关 `mcp.server.enabled` 默认关，在「系统设置 → MCP 服务（双向）」开启

## 平台级 MCP 入口

`/ai/mcp` 一个地址提供四项能力：检索知识库、提问、列出可见知识库、列出可用智能体。凭据为 API Key，且需在「API 密钥」中打开该 Key 的「MCP」开关。可见范围与 Key 创建者在网页上看到的一致，不是另一套权限。

## API Key 与游客分享

- **API Key**：仅存 SHA-256 哈希 + 前 8 位前缀，明文仅在签发时返回一次；权限固定为问答链路——即便持有 Key 也无法访问管理端点。名称、有效期与共享范围可随时编辑，到期即失效
- **游客分享**：智能体公开发布生成 `/s/{token}` 免登录对话页，可 iframe 嵌入（`?embed=1` 为紧凑模式）
- **会话只读分享**：`/shared/{token}` 把一段对话发给他人查看，不能续聊；可查看访问次数、换一个链接或停止分享，管理入口在「个人设置 → 分享管理」
- 游客链路按 IP 限频、工具白名单收窄、不携带个人记忆

接口契约与调用示例见《对接与集成》。
