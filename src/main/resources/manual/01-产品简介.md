# 问渠是什么

问渠（WenQu）是一款以智能体为核心的 AI 工作台，基于 Spring AI 构建，支持私有化部署。它将大模型、知识库与工具统一组织与编排，覆盖「智能对话 → 知识检索 → 工具执行 → 产物交付 → 对外能力开放」的完整链路。

> 问渠那得清如许，为有源头活水来。—— 答案，自有源头。

## 核心理念

- **智能体优先**：以智能体（人设 / 知识范围 / 工具集）为核心组织能力，支持多智能体并行编排与可视化工作流
- **答案可溯源**：混合检索 + 引用溯源 + 位置级文档原图展示，每个结论都能回到源头
- **开放互联**：MCP 双向（接入外部 Server / 对外发布为 MCP Server）、API Key 开放接口、游客分享页
- **生产就绪**：RBAC 权限、OIDC 单点登录、密钥加密存储、接口限流、操作审计、多副本水平扩展

## 能力地图

| 能力域 | 说明 |
|--------|------|
| 智能对话 | SSE 流式回答、句末 [N] 引用溯源、深度思考、过程独白、图片理解、@ 文档引用 |
| 知识库（RAG） | Word/PDF/Excel/TXT/Markdown/网页解析（扫描件 OCR）、混合检索、查询改写、知识块关联扩散、语义缓存 |
| 智能体 | 人设/知识/工具可配、会话级绑定、多智能体并行编排、定时执行 |
| 工具与沙盒 | 内置工具 + 技能包（Skills）+ MCP 工具；Docker 沙盒隔离执行 shell/文件读写；有副作用工具支持执行前人工确认 |
| 可视化工作流 | DSL 唯一真源 + StateGraph 执行引擎、11 类节点、画布编辑器与节点级 trace 回放、版本发布/回滚 |
| MCP 双向 | 接入任意外部 MCP Server；智能体一键发布为 MCP 端点（Claude/Cursor 直连） |
| 安全管控 | RBAC 菜单/端点两级管控、OIDC 单点登录、API Key（仅存哈希）、接口限流、操作审计 |
| 运营闭环 | 问答日志、赞/踩反馈、数据看板、检索量化评估（recall@k / MRR）、检索链路分步调试 |
| 长期记忆 | 问答后异步提炼用户画像、跨会话注入；个人设置可查/改/删 |

## 本手册在哪

你正在读的这本《问渠使用手册》就是问渠的**官方内置知识库**——它本身也是一个普通知识库，随版本自动同步，全员可读、不可编辑。你可以：

- 在「帮助中心」直接阅读（侧边栏 → 帮助中心）
- 在对话里直接问，比如「怎么调检索阈值」「上传支持哪些格式」——问答链路会自动从本手册检索并给出带引用的回答
- 把本手册库绑定到任意智能体的知识范围，让智能体成为问渠使用顾问
