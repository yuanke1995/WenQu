# 问渠是什么

问渠（WenQu）是一款以智能体为核心的 AI 工作台，支持私有化部署。它将大模型、知识库与工具统一组织与编排，覆盖「智能对话 → 知识检索 → 工具执行 → 产物交付 → 对外能力开放」的完整链路。

> 问渠那得清如许，为有源头活水来。—— 答案，自有源头。

## 核心理念

- **智能体优先**：以智能体（人设 / 知识范围 / 工具集）为核心组织能力，跨主题的问题由当前助手委派给职责对口的助手查询，复杂流程交给可视化工作流
- **长任务可控**：计划模式先出执行计划、经确认再动手；目标模式自动续跑，助手提交证据、平台逐条核验后判定完成；提问、审批与裁决都以卡片形式留在对话中
- **答案可溯源**：向量与关键词混合检索 + 重排 + 句末 `[N]` 引用，配合位置级文档原图展示，每个结论都能回到源头
- **开放互联**：MCP 双向（接入外部 Server，也可对外发布为 MCP Server）、API Key 开放接口、免登录游客分享页与只读对话分享
- **生产就绪**：RBAC 菜单与接口两级管控、多认证源单点登录、密钥加密存储、接口限流、操作审计、多副本水平扩展，电脑端与移动端两套界面

## 能力地图

| 能力域 | 说明 |
|--------|------|
| 智能对话 | SSE 流式回答、随时停止、断线后接回同一轮、运行中插话、引用溯源、深度思考（思考强度五档）、上下文容量明细与压缩、过程独白与执行清单、图片与文件输入、`@` 引用资料与 `#` 引用历史问答、回答末尾下一步建议 |
| 长任务执行 | 计划模式（执行计划卡）、目标模式（自动续跑 + 证据核验 + 四项硬预算）、任务清单进度、工具执行确认与智能体提问卡 |
| 知识库（RAG） | docx / pdf / xlsx / ppt / pptx / txt / md / csv 解析与网页导入（扫描件 OCR）、混合检索 + GraphRAG 图谱扩展、父子分块与问答对增强、网页定时刷新、文档版本与回收站、知识块预览与编辑 |
| 智能体 | 人设、知识范围与能力开关可配；会话不锁定助手，换人立即生效；按需委派与两种被委派执行形态；配置历史版本回滚；公开发布、MCP 端点与定时执行 |
| 工作区 | 一个工作目录 + 一份约定 + 一位默认助手；文件管理、会话与自动化归集、动态时间线、事项清单、资料域绑定、共用目录与记忆隔离 |
| 工具与沙盒 | 内置工具、联网搜索、技能包与 MCP 工具；Docker 沙盒内执行命令与读写文件（输出实时回传）、后台进程查看与停止、脚本批量执行；产物与沙盒文件整屏预览 |
| 可视化工作流 | DSL 唯一真源、13 类节点（含技能节点与 MCP 工具节点）、画布编辑与逐节点执行回放、版本发布与回滚、API 触发、定时触发、终态回调 |
| 技能与市场 | 技能三层来源（内置 / 我的 / 工作区）、zip 与 URL 安装、平台与个人两级停用；团队内市场分发技能、应用模板与工作流，安装即复制 |
| MCP 双向 | 接入任意外部 MCP Server（凭据加密、JSON 粘贴导入、工具逐条命名）；智能体发布为 MCP 端点，平台级入口对外提供检索、提问与清单能力 |
| 安全管控 | RBAC 两级管控、OIDC 单点登录（多认证源）、部门与共享范围、API Key（仅存哈希）、接口限流、操作审计、数据按归属隔离 |
| 运营闭环 | 个人使用统计与费用、问答日志与赞/踩反馈、数据看板（无命中率、热门与无命中问题、差评回流、知识缺口补块、执行 Trace、采样池）、检索量化评估、检索链路分步调试 |
| 通知与可感知 | 解析、工作流、网页源刷新、定时任务、审批与提问等待、长轮次跑完与没跑成、目标达成或停住、模型额度等事件写入站内通知，支持未读计数、按类型筛选与静音 |
| 长期记忆 | 问答后异步提炼用户信息，跨会话引用；同一工作区内的会话共用一份记忆，可按工作区隔离；个人设置可查看、编辑与清空 |
| 帮助中心 | 本手册即官方内置知识库，可在界面右下角直接阅读，也可在对话中就问渠的用法提问 |

## 在哪阅读本手册

- **帮助中心**：任意页面右下角的 `?` 角标（平时淡化贴在角上，鼠标移过去即点亮），或直接访问 `/help`
- **对话中提问**：问答链路会自动从本手册检索，例如「怎么调检索阈值」「上传支持哪些格式」，回答带引用
- **绑定到智能体**：在智能体的知识库范围中勾选《问渠使用手册》，即可作为问渠使用顾问

本手册随安装包分发。版本升级后由管理员在帮助中心点「**同步官方手册**」写入知识库——同步会对每篇逐块重新向量化并消耗供应商额度，内容没有变化的篇目自动跳过、不产生调用，因此通常只在升级后同步一次。同步后全员可读、任何人不可编辑，也不接受上传与导入。
