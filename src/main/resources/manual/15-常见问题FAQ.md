# 常见问题 FAQ

## 对话与问答

**Q：回答里没有 [N] 引用角标？**
检索未召回足够相关的知识块，或命中块被相关性阈值（重排分 0.6 / 融合分 0.5）过滤。可在问答页展开「检索状态行」查看命中情况；持续不准时用检索调试与评估页定位，见《检索原理与调参》。

**Q：换一个智能体要新建会话吗？**
不需要。选择哪位助手作答从下一问起生效，旧会话照常继续。决定「该问查哪些资料」的是模型：当前助手没有对应资料、而某位助手的职责范围明显匹配时，会把该问委派给该助手查询（对方在自己的知识库范围内检索一遍，返回结论和引用）。

**Q：对话里那个模型显示「已停用」，是不是不能提问了？**
可以正常提问。这表示该会话上次选择的模型所在供应商被停用，或该模型已从模型列表移除。胶囊上显示的是原因，打开列表重新选择即可继续；不改动直接发问也可以——该问会自动改用你的默认模型，并在回答上方留一条说明。若还没有设置默认模型，去「个人设置 → 默认模型」设置一个。历史会话里记录的选择可以在「智能体 → 模型供应商 → 查看引用」中一次清除。见《对话与问答 · 模型选择与「这个模型不能用了」》。

**Q：重新生成会丢掉上一版回答吗？**
旧答案软删除，可在「按消息组删除/撤销」里恢复；30 天保留期后物理清理。

**Q：怎么让助手忘掉我说过的信息？**
记忆存储在用户自己的记忆文件中：需要修改或删除，直接在对话中告知助手。

**Q：@ 文档和 @ 知识库有什么区别？**
@ 文档把该文档内最相关的块前置注入上下文（最强指定）；@ 知识库把检索范围收窄到该库。

**Q：对话里那条「已压缩上下文」是什么？我的记录还在吗？**
在，原文全部保留。长对话中更早的轮次会被折叠为一份摘要继续携带，该分隔线标出压缩发生在对话的哪个位置——压缩只改变送入模型的内容，问答原文仍留在会话中，向上滚动可回看。点分隔线旁的「查看摘要」可查看摘要内容；需要立即压缩时在输入框打 `/compact`（可带要求，如 `/compact 只保留结论和数字`）。见《对话与问答 · 上下文压缩》。

## 知识库与文档

**Q：上传支持哪些格式？解析失败怎么办？**
docx / pdf / xlsx / txt / md / csv 与网页 URL。失败时查看文档列表中的失败原因：文件损坏/加密、超大截断、视觉模型不可用（扫描件 OCR 需要）等，修复后点「重解析」。

**Q：改了知识库的分块参数，为什么存量文档没变化？**
库级解析参数只对其后解析/重解析的文档生效，需对存量文档手动重解析。

**Q：换绑向量模型会怎样？**
触发本库全量重嵌入（与块数成正比），期间向量检索降级为关键词路。避免在业务高峰操作。

**Q：为什么我的知识库其他人搜不到？**
未配置共享 = 私有（仅自己可见）；检索可见性 = 库允许 且 文档允许。需要共享时在库/文档的「共享范围」中配置。

**Q：《问渠使用手册》这个库为什么不能编辑/删除/上传？**
官方内置库：内容随版本自动同步，全员只读。需要智能体使用该库，在智能体的知识库范围中勾选即可。

## 智能体与工具

**Q：工具/沙盒开关打开了还是不执行？**
确认两级都已开启：系统设置「工具调用」总开关 + 对应子开关（沙盒另有 provisioner 与访问令牌配置）。

**Q：联网搜索的结果，为什么有的没列为引用？**
搜索返回的网页按本轮问题重排后再过相关性阈值（与知识库同一口径），低于阈值的不列为引用、不交给模型——服务商自带的相关度分（如位置衰减）不具相关性含义，不参与判定。重排不可用时会提示「本轮搜索结果未经相关性过滤」，此时保留未过滤的结果，而不是因一次瞬时故障导致完全无结果。

**Q：工具执行前弹出确认卡是什么机制？**
有副作用的沙盒/MCP 工具可配置「执行前确认」：批准/拒绝/超时按拒绝，防误操作。

**Q：MCP Server 连不上？**
按三层排查：核对配置 → 用 curl 直接向端点发 initialize 请求（带 `Accept: application/json, text/event-stream`）→ 查看服务端日志中的异常根因（初始化与 tools/list 串行，超时按两个请求计）。

## 管理与运维

**Q：登录后一直跳回登录页？**
`AI_JWT_SECRET` 未固定，服务重启后旧令牌全部失效。设置为固定值（≥32 位）即可（多副本必须一致）。

**Q：启动直接失败？**
先检查 `DB_PASSWORD`——必填项缺失会启动即失败；再确认数据库与 Redis Stack（向量索引依赖）的连通性。

**Q：设置页改的参数什么时候生效？**
多数保存即生效；解析类参数需重解析/新上传；`vision.timeoutMillis` 需重启。详见《系统配置说明》。

**Q：保存设置时报「这些项系统不认」，结果一个参数都没改，为什么？**
提交项中有一项不在可保存的配置清单里（通常是页面版本比后端旧，或该项已改名/取消）。此时整笔都不保存，而不是先写入可识别的项再报成功——否则界面显示「已保存」而实际未生效。刷新设置页重新修改即可；若确认该项应当可改，说明系统缺少它的定义，需要补进配置项清单。

**Q：回答下面那行黄色提示（本轮降级说明）刷新后还在吗？**
在。它随该条回答一起留存，回看历史时同样能看到「本轮未咨询到其他助手 / 未检索到资料 / 回答被截断」这类事实，不会因刷新而消失。是否显示这些提示由系统设置里的「检索调试入口」开关统一管理；关闭时回答区不显示任何降级提示。

**Q：怎么评估和优化检索质量？**
检索评估页从历史问答生成评估集，多参数组对比 recall@k / MRR；`POST /api/ai/debug/retrieval` 分步调试；数据看板有热门/无命中问题与知识缺口一键补块。
