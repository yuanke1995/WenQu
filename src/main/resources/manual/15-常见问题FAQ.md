# 常见问题 FAQ

## 对话与问答

**Q：回答里没有 `[N]` 引用角标？**
检索未召回足够相关的知识块，或命中块被相关性阈值（重排分默认 0.6 / 融合分默认 0.5）过滤。可在问答页展开「检索状态行」查看命中情况；持续不准时用检索调试与检索评估页定位，见《检索原理与调参》。

**Q：换一个智能体要新建会话吗？**
不需要。选择哪位助手作答从下一问起生效，旧会话照常继续。决定「该问查哪些资料」的是模型：当前助手没有对应资料、而某位助手的职责范围明显匹配时，会把该问委派给该助手查询（对方在自己的知识库范围内检索一遍，返回结论和引用）。

**Q：对话里那个模型显示「已停用」，是不是不能提问了？**
可以正常提问。这表示该会话上次选择的模型所在供应商被停用，或该模型已从模型列表移除。胶囊上显示原因，打开列表重新选择即可继续；不改动直接发问也可以——该问会自动改用你的默认模型，并在回答上方留一条说明。若还没有设置默认模型，去「个人设置 → 默认模型」设置一个。历史会话里记录的选择可以在「智能体 → 模型供应商 → 查看引用」中一次清除。

**Q：刷新页面或换设备后，正在跑的那一轮还在吗？**
在。本轮的过程、计划与待裁决卡片都会恢复；卡片未处理时铃铛也会提示。回答进行中发出去的内容作为插话进入本轮，在下一次调用模型前生效；没赶上本轮的会在本轮结束时自动补发。

**Q：重新生成会丢掉上一版回答吗？**
不会。旧答案软删除，可在新旧版本间切换，也可在「按消息组删除 / 撤销」里恢复；保留期（默认 30 天）后物理清理。

**Q：怎么让助手忘掉我说过的信息？**
记忆存储在用户自己的记忆文件中：需要修改或删除，直接在对话中告知助手，或在「个人设置 → 我的记忆」里编辑、按上限裁剪与清空。

**Q：`@` 文档和 `@` 知识库有什么区别？**
`@` 文档把该文档内最相关的块前置注入上下文（最强的指定）；`@` 知识库把检索范围收窄到该库。`#` 则用于把以往对话中的具体问答带入本轮。

**Q：对话里那条「已压缩上下文」是什么？我的记录还在吗？**
记录全部保留。长对话中更早的轮次会被折叠为一份摘要继续携带，该分隔线标出压缩发生在对话的哪个位置——压缩只改变送入模型的内容，问答原文仍留在会话中，向上滚动可回看。点分隔线旁的「查看摘要」可看内容，那里还能带一句要求重新压缩；需要立即压缩时在输入框打 `/compact`。

**Q：一轮任务被截断了怎么办？**
回答下方会出现一行说明：本轮执行预算按步计，到达上限即停止。发送「继续」即可接着执行，已生成的文件在右栏「沙盒文件」卡中不会丢失。两道闸（框架引擎推理步数上限、单轮工具步数上限）都在系统设置里，填 0 表示不限制；长任务被截断优先调大前者。

**Q：目标模式跑了很久，为什么还没判「已完成」？**
完成不由回答里的一句话决定。助手需要提交完成申请并附证据，平台逐条核验：必须有摘要与至少一条可解析证据，产物要能在产物登记表查到，命令或测试类证据必须带退出码且为 0。核验未通过时目标会继续补做缺口，并写明缺什么；连续多次未通过（默认 5 次）会转为「已暂停」。

**Q：交付的网页在预览里样式全丢了？**
同批交付的几份文件互相引用时（例如网页里写 `./style.css`）无法整体预览——产物逐份独立存储，文件名前各带一串随机字符。需要单份可直接查看的网页，请让助手把样式与图片内联进同一份 HTML。Excel 与压缩包不提供预览，只给下载。

**Q：右栏「后台进程」卡为什么不出现？**
只有确实扫到由本处执行留下的、且不会自行退出的进程时才出现；该卡只覆盖由对话执行产生的进程，工作流与定时任务起的进程在各自的运行历史里。沙盒被回收（默认空闲 60 分钟）后卡片清空，端口随之释放。

## 工作区

**Q：新建的对话为什么没进工作区？**
顶部「新建对话」创建的是不挂归属的对话，落在「会话」栏。要归属到某个工作区，请在该工作区页点「新建对话」，或点侧栏该工作区行右侧的 ＋。

**Q：上传到工作区的文件，助手为什么找不到？**
看文件栏顶部的提示：未开启「共用目录」时，就地按提示打开即可（新建的工作区默认是开的）；已开启仍看不到，是管理员在系统设置关闭了总闸，需要找管理员处理。

**Q：归档还是删除？**
归档是收尾：工作区收进折叠区，会话、文件、产物全部保持不动，文件仍可查看下载与预览，只是不能再写入，随时可恢复。删除会解除归属，工作目录中的文件不再有界面入口，约定一并丢失；删除对话框提供「保留文件」与「连工作目录文件一起删除」两种处置，都不可撤销。

## 知识库与文档

**Q：上传支持哪些格式？解析失败怎么办？**
docx / pdf / xlsx / ppt / pptx / txt / md / csv 与网页 URL。失败时查看文档列表中的失败原因：文件损坏或加密、超大截断、视觉模型不可用（扫描件 OCR 需要）等，修复后点「重解析」。

**Q：改了知识库的分块参数，为什么存量文档没变化？**
库级解析参数只对其后解析或重解析的文档生效，需对存量文档手动重解析。

**Q：换绑向量模型会怎样？**
触发该库全量重嵌入（与块数成正比），期间向量检索降级为关键词路。避免在业务高峰操作。

**Q：为什么我的知识库别人搜不到？**
未配置共享即私有；检索可见性要求「库允许」且「文档允许」。需要共享时在库或文档的「共享范围」中配置。

**Q：文档删了还能找回吗？**
能。删除的文档进回收站，内容保留期内可单条或批量恢复；「彻底删除」与清空回收站不可恢复。

**Q：《问渠使用手册》这个库为什么不能编辑、删除或上传？**
它是官方内置库：内容随安装包分发、全员只读。需要助手使用该库，在智能体的知识库范围中勾选即可。版本升级后由管理员在帮助中心点「同步官方手册」写入新版——内容未变化的篇目自动跳过，不产生模型调用。

## 智能体、工具与沙盒

**Q：工具或沙盒开关打开了还是不执行？**
确认两级都已开启：系统设置「工具调用」的问渠工具总开关 + 对应子开关（沙盒另有 provisioner 连接与访问令牌配置）。再检查该智能体的能力开关与权限档位——「只读调研」档下命令执行与文件写入根本不进入工具表。

**Q：联网搜索的结果，为什么有的没列为引用？**
搜索返回的网页按本轮问题重排后再过相关性阈值（与知识库同一口径），低于阈值的不列为引用、不交给模型——服务商自带的相关度分（如位置衰减）不具相关性含义，不参与判定。重排不可用时会提示「本轮搜索结果未经相关性过滤」，此时保留未过滤的结果，而不是因一次瞬时故障导致什么都搜不到。

**Q：工具执行前弹出确认卡是什么机制？**
有副作用的沙盒与 MCP 工具可配置「执行前确认」：批准 / 拒绝，超时按拒绝处理，防止误操作。留空即跟随权限档位。

**Q：沙盒脚本里调不到任何工具？**
检查回调地址 `SANDBOX_CALLBACK_BASE_URL` 是否配置为容器可访问的本服务地址。未配置时脚本内调不到任何工具，并直接提示「回调地址未配置」。另外脚本模块只包含本轮实际挂载的取数与计算类工具——沙盒文件读写、列目录、查找文件与交付产物不在其中，脚本内也不提供再执行命令行。

**Q：MCP Server 连不上？**
按三层排查：核对配置 → 用 curl 直接向端点发 initialize 请求（带 `Accept: application/json, text/event-stream`）→ 查看服务端日志中的异常根因（初始化与 tools/list 串行，超时按两个请求计）。本地进程（stdio）型条目不会被 JSON 导入接受，问渠只接入 http(s) 地址型服务。

**Q：技能装不上、或从 URL 安装没有反应？**
从 URL 安装需要管理员先在「系统设置 → 工具调用 → 技能 → 允许远程安装的域名」登记域名，且地址要指向 `SKILL.md` 原文；zip 安装会逐条目校验路径穿越、体积与条目数，同名时需确认覆盖。

**Q：市场里点「安装」后，为什么提示知识库或 MCP 被剔除？**
安装是复制成安装者自己的资产，引用会按安装人的权限裁剪：不可读的知识库剔除（全数剔除时检索回落默认知识库）、未登记的同名 MCP 剔除、缺装的技能保留引用并提示去技能市场装上。子智能体委派关系不随模板走。

**Q：市场条目显示「有更新」是怎么判定的？**
按快照内容自动判定：作者重新上架且内容有变化时装过的人会看到提示；只改市场卡片上的简介或标签不会误报。已安装的副本不受作者改版、下架与删除影响。

## 通知与可感知

**Q：解析跑完了、工作流失败了、问答的一轮跑完了，我怎么知道？**
这些事件会写入站内通知（铃铛）。若某一类没有提示，先在通知中心确认未被静音，再看该类事件是否确实产生（例如文档仍在队列中排队）。定时任务与工作流也都有各自的执行记录页。

**Q：我随口问的一句也回了通知，能不能只留长任务？**
问答轮次只报跑得久的：默认机器耗时满 60 秒才报「跑完了」，短问答当场就在屏幕上，不额外钉一条。门槛与整类开关在系统设置「定时任务 → 站内通知」。不受门槛约束的只有三类——这一轮没跑成或提前停了、卡片在等你拍板、目标跑到头。

**Q：手机上离开页面，这一轮还在跑吗？跑完了会通知我吗？**
会。断线、切后台、锁屏都不中止本轮，跑完或跑挂都会给这条会话的归属人发通知，点开就是那条会话；卡片还挂着等你的，通知会说清在等什么。个人设备上的推送通知（Web Push）尚未接入，手机靠铃铛的未读计数。

**Q：静音某类通知会丢消息吗？**
不会。静音只影响本人是否再接收该类通知，通知仍会生成，可在通知中心按类型查看。

## 管理与运维

**Q：登录后一直跳回登录页？**
`AI_JWT_SECRET` 未固定，服务重启后旧令牌全部失效。设置为固定值（≥32 位）即可，多副本必须一致。

**Q：启动直接失败？**
先检查 `DB_PASSWORD`——必填项缺失会启动即失败；再确认数据库与 Redis Stack 的连通性（框架会话状态依赖 Redis，连不上时不会降级启动）。

**Q：设置页改的参数什么时候生效？**
多数保存即生效；解析类参数需重解析或新上传；`vision.timeoutMillis`、工作流并发与排队容量、目标模式 worker 数需重启。详见《系统配置说明》。

**Q：保存设置时报「这些项系统不认」，结果一个参数都没改，为什么？**
提交项中存在 schema 未定义的键（通常是页面版本比后端旧，或该项已改名、取消）。此时整笔不保存，而不是先写入可识别的项再报成功——否则界面显示「已保存」而实际未生效。刷新设置页重新修改即可。

**Q：回答下面那行黄色提示（本轮降级说明）刷新后还在吗？**
在。它随该条回答一起留存，回看历史时同样能看到「未检索到资料 / 未咨询到其他助手 / 回答被截断」这类事实。是否显示这些提示由「调试设置 → 检索调试入口」统一管理，关闭时回答区不显示任何降级提示。

**Q：怎么评估和优化检索质量？**
检索评估页从历史问答生成评估集，多参数组对比 recall@k / MRR，并可另跑答案质量评测（忠实度与相关性）；`POST /api/ai/debug/retrieval` 分步调试；数据看板有热门与无命中问题、差评回流与知识缺口补块；「执行 Trace」与采样池把线上真实问答回流成评测集。
