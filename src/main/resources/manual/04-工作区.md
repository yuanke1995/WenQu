# 工作区

工作区把一件事相关的对话、文件与产物收在一起：**你电脑上的一个或多个真实文件夹 + 一份约定 + 一位默认助手**。文件只存在于你自己的电脑，问渠服务器只记「哪台电脑、哪些目录」；读写由那台电脑上的本机执行器完成，服务器不保存副本。

## 侧栏两栏的划分

- **会话**：未归属任何工作区的对话。顶部「新建对话」创建的对话默认在此
- **工作区**：用户自建的工作区，各自包含自己的对话。点工作区名展开或收起其下的对话；该区右上角的 ＋ 用于新建工作区

一条对话只归属一处。两栏各自记住折叠状态，搜索时全部展开。归档的工作区收在「已归档」折叠区。

**侧栏只列出这台电脑绑定的工作区**：工作区绑定在创建时选定的那台执行器上，同一账号在别的电脑上建的工作区不会出现在这一栏，数据也不会删除——换到那台电脑登录即可看到。没绑定执行器的旧工作区仍会列出，它们不读写任何电脑上的文件。本机设备由启动脚本（本地开发态）或首次授权确定，认出来之后界面不能把它改成别的电脑。点工作区栏的「这台电脑」只查看当前设备与在线状态；设备被撤销后会自动要求重新选一次。线上页面没有启动脚本注入，首次使用需要选一次，选择记在当前浏览器里。新建工作区固定建在这台电脑上，不再挑设备；要给另一台电脑建工作区，先切换「这台电脑」，或到那台电脑的页面里建。

打开别的电脑工作区里的旧会话时，历史照常可读，但这台电脑不能继续在其中发问，聊天页会提示文件夹在另一台电脑上。

## 新建工作区

在侧栏「工作区」区点 ＋，或者在没点选择工作区时点「新建工作区」：先在**源文件夹**里点「添加」，在这台电脑上弹出系统目录选择框，选中的文件夹会成为工作区的一个源目录；可以继续添加多个。第一个是**主目录**（命令执行与相对路径的基准），后面的都是附加目录。给工作区起名、选图标与颜色后创建。

- 源文件夹必须是这台电脑上的绝对路径；同一个文件夹不能重复添加
- 源文件夹全部来自这台电脑的执行器；一个工作区不跨机器
- 保存后侧栏出现该工作区；工作区页的设置面板里可以继续增删文件夹、换图标与颜色

还没指定这台电脑时，弹窗给出「选择这台电脑」；本机执行器不在线时会提示去终端启动 `wenqu-agent`，此时不能添加源文件夹，也不能创建工作区。

## 工作区页的内容

- **页头**：图标 + 名称 + 「本机目录」标识。点「改名」就地修改名称；点「助手 跟随我的 · 设置」打开设置面板
- **设置面板**：默认助手、工作区资料（默认检索域）、记忆隔离、**源文件夹**（增删、主目录、复制路径）、**外观**（图标与颜色）、归档与删除
- **轮次占用提示**：有对话正在该工作区执行时，页头下方给出「某某 正在此工作区运行 · 已跑 N」与「去看」入口。本机目录同一时间只让一轮在跑，避免两轮同时改同一批文件
- **文件**：列出源文件夹里的真实文件；顶层每一项就是一个源文件夹，默认只展开这一层，更深的文件夹点开时才读取，目录行显示的是该层条目数。上传、新建文件夹、重命名、移动、删除、下载、预览与打包导出都直接作用在你的电脑上（经执行器完成），不是服务器上的一份副本
  - 不显示隐藏文件（点开头、`node_modules`、`__pycache__`），新建与上传也不允许取这类名字
  - 上传单文件上限由管理员设置；重名默认不覆盖，要替换需勾选「重名时覆盖」
  - 打包导出是整个工作区一次打包，超过 2000 个文件或合计 100 MB 时按钮不可用；工具条上的「上传 / 新建文件夹」落在主源文件夹，要放进某个子文件夹用该行 ⋯ 菜单里的动作
  - 删除文件夹会连同其中内容一起删除；工作区有轮次在跑时不允许改名/移动/删除
  - 工作区归档后仍可查看、下载与预览，但不能再上传、改名或删除
- **会话 / 自动化 / 动态 / 事项**：与之前一致——归属本区的对话、定时任务与工作流、合流时间线、待办清单

## 每轮文件改动

在本机工作区里跑的每一轮问答结束时，界面会给出一张「N 个文件已更改 +X −Y」卡片，列出这一轮被改动的文件与各自的增删行数。点开某个文件能看到两版差异；卡片随回答一起留存，刷新后仍在。

工作机制与边界：

- 识别靠 git：源文件夹是 git 仓库（或仓库的一部分）时，问答开始和结束时各给工作树拍一份快照再对比——**你的仓库全程只读**，暂存区、分支、提交一概不动；快照写的是平台自带的临时副本。
- 不在 git 仓库里的源文件夹走兜底：助手用文件工具改动某个文件前，先在本机留存一份原文，轮末对比。这类目录只有「助手用文件工具写的」能被记录，命令行里的改动（`rm`、脚本重写等）盖不到。
- 文件内容不出你的电脑：快照与留底都在那台电脑的磁盘上（默认 `~/.wenqu/executor/turns`），服务器只收到「相对路径 + 行数」；点开差异时由你电脑现算并回传少量改动文本。
- 快照默认保留 14 天（最多 200 轮、总容量 2GB，先到先清）：执行器重启后仍能打开保留期内的差异；过期清理后点旧卡片会提示「改动详情已过期或不存在」。可在启动执行器时用 `--data-dir` / `--turn-ttl-days` / `--turn-max` / `--turn-cache-max-mb` 调整。
- 被本机 `.gitignore` 忽略的文件、超过 2MB 的单个文件、二进制文件：git 快照盖得到的照常计数；盖不到的只列名字不给差异。
- 执行器离线或没装 git 的轮次不出卡片，也不报错——这是记录功能，不该挡住干活。
- 这张卡只做记录，**不做撤销**：撤销会把你自己的未提交改动一起冲掉，需要回退请用 git 或 IDE。

## 权限：会话能对这些目录做什么

输入框工具条最左侧有一个权限选择器，**只对当前会话生效**，可以随时切换：

| 档位 | 含义 |
|---|---|
| 仅可查看 | 能读文件、列目录；不能写/改/删、不能执行命令、不交付产物、不联网与外部工具 |
| 工作区内修改 | 能在这些源文件夹内读写、改文件、跑命令；写到文件夹之外会被拒绝 |
| 完全权限 | 不再把路径收束在源文件夹内，命令直接执行、不再逐项确认 |

选「完全权限」会先弹一次风险确认，勾选「我已了解风险」后才生效；生效后工具条上的权限胶囊变红显示「完全访问」。新会话默认「跟随智能体」，即在智能体配置里选的档位；管理员仍可用平台上限收口，游客会话无论选什么都按只读执行。

本机执行器只执行服务端下发的动作，并在自己的进程里再校验一次路径：即使服务端算错，也落不到源文件夹之外。默认不在终端逐次确认（否则浏览器里的这一轮会一直等不到返回）；需要终端逐次确认时，以 `--ask` 启动执行器。

## 约定的写法

约定描述「这里的规矩」，不是「这次的任务」。适合写：回答要带什么依据、口径以哪份材料为准、哪些情况不允许推测。保存后即对**该工作区里的所有对话**生效，包括以后新建的。

## 默认助手

未设置时跟随平台默认智能体。设置后，该工作区里的对话默认使用它——其知识范围与工具一并生效。某条对话临时更换助手，只影响该条。

## 工作区资料（默认检索域）

设置面板里可把若干知识库绑定为这个工作区的**资料域**：绑定后，该工作区里的对话在没有点名别的库（`@` 知识库）、所使用的助手也没有绑定知识库时，检索只搜这些库。`@` 某个别的库或换用带绑定库的助手，都按当轮的显式选择走，不受默认域限制。不绑定则检索沿用你全部知识库的原有口径。

## 记忆隔离

「记忆隔离」开关默认关闭：该工作区的对话照常使用本人的个人记忆。开启后，本区对话**既不读取也不写入**个人记忆，上下文全靠约定、资料域与目录中的文件；适用于敏感项目或客户现场。改动对之后新开的轮次生效。

## 工作区记忆

工作区记忆是**只属于这个工作区**的一层长期记忆，与个人记忆相互独立、互不影响（不受「记忆隔离」开关控制）。它存于工作区根目录下的 `.wenqu/MEMORY.md`（在那台绑定电脑上），随工作区文件一起走，不进服务器记忆目录。

- **自动读取**：进入本工作区的对话，每轮会自动读这份文件并作为上下文注入，模型据此参考该项目的稳定事实。
- **自动沉淀**：模型在对话中学到的、对今后在本工作区工作有价值的项目事实（约定、决策、结构、坑、偏好），会用文件编辑工具写回 `.wenqu/MEMORY.md`；不要写入临时性或一次性的内容。
- **手动维护**：工作区设置面板的「工作区记忆」可查看 / 编辑这份文件，保存即经执行器写回那台电脑。
- 没有绑定本机目录、文件不存在或执行器离线时，这部分上下文自动缺省，不影响对话。

## 约定改动历史

约定每次被修改或清空时，被替换掉的旧版会自动留痕。约定卡上的「历史」可查看最近 20 版（含「当时约定为空」的状态），每版可一键恢复——恢复即以该版本重新保存一次，当前版本同时留痕，历史始终完整可回溯。

## 工作区事项

「事项」栏记这个工作区里要做的事：想到就填一行，回车添加；做完勾掉，勾掉的收进「已完成」分组（记录完成时刻，可再取消）。每条未完成事项右侧有「去聊」——点它会新建一条归属本工作区的对话，并把事项内容预填进输入框，**不会自动发送**：发给模型前可以改写措辞。动态栏顶部的「接下来」会给出建议：没做完的事项、上次聊到哪、哪次运行失败了、下一趟定时任务什么时候。

## 定时任务与工作流

- **定时任务**在工作区页直接创建：填写任务名、每轮发给智能体的指令、cron，创建后按计划自动执行，结果落进该工作区的会话里
- **工作流**在「智能体 → 工作流」中编排；保存时在画布顶部把**归属**选为该工作区，该工作流即出现在此处的「自动化」栏

## 归档还是删除

**归档**用于收尾一个工作区：工作区收进侧栏的折叠区，会话、文件、产物全部保持不动，随时可恢复。归档期间该栏仍可查看、下载与预览，但不能再上传文件，也不能改名或删除——表示这里的资料已定稿。

**删除**只解除服务器上的归属关系：其下对话与产物仍然保留（回到「会话」），**你电脑上的源文件夹与文件一个都不动**。问渠没有「连本机文件一起删」这个选项。

## 常见问题

**为什么有的工作区不在这台电脑上？** 侧栏只显示这台电脑绑定的工作区，别的电脑上建的仍保留，到那台电脑登录即可看到。重新授权后旧执行器被撤销时，页面会自动清掉旧身份并要求重选一次当前设备。

**为什么新建的对话没进工作区？** 顶部「新建对话」创建的是不挂归属的对话，落在「会话」栏。要归属到某个工作区，请在该工作区页点「新建对话」，或点该工作区行右侧的 ＋。

**文件在哪里？** 就在你创建时选的那些文件夹里；按设置面板「复制主目录」或直接在 Finder/资源管理器里打开即可。问渠不搬家、不备份这些文件。

**执行器离线了会怎样？** 聊天页会给出「本机执行器不在线」；去那台电脑上启动 `wenqu-agent` 后刷新即可。离线期间不会静默改回服务器执行，避免文件出现两份。离线的那一轮也不会有「每轮文件改动」卡片（见上节）。

**为什么有的轮没有改动卡片？** 可能是：执行器离线、那台电脑没装 git 且改动是命令行做的、这一轮确实没改任何文件、或者不是本机工作区的会话。卡片只做记录，缺了不代表改没发生——拿不准时用 `git status` 对一下。

**能跨源文件夹移动文件吗？** 不能。不同源文件夹是不同目录，跨目录请先下载再上传；同一个源文件夹内的移动/改名正常。
