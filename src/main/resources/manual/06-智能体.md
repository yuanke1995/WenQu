# 智能体

智能体工作台包含六个 Tab：模型供应商 · 智能体 · 技能 Skills · MCP 外部工具 · 定时任务 · 工作流。其中技能与 MCP 由每个人各自管理。

> 智能体与工具能力默认全局关闭（`agent.enabled`、`tool.*`），需管理员在系统设置显式开启。

## 配置一个智能体

- **模型引用**：问答模型 + 可选的个人默认模型（选择器里只出现你有权使用的）
- **System Prompt**：人设与回答风格；引用/图片/追问等规则由系统固定注入，不占这里
- **知识库范围**：勾选该智能体能看到的库（含官方内置的《问渠使用手册》——勾上它就成了问渠使用顾问）；绑定了库时，智能体的检索与工具检索都不允许越过该范围
- **能力开关**：深度思考、工具调用、沙盒、@ 引用等
- **MCP / 技能**：挂载外部工具与技能包
- **委派关系**：把其他智能体设为子智能体，构成编排

## 会话级绑定

对话时智能体在**会话首问锁定**，全程同一人设/知识库/工具集；切换智能体请新建会话。「自动派遣」开启时由模型在首问从可用智能体中路由（挑选理由随流式下发并可解释），失败回落默认智能体并标注。

## 多智能体并行编排

- 主智能体可把复杂问题**并行委派**给多个子智能体：各自检索+提炼，汇总节点合并
- **按需委派路由**：主模型先从候选子智能体中挑出相关者，未选中的不跑，挑选理由随 SSE 下发；可开「委派收窄检索范围」
- **聚合策略可配**：`concat` 直拼 / `rerank` 按重排分降序合并 / `supervisor` 监督者二次聚合（LLM 去重合并、矛盾显式标注）；失败分支显式占位，模型可声明「资料不足」
- 编排卡片实时展示各分支状态、要点、耗时占比与路由理由

## 公开发布

智能体卡片可公开发布：生成 `/s/{token}` 免登录链接与 iframe 嵌入代码。游客对话工具收窄为知识检索 + 内置项，不泄露内部工具与私人数据；停用/撤销立即失效。

## 定时执行

智能体可按 cron（6 段）或固定间隔自动执行，执行历史与结果在会话留痕。调度中心先推进 next_run_at 再执行（单实例防重复），同任务串行防重叠；任务间隔可设 0 暂停。

## 工具执行确认

沙盒/MCP 类有副作用工具可按智能体配置「执行前确认」（人在回路：批准/拒绝，超时按拒绝）或「禁用」（不给模型这两类工具）。联网搜索默认自动执行；管理员在系统设置开启其「纳入执行审批」后，同样受「执行前确认」管辖（「禁用」不影响联网搜索的启停）。审批卡会随流式对话弹出，批准后继续执行。

## 智能体向你提问

问题没说清时，智能体会先出一张提问卡（每题最多 3 个候选，也可自己写答案），你作答后它才继续。默认等你 10 分钟（系统设置「对话」页的「提问等待」可调）。这期间关掉页面、换设备都不影响这一轮：重新进入这个会话，卡片还在原处，接着答就行；不在会话页时铃铛也会提示「智能体提问待答」。

超时或点「忽略」都**不会替你选答案**——智能体只会知道「这一题你没回答」，然后基于已有信息继续，或把候选写进正文再问你一次。想要它按某个方向推进，最好直接答一句，或点候选里的「（推荐）」项。
