# 智能体

智能体工作台包含六个 Tab：模型供应商 · 智能体 · 技能 Skills · MCP 外部工具 · 定时任务 · 工作流。其中技能与 MCP 由每个人各自管理。

> 智能体与工具能力默认全局关闭（`agent.enabled`、`tool.*`），需管理员在系统设置显式开启。

## 配置一个智能体

- **模型引用**：问答模型 + 可选的个人默认模型（选择器里只出现你有权使用的）
- **System Prompt**：人设与回答风格；引用/图片/追问等规则由系统固定注入，不占这里
- **知识库范围**：勾选这位助手管哪些库（含官方内置的《问渠使用手册》——勾上它就成了问渠使用顾问）。**P5 起这一项定义的是它「被派去查」时的资料域**：对话页直接问的那一轮会查遍你读得到的全部库，把某一问派给这位助手时，它只在自己勾选的库里查
- **能力开关**：深度思考、工具调用、沙盒、@ 引用等
- **MCP / 技能**：挂载外部工具与技能包
- **委派关系**：把其他智能体设为子智能体，构成编排

## 谁来答这一问

对话页不再需要「先选一个人」：不挑就用默认助手，挑了从下一问起立即生效，**换人不用新建会话**。

跨主题的问题由模型自己分工——它手上没有对应资料、而某位助手的职责范围明显对得上时，会把那一问**派给那位助手去查**（`consultAgent`）：对方带着自己勾选的知识库跑一条完整子轮，把结论和可点开的引用交回来，回答仍由当前助手汇总。一轮最多派几位、单次等多久都在「系统设置 → 智能体」里可调；免登录分享页与被派出去的助手本身不再继续往外派。

交回的资料要再过**你这一轮问题**的相关度门与引用配额才进引用面板——子轮的门是子轮问题的门，管不了父轮面板，两边同一把尺才不会出现「子轮觉得相关、你眼前全是无关块」。没过的条数会如实告诉模型「另有 N 处未通过校验」，模型不会在正文里引用它们。

派出去查过的助手会写在回答上方那条「本轮已咨询 …」里，刷新后仍在——好答案要看得见是谁查的，派错了也才知道该去改谁的职责描述。

整天只跟某一位助手聊的话，在「个人设置 → 对话偏好」里把它设成**默认助手**：没挑助手时由它答，换人仍在对话页即时生效。它被删除或不再共享给你时，问答会明确说一句再改用平台默认智能体。

## 多智能体并行编排

- 主智能体可把复杂问题**并行委派**给多个子智能体，各按自己的知识库范围与角色视角处理，再汇总作答
- **被委派时怎么做**（在子智能体自己的配置页「能力」里选，留空跟随系统默认）：
  - **检索要点**：它只查资料、把要点交回来，快也省，它自己的工具、技能、沙盒都不参与；
  - **全循环**：它像一次完整对话那样把这件事办完——用自己的知识库查、用自己的工具与沙盒做，
    能写出文件并交付给你。代价是每派一次就等于跑一轮问答，更慢也更花费，所以按角色逐个开。
  编排卡片会标出哪一支是全循环、它跑了几步工具、交付了什么。
- 全循环那一支**跑着的时候就能看它在做什么**：展开那一支，能看到它正在执行的每一步（正在检索、正在生成、某次查资料在跑或跑完用了多久）；被单轮步数上限挡下的那几次也会列出来，耗时显示得极短——"它只试了几次"与"它试了很多次都没查到"是两种看得出来的形状。这串实时步骤不随消息保存，跑完留下的是它的步数和它交回的全文
- 被委派的那一支不会向你提问，也不会建任务清单：缺信息时它按资料里最合理的做法完成，并把假设写进结论。
  它交付的产物、它引用的资料都归到当前这轮对话里，照常能点开看来源。
- **按需委派路由**：主模型先从候选子智能体中挑出相关者，未选中的不跑，挑选理由随 SSE 下发；可开「委派收窄检索范围」
- **聚合策略可配**：`concat` 直拼 / `rerank` 按重排分降序合并 / `supervisor` 监督者二次聚合（LLM 去重合并、矛盾显式标注）；失败分支显式占位，模型可声明「资料不足」
- **给分支带多少前情**（系统设置 → 智能体与沙盒）：默认只带最近几句，与你不认识这个选项时完全一样；如果委派时反复出现「我上面说的那张表 / 按刚才那个口径」而它答不上来，再放开到「最近几轮」或「尽量带全」。代价是每派一支都要把这些字带进它的上下文，多支并行按支数乘，带太多还会挤掉那一支自己查资料的部分
- 并行条数、单支等待上限、往下再派几层，同在「智能体与沙盒」里调
- 编排卡片实时展示各分支状态、要点、耗时占比与路由理由；全循环那一支还能点开看**它交回的全文**（列表里那一行只是摘要）
- 想看清一次委派到底花了多少：「使用统计」页新增的**这些用量花在什么地方**按用途分开记账——对话问答、子智能体分支、深度思考、检索词改写、历史压缩、引用自检等各有自己的额度，分支那一行就是被派出去的那些轮

## 公开发布

智能体卡片可公开发布：生成 `/s/{token}` 免登录链接与 iframe 嵌入代码。游客对话工具收窄为知识检索 + 内置项，不泄露内部工具与私人数据；停用/撤销立即失效。

## 定时执行

智能体可按 cron（6 段）或固定间隔自动执行，执行历史与结果在会话留痕。调度中心先推进 next_run_at 再执行（单实例防重复），同任务串行防重叠；任务间隔可设 0 暂停。

## 工具执行确认

沙盒/MCP 类有副作用工具可按智能体配置「执行前确认」（人在回路：批准/拒绝，超时按拒绝）或「禁用」（不给模型这两类工具）。联网搜索默认自动执行；管理员在系统设置开启其「纳入执行审批」后，同样受「执行前确认」管辖（「禁用」不影响联网搜索的启停）。审批卡会随流式对话弹出，批准后继续执行。

## 智能体向你提问

问题没说清时，智能体会先出一张提问卡（每题最多 3 个候选，也可自己写答案），你作答后它才继续。默认等你 10 分钟（系统设置「对话」页的「提问等待」可调）。这期间关掉页面、换设备都不影响这一轮：重新进入这个会话，卡片还在原处，接着答就行；不在会话页时铃铛也会提示「智能体提问待答」。

超时或点「忽略」都**不会替你选答案**——智能体只会知道「这一题你没回答」，然后基于已有信息继续，或把候选写进正文再问你一次。想要它按某个方向推进，最好直接答一句，或点候选里的「（推荐）」项。
