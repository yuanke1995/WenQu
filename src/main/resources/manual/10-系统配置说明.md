# 系统配置说明

行为参数统一在「系统设置」页维护（存 `c_ai_config`，保存即生效），**不走环境变量**；环境相关值（数据库、Redis、密钥路径等）走环境变量/yml。两类配置的边界见下。

## 配置语义

- 设置项 schema 唯一定义源是 `config-schema.json`（后端据此校验 + 下发前端渲染设置页）
- **敏感项按后缀判定**（`.apiKey` / `.clientSecret` / `.token`）：RSA 加密入库，页面仅回显 `****后4位`，「恢复默认」会跳过敏感项
- 多副本部署时动态配置经 Redis pub/sub 广播即时生效，另有 5 分钟兜底轮询
- 「恢复分组默认」把该组恢复为出厂默认值

## 16 个分组速览

| 分组 | 关键内容 |
|------|----------|
| 对话模型 | 供应商与模型登记、引用自检、相关建议条数、并发与超时、消息图片限制 |
| 图片描述（视觉） | 视觉开关、提示词、并发、超时重试、描述缓存、图片相关性校验；视觉模型按知识库 visionRef 绑定 |
| 文档解析默认模板 | 分块大小/重叠、结构感知切分、图片处理、上传大小上限；各库可在知识库设置覆盖 |
| 检索设置 | 关键词引擎（mysql/meilisearch）、融合权重与阈值、查询改写、意图分类、关联扩散、重排 |
| 上下文与长度控制 | 历史裁剪、命中片段窗口、知识块填充与去冗余（窗口/最大输出已按模型在模型管理中声明） |
| 深度思考 | 思考模式、检索计划、多路与超时、思考护栏与自动路由 |
| 工具调用 | 工具总开关与子开关（**默认全关**）、知识检索工具、产物交付、沙盒执行 |
| 联网搜索 | 服务商与连接、检索行为与配额（结果进引用体系） |
| 技能 Skills | 技能开关、目录、注入开关、远程安装域白名单 |
| 并行检索 | 未配置子智能体时的默认并行策略 |
| 接口限流 | 问答/上传按用户（无身份按 IP）Redis 固定窗口限频 |
| 定时任务 | 索引对账、自动体检、会话/图片/产物清理、解析队列并发与重试、网页刷新、工作流治理 |
| 单点登录 OIDC | issuer/clientId/clientSecret/scopes/frontendBaseUrl 等 20 项 |
| 沙盒 | provisioner 连接、访问令牌（敏感）、执行限额、空闲回收 |
| 用户长期记忆 | 总开关、条数上限、注入预算、去重阈值（向量化模型为个人设置项） |
| MCP 服务（双向） | 服务端开关、超时、允许来源（空=仅本机回环） |

## 个人可覆盖的参数（个人设置 → 聊天模型与偏好）

以下参数在本页是平台默认值，每个人可在「个人设置 → 聊天模型与偏好」里覆盖，仅对自己的问答生效（跨设备同步、保存即生效）：

| 参数 | 说明 |
|------|------|
| 相关建议条数 | 回答末尾 <related> 下一步建议的条数（追问/深入方向/可执行操作混合） |
| 深度思考默认开启 | 对话页深度思考开关的初始状态（按模型的手动切换仍记在本机浏览器） |
| 启用重排 | 重排的个人默认开关（平台开关的覆盖；知识库/智能体单独设置时以其为准） |
| 默认重排模型 | 你的库未单独配置重排模型时生效；清空回落平台内置重排服务 |
| 记忆向量化模型 | 你本人记忆的语义去重/注入所用向量模型；留空则回落「平台内置向量化模型」(管理员统一托管)，再无则降级为精确匹配去重/关闭语义注入 |
| 平台内置向量化模型 | 管理员统一托管的向量化模型（用平台自己的 Key），作为全体用户记忆语义能力的兜底——用户无需自备向量模型即可获得语义记忆 |
| 问答对生成模型 | 解析你本人知识库文档时生成问答对所用模型（按库主身份调用） |

个人设置里留空或点「全部清除个人设置」= 清除该覆盖、回落全局（模型类项清除后回落平台内置服务/降级）。

**模型默认（重排/记忆向量/问答对生成）是个人设置项**：模型都归登记人（谁建供应商/模型归谁），没有平台全局槽位，只能在个人设置里选自己登记的模型，且按使用身份生效（问答按提问者、解析/抽取按库主）。管理员在系统设置里也不能把这些模型配成全平台默认——避免"把某人的模型用成所有人的默认"。向量模型仍归**知识库绑定**（向量空间与库索引一一对应），聊天/视觉默认模型在个人设置上方面板。GraphRAG 抽取模型归**知识库绑定**（知识库编辑里选择）；库未绑定时回落库主的个人默认聊天模型，两者皆空则不抽取。

## 生效时机（易踩坑）

- **需重解析/新上传才生效**：`chunk.maxSize`、结构感知切分、标题层级等解析参数——它们只影响之后的解析，存量文档需手动重解析
- **需重启**：`vision.timeoutMillis`（视觉客户端启动时构建）
- **其余保存即生效**：检索、重排、上下文、工具、限流、记忆等绝大多数项
- 切换**向量模型**必然触发全量重嵌入（与知识块数成正比，万级块可达数十分钟），期间向量检索降级关键词路、语义缓存清空，避免业务高峰操作
