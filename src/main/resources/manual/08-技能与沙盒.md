# 技能包与沙盒

## 技能包（Skills）

技能是「目录 + SKILL.md」形式的可插拔能力，支持：

- 新建 / URL 安装（远程域白名单）/ 启停用 / 删除
- 注入 System Prompt，或由模型按需渐进读取（先读目录再读正文，省 token）
- 按用户隔离，各自管理；沙盒内以只读投影暴露给容器

内置技能随版本提供（深度研究 deep-research、HTML 预览 html-preview、图片生成 image-gen、知识库问答 knowledge-base、MySQL 报表 mysql-reporter 等），在「智能体 → 技能 Skills」查看与启用。

> 技能开关 `skill.enabled` 默认关，需在系统设置显式开启。

## 沙盒隔离执行

模型经 Function Calling 在隔离 Linux 容器内获得 6 个工具：

| 工具 | 说明 |
|------|------|
| execute | 执行 shell 命令，**输出实时流式回传**（边跑边看） |
| read_file / write_file | 读文件 / 写文件（无则新建、有则整体替换；局部修改用 edit_file） |
| edit_file | 精确替换修改 |
| ls | 浏览目录 |
| deliver_artifact | 把文件交付为「我的产物」 |

- **scope 挂会话**：同会话文件跨轮保留，按用户隔离工作目录；会话空闲（默认 60 分钟）自动回收容器
- 命令超时/输出上限/keepalive 均可配；瞬时故障自动重试
- 对话右栏「沙盒」卡可浏览/下载工作区文件
- 产物在「我的产物」页（/artifacts）汇总：预览、下载（签名 URL）、删除；交付文件按扩展名白名单净化，单个 ≤1MB

> 沙盒开关 `tool.sandbox.enabled` 默认关；启用需部署 sandbox provisioner 并在系统设置「沙盒」面板配好连接与访问令牌（令牌须与 provisioner 侧一致且 ≥32 字符）。

## 内置工具

计算器（递归下降表达式求值，仅四则/幂/括号，**不执行任意代码**）、日期、知识检索（命中块进引用流）、产物交付、技能读取。全部工具开关集中在 `tool.*`，**默认均为 false**。
