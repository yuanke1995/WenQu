# 技能包与沙盒

## 技能包（Skills）

技能是「目录 + SKILL.md」形式的可插拔能力：一段写好的做法说明，模型照着做。以前那个「技能面板」（新建 / 从 URL 安装 / 启停用 / 删除）已经取消，**写**这件事交给了助手，**读**的这一侧因此做得更可查——技能正文是逐字带进这一轮提问里的，你该看得到它写了什么。

三类来源，同名时后面那类覆盖前面那类：

| 标在清单上的名字 | 从哪来 | 谁能改 |
|---|---|---|
| 内置 | 随版本分发，所有人都有 | 改不了（要改请让管理员改这一版的内容） |
| 我的 | 你名下的技能目录 | 在对话里让助手改 |
| 工作区 | 助手在对话里把做过的做法沉淀下来的那几条，存在沙盒工作区里 | 在对话里让助手改或删 |

- 每一轮问答，模型都会先看到「有哪些技能、各自管什么」的清单，需要时才去读正文（先列目录再读全文，不一次塞满上下文）
- 你在输入框的「+」里点名某几条技能时，那一轮会把这几条的正文直接带上，等于明确交代「照这个做法做」
- **看正文**：输入框「+」→ 技能 → 那条右边的「查看正文」；智能体配置页选了「指定」技能之后，下面有「已选正文」可直接点。这里显示的就是模型真正吃到的那份内容
- **不再用某条**：在「查看正文」里点「这条别再用了」即可（也可以到 个人设置 → 回答偏好 里那一项统一维护）。停用后下一问起它不再进模型的清单；想临时用一次，仍然可以点名带上。想恢复就点「恢复使用」
- 「工作区」那一路只给看、不给点名，也不吃「停用」——它随会话走，要处理请在对话里说一声
- 沉淀技能需要沙盒可用；智能体的权限档位是「只读」时，助手不能新建也不能改写技能

按用户隔离：你名下的技能只对本人生效。

## 沙盒隔离执行

模型经 Function Calling 在隔离 Linux 容器内获得 8 个工具（开了「沙盒脚本」再加 1 个，见下）：

| 界面上的名字 | 说明 |
|------|------|
| 执行沙盒命令 | 执行 shell 命令，**输出实时流式回传**（边跑边看） |
| 读取沙盒文件 / 写入沙盒文件 | 读文件 / 写文件（无则新建、有则整体替换；局部修改用「编辑沙盒文件」） |
| 编辑沙盒文件 | 精确替换修改 |
| 查看沙盒目录 | 浏览目录 |
| 在沙盒里搜内容 | 按关键词跨很多文件一起找 |
| 按文件名模式找文件 | 按文件名规律找，比如「所有 .md」 |
| 交付沙盒产物 | 把文件交付为「我的产物」 |

### 沙盒脚本（一次做完一批同类活）

多开一个开关 `tool.runcode.enabled`（默认关）后，模型还能用第 7 个工具 **run_code**：它写一段脚本在沙盒里跑，脚本内部可以继续调用本轮已经挂上的工具。两种语言任选——Python（默认）与 JavaScript（Node）：Python 里写 `import wenqu_tools as wq`，JavaScript 里写 `const wq = require('./wenqu_tools')`。模块由系统按**本轮真实挂上的工具**当场生成，本轮没挂的工具，模块里就没有那个函数。

- **什么时候有用**：「把这 30 份文档逐一汇总」「每个库都查一遍再对比」这类活。不用脚本时这是一串来回，还会撞上单轮工具步数上限；用脚本时是一段程序扇出去，只把打印出来的结果带回对话。
- **它不是旁路**：脚本里的每一次调用与模型直接调用走同一套管控——本轮没挂的工具脚本也调不到；写到沙盒目录外面照样被拒；你中途点「停止本轮」，脚本剩下的调用就全断了（运行凭据当场作废）。
- **只有打印出来的内容会回到对话**（print / console.log，不是函数返回值），所以让它只打印结论与关键数字。要留给你的文件仍然要用「交付沙盒产物」交出来。
- 点开那张「运行脚本」的工具卡能看到**这次运行扇出了哪些调用**——每个的名字、耗时与结果开头一行。它们不各自占一张卡片，否则一次扇出就把过程区刷成一堵墙，也看不出这些属于同一次运行。
- **跑着的时候就是活的**：那张卡的标题旁边一跳一跳显示「子调用 N 次 · 在途 K」，展开能看到脚本自己的输出逐行滚出来、本轮额度用到哪了（如「本轮额度 12/50」）、并发上限是多少、以及它这一趟交回了几个文件。一段接一段地跑时，每张卡只算**那一段**自己的调用
- **没跑成的样子与跑成了不一样**：追踪超时（脚本可能还在沙盒里跑）、沙盒没通（不是脚本写错）、退出码非 0 会直接标在卡片上；正常跑完但一行都没打印也照旧说明只有打印才回得来。以前这几种全都显示成绿色对勾，要读一遍正文才知道脚本其实没跑完
- 额度分两摞：脚本自己的额度是「单次脚本子调用上限」（系统设置 → 工具调用），不占用模型的单轮工具步数——扇出几十次不会把后面真正需要工具的几步饿死。另有脚本运行上限、单次调用超时、脚本内并发上限三项在同处。
- 前提是系统设置「沙盒 → 平台回调地址」填的是**容器真能打到**的本服务地址（本机部署默认 `http://host.docker.internal:8090/ai`；生产跨网络时要换成容器侧可达的地址）。没配时脚本里调不到任何工具，会直接说明「回调地址未配置」。
- 「工具执行确认=执行前确认」时这个工具不提供：一次扇出会刷出同样多次的确认卡，人在第一张卡上并不能预见后面要做什么。要用脚本请先选自动执行。
- **脚本里能并发扇出的是「取资料与算数」这一类**：查知识库、联网搜索、算数、日期换算都可以，模块里有什么函数取决于本轮真正挂上了哪些工具；**沙盒的文件读写、看目录、搜文件与交付产物不在脚本模块里**（那几把由模型自己直接调用），**在脚本里再跑命令行也不提供**——实测那条路会有结果回不来的情况，表现是脚本停在某一次调用上直到超时。要跑命令行交给模型自己用「执行沙盒命令」那个工具，一样看得见实时输出

- **scope 挂会话**：容器与沙盒目录都以会话为界——同会话文件跨轮保留（容器回收重建后仍在），不同会话互相看不见；会话空闲（默认 60 分钟）自动回收容器
- 命令超时/输出上限/keepalive 均可配；瞬时故障自动重试
- 对话右栏「沙盒」卡可浏览/下载沙盒文件
- 产物在「我的产物」页（/artifacts）汇总：预览、下载（签名 URL）、删除；交付文件按扩展名白名单净化，单个 ≤1MB

> 沙盒开关 `tool.sandbox.enabled` 默认关；启用需部署 sandbox provisioner 并在系统设置「沙盒」面板配好连接与访问令牌（令牌须与 provisioner 侧一致且 ≥32 字符）。

## 权限档位

「智能体 → 工具与能力」里的**权限档位**决定这个智能体能改动多少东西（留空=跟随平台默认档）：

| 档位 | 实际表现 |
|------|----------|
| 只读调研 | 能读沙盒里已有的文件、列目录；**不执行命令、不写文件**——这两项它根本看不到，不是点了被拒；调用外部工具每次都要你确认 |
| 常规（默认） | 能跑命令、能在沙盒目录内读写文件；写到沙盒目录外会被拒绝 |
| 全自主 | 不再限制它写到哪，也不再逐项确认 |

- 只想拿掉个别工具：「智能体 → 能力 → 禁用指定工具」按名字点几个即可，其余照旧。它与「指定内置工具」是反方向——白名单要把用的那几个逐个勾全（平台新增工具时那份名单不会自动跟上），这里只写要去掉的那一两个。被禁的工具同样不进模型的工具表。
- 档位与「工具执行确认」管两件事：档位定**能做什么**，确认定**做之前问不问你**。两者都设过时，确认档位以你设的为准。
- 想自我约束：「个人设置 → 回答偏好」里有一项**我个人这一轮的最高档位**，只能往下收（与平台上限取较低者生效）。选了「只读调研」后，你用的任何智能体——包括别人建的、它自己选了全自主的——都不会在你账号下执行命令或改文件。
- 管理员在系统设置「工具调用 → 权限档位」可设**平台上限**：收到「只读调研」后，全部智能体的命令执行与沙盒写入一起消失；选了高于上限档位的智能体按上限执行，并在回答的过程面板里说明被收紧了。同处还有一项**平台停用工具名单**：从下拉里挑本平台已注册的工具（可搜中文名或工具名；外部 MCP 工具按用户动态接入、没有静态名册，可直接敲名字），选中的对全平台都不再提供（比关掉整族精确、比逐个智能体设置省事）。

## 内置工具

计算器（递归下降表达式求值，仅四则/幂/括号，**不执行任意代码**）、日期、知识检索（命中块进引用流）、产物交付、技能读取。全部工具开关集中在 `tool.*`，**默认均为 false**。

## 联网搜索

模型可调用联网搜索获取公网网页资料（**默认关**，管理员在「系统设置 → 工具调用 → 联网搜索」页签开启；服务商支持 Tavily / 博查 / 自建 SearXNG）：

- **结果进引用体系**：搜索返回的网页与知识库来源共用同一套 `[N]` 编号，回答里标注后可在引用面板点开看站点、摘要与外链
- **按本轮问题过相关度门**：返回结果按你这一轮的问题（多轮为指代消解后的检索查询）重排，低于「检索设置 → 最低相关分」的不列为引用、不交给模型——服务商自带的相关度分（如位置衰减）没有相关性含义，不参与判定。重排不可用时会明确提示「本轮搜索结果未经相关性过滤」：宁可看见没过滤，也不把一次瞬时故障演变成「什么都搜不到」
- **配额与审批**：单轮搜索次数可配（防反复搜烧 token）；可纳入「执行前确认」审批；游客分享链路不暴露联网搜索
