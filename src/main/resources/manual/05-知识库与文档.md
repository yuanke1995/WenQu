# 知识库与文档管理

知识库是文档的容器，也是检索的作用域：检索按库隔离，不同库互不干扰；检索与解析参数随库配置。

## 知识库

- **个人默认库「问渠」**：自动创建，无需手动建档；未指定知识库的上传、导入与移库都归入自己的默认库。默认库不绑定向量模型——首次使用前在知识库页自行绑定（只能绑定自己登记的供应商）
- **新建知识库**：名称 + 向量模型（必填）。向量空间与索引一一对应，同库所有块必须使用同一向量模型
- **库级参数稀疏覆盖**：检索参数（阈值 / 召回数 / 权重 / 重排模型）与解析参数（分块大小 / 重叠 / 结构感知 / 问答对 / 父子分块 / PDF 引擎 / 视觉与 OCR 模型等）留空即继承全局默认，填写即覆盖；解析参数仅对其后解析的文档生效
- **GraphRAG（可选）**：库级开关（默认关），开启后解析时抽取实体关系三元组、检索时做一跳图扩展；抽取模型在「知识库编辑 → 知识图谱」绑定（使用库主登记的模型），未绑定则用库主的个人默认聊天模型，两者皆空则不抽取并给出告警
- **官方内置库**：《问渠使用手册》是系统内置库，全员可读、不可编辑，不接受上传与导入；管理员可维护其检索与解析参数。手册内容随安装包分发，升级后由管理员在帮助中心点「同步官方手册」写入（内容未变的篇目自动跳过，不产生模型调用）
- **可见范围提示**：卡片上标出「建议分库」（库内文档可见范围不一致）、「默认」、「官方」等标记

## 文档上传与解析

支持格式：**docx / pdf / xlsx / ppt / pptx / txt / md / csv**，以及网页 URL 导入。扫描件 PDF 自动 OCR（文本抽取不足阈值时逐页转图后走库绑定的视觉模型）；也可在库设置里改用 PP-StructureV3 或 MinerU 做版面与表格还原。

解析链路：上传只登记持久化解析任务（解析队列），后台按并发抢占执行：解析 → 分块（按标题与结构感知切分）→ 增量入库 → 向量化（按库绑定模型）→ 关键词索引。队列有上限，排满时直接拒绝新上传并提示，不会先接收后丢弃；服务重启不影响队列中的任务。

- **解析进度**：文档行内显示状态与进度（解析中 / 已入库 / 已弃用 / 解析失败），页头给出队列指示（排队 N / 执行 M）
- **增量重解析**：同名上传或手动重解析按内容指纹对比，未变的块保留向量，只重嵌变更处
- **解析中删除**：立即中断解析并清理产物，不留孤儿数据
- **版本管理**：每次成功解析版本号 +1 并存快照，可查看历史并一键回滚
- **回收站**：删除的文档进回收站，内容保留期内可查看，支持单条与批量恢复、彻底删除与清空
- **批量操作**：批量启用、弃用、删除与重解析
- **知识块**：文档列表可打开知识块预览，提供**切片列表**与**结构导图**两种视图，并给出块数、合计与平均 token、未向量化块数；支持按标题或内容过滤、跨全部文档全局搜索（含已停用）；单块可编辑（自动重向量化）、停用、删除，也可手动创建知识块
- **图片描述**：可按文档补生成图片描述；图片理解模型可在上传时指定，或选择「不描述图片」
- **标签**：文档可打标签并按标签筛选

## 网页 URL 导入

- 批量粘贴 URL（一次最多 20 个），抓取正文后按与上传完全相同的链路入库；同名页面重复导入会替换内容
- 仅支持公网 http/https，重定向逐跳校验，防止内网探测
- 源文件为 HTML 快照：重解析读快照离线提取，不重新抓网
- 可开**定时自动刷新**（文档级 cron），到期自动重抓并同名替换重建，失败留痕且不中断后续周期，结果写入站内通知

## 文档归属与共享

- **移动文档**：文档可在库之间移动；前后两库向量模型不同时自动异步迁移向量
- **共享范围**：文档未配置共享时跟随所属库（库的可见范围通过后文档即可见）；显式配置则按配置独立判定。共享范围支持「全局 / 指定部门 / 指定用户」三档，管理范围不得宽于阅读范围
- **检索可见性两级判定**：文档可见 = 所属库允许 **且** 文档自身允许。私有库的内容不会因文档未配置共享而泄露

## 库的导出与导入

- **整库导出**：把库内文档与清单打包取走
- **导入文档包**：选择目标库后上传 zip（源文件 + 清单），逐篇按上传同链路入库；向量按导入库绑定的模型重新嵌入

## 常见问题速查

- **上传后一直显示解析中**：查看文档列表的解析进度与队列状态（排队 N / 执行 M）；服务重启残留的解析中文档会被对账复位，交队列重跑
- **解析失败**：查看失败原因（文件损坏或加密、超大文档截断、视觉模型不可用等），修复后点「重解析」
- **改了库级解析参数不生效**：解析参数仅对其后解析或重解析的文档生效，对存量文档需手动重解析
- **搜不到别人的库**：未配置共享即私有；检索可见性要求库与文档两级都放行。需要共享时在库或文档的「共享范围」中配置
