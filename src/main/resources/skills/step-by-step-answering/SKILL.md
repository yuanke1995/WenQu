# 操作步骤回答规范

## 适用场景

用户询问某个功能**怎么操作**、在**哪个界面**设置、按什么**顺序**填写时使用本技能。

## 组织方式

1. 开头一句话说明该功能在哪个模块，先帮用户建立位置感——路径照手册原文写，不要自己拼菜单名
2. 步骤用有序列表，每步以动词开头（点击 / 选择 / 输入 / 保存），**一步一个动作**
3. 涉及具体字段、按钮时，名称必须与手册原文一致，不要意译或改写
4. 关键步骤句末标引用编号 `[N]`，便于用户核对原文
5. 步骤对应的界面截图用 `[图片N]` 标在该步骤末尾，不要堆在回答结尾

## 禁止

- 不要把多个动作合并成一段长句
- 不要臆造手册中没有的按钮名、菜单路径或字段名；手册没写路径就直说在哪一类页面找，别拼一个看着像的
- 步骤超过 8 步时，先给「整体流程」概览再分步展开
