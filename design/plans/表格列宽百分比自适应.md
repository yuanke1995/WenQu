# 表格列宽支持 % 自适应(px/% 双单位,老表单 px 原样保留)

## Context

预览溢出根因:列宽是写死 px(col.width 数字 + colgroup 硬拼 `${col.width}px`),四端都不随视口缩放。用户拍板:**不做存量兼容/迁移——老表单 px 是多少就是多少(行为零变化);给列宽新增 % 单位,设计成 % 的新表单渲染时按容器自适应,四端(设计/预览/填报/查看)全家族一步到位。**

## 模型设计

`col.width` 单字段双单位:
- **Number → px,固定**(与今天完全一致,存量表单零变化)
- **"N%" 字符串 → 自适应**:渲染时换算为 `pct/100 × 可用宽`(可用宽 = 容器宽 − 固定列 60/80 − Σ px 列),即 % 分掉剩余空间
- **undefined → 自动**:均分剩余空间(渲染侧算,不落库)

渲染统一走 **量容器宽度(ResizeObserver)→ 换算成 px 输出 colgroup**:这样序号/操作固定列预算、sticky 偏移、拖拽几何全部继续在 px 空间运作;纯 px 老表单算出的就是原值,行为与今天逐像素一致。
