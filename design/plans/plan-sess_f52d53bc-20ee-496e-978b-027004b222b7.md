# 报表系统后台管理 + 登录入口 实施计划

## Context

报表系统（dynamic-form 后端 + dynamic-form-vue 前端）当前**没有真实登录**：后端 `GET /dtbd/login?user=admin|report|sh` 是无密码 mock（硬编码三个内置身份直接发 JWT），前端没有登录页（靠外部系统带 `?token=` 跳转，dev 兜底硬编码 JWT）；`HeaderInterceptor` 只解析 token 不拒绝请求（软鉴权）；无用户表。本次新增：**真实账号密码登录 + 全局强制鉴权 + 后台管理四模块（用户/角色与授权/部门/系统参数）**。

关键勘察结论（已核实）：
- 密码工具 `PasswordUtil`（MD5+盐 48 位 generate/verify）现成可用：`com.wisesoft.form.base/.../utils/PasswordUtil.java`
- 权限三表已在：`c_role`（Role.java）、`c_user_role_dept`（UserRoleDept.java）、`c_table_role_relation`；部门表 `c_department`
- `FormUser` VO 无角色字段；JWT claim `param` 只塞固定字段（`FormJwtUtil.buildToken(FormUser)`）
- 全部 Controller 响应封装 `ResultJson{success,code,msg,data}`；分页约定 `ResultJson<Pager<VO>>` + `Pager.convertToMyPage(mpPage)`；Mapper 由 `@MapperScan("com.wisesoft.**.mapper")` 扫描；actable 自动建表（实体加注解即得表）；操作日志 `@SysLog` 切面现成
- 外部接口均带 JWT 或自带校验：`/open/api/**`（不在 `/api/` 前缀下）、`/mcp/form`（X-Service-Token 自认证）、`/api/callback`、`/api/external/api`（内部都校验 FormUser）；前端 `cos-table` + `loadData` 页面模式（参照 `views/log/OperationLog.vue`）；`store/modules/user.js` 已有 `reset` 登出 action（无调用方），`catchPermissionData` 目前前端 mock `isSuperAdmin:true`

## 一、后端（dynamic-form）

### 1. 新实体（actable 自动建表）
- `SysUser` → `c_sys_user`（biz.base 包，仿 Role.java 注解风格）：id、account、password、name、deptId、phone、status(0禁用/1启用)
- `SysConfig` → `c_sys_config`：id、configKey、configValue、configName、description、sortIndex

### 2. 认证与鉴权
- **`FormUser` 加 `roles`（List\<String\> roleCodes）字段**，`FormJwtUtil.buildToken(FormUser)` 写入、`getFormUser()` 解析（旧 token 无此字段=空列表，向后兼容）
- **新建 `AuthController`**（`/api/auth`）：
  - `POST /api/auth/login`：账号密码登录——查 `c_sys_user`（status=1）→ `PasswordUtil.verify` → 从 `c_user_role_dept`+`c_role` 加载 roleCodes → 组装 FormUser → `FormJwtUtil.buildToken` → `contextService.setFormUser`（cookie+Redis 双写，与现流程一致）→ 返回 `{token, user}`
  - `GET /api/auth/me`：返回当前上下文用户
  - `POST /api/auth/logout`：清 Redis `current_user_{id}`
- **`HeaderInterceptor` 加强制鉴权**：解析后 FormUser.id 为空 且 请求 URI 在 `/api/` 前缀下 → 直接写 401 响应（HTTP 200 + `{success:false, code:401, msg:'未登录或登录已过期'}`）。豁免：`/api/auth/login`。CURRENT_USER_URL 网关回落流程保留（有解析结果即放行）。`/open/api/**`、`/mcp/**`、`/example/**`、静态资源、`/webapp|/h5app` 转发不在 `/api/` 前缀下，天然不受影响
- **管理端 admin 守卫**：同拦截器内，URI 以 `/api/sys/` 开头且 roles 不含 `admin` → 403
- **`/context/resource`（FormContextController）改为真实返回**：`admin` 从 JWT roles 计算（替换前端 mock）
- **mock 登录保留**（dev 工作流兼容）：`LoginController` 三个内置身份的 JWT 塞入对应 roles（admin→["admin"] 等），保持可用

### 3. 管理端四组接口（均 `@SysLog` 注解记账）
- `SysUserController`（`/api/sys/user`）：分页（account/name/状态筛选，联表带部门名+角色名）、新增（PasswordUtil 加密、账号唯一校验）、编辑、删除（禁删 admin 与自己）、重置密码、启停用、分配角色（写 `c_user_role_dept`）
- `SysRoleController`（`/api/sys/role`）：c_role CRUD（roleName/roleCode/roleType/roleLevel/orderIndex/status/description）；表单级授权沿用现有 TableRoleRelationController 不动
- `SysDeptController`（`/api/sys/dept`）：树查询 + 新增/编辑/删除（有子节点/有用户引用时拒删），复用 `IDepartMentService`
- `SysConfigController`（`/api/sys/config`）：列表 + 保存
- Service/Mapper 仿 `SysOperLog` 三件套结构（biz 包下新建 `sys` 子包：mapper/service/impl）
- **`SystemSeedRunner`**（ApplicationRunner）：启动时 c_sys_user 为空则种子 `admin/admin123`（密码 PasswordUtil.generate），并种子「系统管理员(admin)/填报员(report)/审核员(audit)」三个角色和默认系统参数

## 二、前端（dynamic-form-vue）

### 4. 登录页
- **`src/views/login/Login.vue`**（BlankLayout 组）：品牌化渐变背景 + 居中卡片，账号/密码 + 回车提交，成功后 `store.dispatch('user/login', {token})` → 跳 `?redirect` 或 `/welcome`；已带 token 访问 /login 自动跳 /welcome
- `router.config.js`：加 `/login` 路由（name `login`），`whiteList` 加 `'login'`
- `store/modules/user.js`：加 `login` action（SET_TOKEN + persistToken）；**`catchPermissionData` 弃 mock 改调真实 `/context/resource`**（isSuperAdmin=data.admin）

### 5. 401 全局处理
- `utils/request.js` 响应拦截：`data.code === 401` → `user/reset` 清 token → 提示「登录已过期」→ 跳转 /login（用 location 跳转避免 router 循环引入）

### 6. 顶栏改造（LayoutHeader.vue + header.config.js）
- 右侧加用户区：a-dropdown（用户名，来自 `/api/auth/me` 静默拉取）+ 退出登录（`user/reset` → /login）
- 加「系统管理」下拉（用户管理/角色管理/部门管理/系统设置），仅 `isSuperAdmin` 可见（顺带把 header.config.js 里定义了但未生效的 `adminOnly` 过滤接上）

### 7. 管理页面（views/system/，全部仿 OperationLog.vue 的 cos-table 模式）
- `UserManagement.vue`：查询（账号/姓名/状态）+ 表格（账号、姓名、部门、角色、状态、操作）+ 新增/编辑弹窗（账号、姓名、部门树选、手机号、角色多选、建号时密码）+ 重置密码/启停/删除
- `RoleManagement.vue`：角色列表 + 弹窗表单
- `DeptManagement.vue`：a-table 树形展示 + 增删改
- `SystemSettings.vue`：参数键值表 + 行内编辑
- `src/api/system.js`：四组接口封装；路由 `/system/user|role|dept|config`（BasicLayout 组，meta 标 adminOnly）

## 三、风险与兼容

- 全局鉴权收口在 `/api/**`：外部系统对接（open api/MCP/静态/文档/转发）零影响；`/api/callback`、`/api/external/api` 从「业务层报错」提前到「拦截器 401」，错误语义一致
- dev 硬编码兜底 token 仍有效（密钥未变）；mock 登录保留
- 种子账号 admin/admin123 首次登录后建议改密（重置密码接口已具备）
- 两仓均有未提交 WIP：只新增/最小触碰文件，**不自动提交**
