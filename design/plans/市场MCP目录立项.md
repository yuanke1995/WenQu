# 市场三期 · MCP 目录 立项文档

> 2026-11-07 立项（由 MCP 外部工具页升级方案派生：用户拍板「常用服务模板」走市场三期正式目录，不做添加弹窗轻量预设）。实施排期另议，本文档只定边界，防跑偏。

## 目标

在市场（Market）中新增「MCP 服务」类型目录：用户可浏览/搜索常用 MCP 服务，一键安装到自己的 MCP 服务列表。替代「每次手填 URL」的冷启动体验。

## 范围与边界

- **做**：市场新增 mcp 类型物品的浏览/搜索/详情/一键安装；官方目录条目由管理员维护（复用市场官方模板机制口径）；安装成功后跳转/提示到 MCP 外部工具页。
- **不做**：游客/分享面（MCP 是登录用户个人资产，游客 MCP 走既有 fail-closed 名单，与市场无关）；OAuth 代管；stdio 型服务（后端本就不支持，导入时沿用「跳过并说明」口径）；凭据代填（headers 值不进市场条目）。

## 数据结构（表已预留，扩类型不改表）

- `c_ai_market_item.item_type = 'mcp'`（`schema.sql:1245` 已预留注释；`MarketItem.java` 注释同口径）。
- payload 存：`{ name, url, type: streamable|sse, description, icon?, tags?, official }`——**不含 headers/凭据**；name 校验沿用 MCP 服务规则（≤40 字、不含 `/`）。
- 安装 = 调现有 `POST /api/ai/mcp/servers`（个人行）或 `/servers/import`（批量）；重名/超限（每人 10 个）走既有失败语义，市场侧展示「已安装」态。

## 与 MCP 面板升级方案的衔接

- 依赖项为零：安装端点全是现有件；MCP 面板升级（`MCP面板升级方案.md`）完成后，安装跳转落点的页面体验（错误详情/测试连接）已就绪。
- 搜索/列表 UI 复用市场现有 skill 模式（一期 c92db191 起的骨架）；物品类型分发在 MarketService 增 mcp 分支。

## 验收要点（实施时展开）

1. 浏览/搜索/详情/一键安装全链真机；重名、超限、已安装三态。
2. 官方条目管理员维护入口（新增/下架）+ RBAC 权限点（沿用市场现有权限面）。
3. 安装后 MCP 页立刻可见、连接状态轮询收敛正常（回归 §plan-mcp-panel-upgrade §6）。
