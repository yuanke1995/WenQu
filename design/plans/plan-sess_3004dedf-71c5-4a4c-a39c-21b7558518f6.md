# 智能体对外能力第一批：自定义 HTTP 工具（OpenAPI 导入）+ 调用变量注入

## Context（为什么做）

用户拍板方向：**问渠智能体要能嵌入其他项目随意使用**（agent-as-a-service），而不是外部用户进问渠。评估出的本体能力六缺口中，先做最小业务闭环的两条（批次范围已经用户确认，2026-11-07）：

```
宿主项目 ──带变量调用──▶ 问渠智能体
                          ├─ 变量：宿主业务上下文随轮进模型（Feature 2）
                          └─ HTTP 工具：按 OpenAPI 导入调宿主 API 干活（Feature 1）
         ◀──结果────────
```

勘察确认的关键架构事实（方案据此设计）：
- **系统提示词按会话常驻实例烤死**（`AgentscopeChatEngine.java:712` 注释、`bindingOf:2641` 实例指纹）→ 调用级变量**只能走用户消息侧**（`TurnPromptAssembler.userContentWithContext:141`），进 sysPrompt 会破坏实例复用且打爆供应商前缀缓存。因此「模板变量」落地为**调用方上下文段注入**，sysPrompt 保持静态。
- **凭据加密有现成惯例**：`c_ai_user_mcp.headers` 整块 JWE（`ConfigCryptoService`，`JWE:` 前缀）+ 边界校验（`McpHeaders.normalize`）+ 回显只给键名——HTTP 工具的鉴权配置整套照抄。
- **动态工具以 `McpToolProvider` 为结构先例**（每轮按配置动态构建 ToolCallback，不走静态 `@Tool` holder）；启动三闸（一族一 provider/跨族重名/声明漂移）在 `ToolRegistry.init/validate`。
- **无 swagger-parser 依赖**；类路径已有 snakeyaml 2.4 + fastjson2。按仓库取向**手写 OpenAPI 子集解析器**，不加新依赖。
- 只加列不建表 → **不碰 GLOBAL_TABLES**（`WenquTenantLineHandler.java:41`，无 G16 风险）。

## Feature 1：自定义 HTTP 工具（OpenAPI 导入）

### 数据模型（schema.sql，两列进 `c_ai_agent`，无新表）

- `tool_http INT DEFAULT NULL COMMENT 'HTTP工具: 1=开 0=关 NULL=继承'`——插在 `tool_websearch`（schema.sql:370）后，**照抄邻居的 INT 三态写法**（本表无 TINYINT 先例）。
- `http_tools MEDIUMTEXT`——插在 `builtin_tools`（:378）后，存**归一化工具集 JSON 数组**（不存原始 spec；MEDIUMTEXT 先例在 :217/:958）：
  ```json
  [{"id":"uuid","name":"crm","baseUrl":"https://host/api","timeoutMs":10000,
    "requireApproval":false,"enabled":true,
    "auth":{"type":"bearer|apiKeyHeader|none","header":"Authorization","value":"JWE:..."},
    "ops":[{"name":"crm_getOrder","method":"GET","path":"/orders/{id}","summary":"查订单",
            "inputSchema":{...已解析的 JSON Schema}}]}
  ```

### 后端（新文件 3 个 + 改 7 个）

1. **`service/httptool/OpenApiSpecParser.java`（新）**：解析 OpenAPI 3 JSON/YAML（snakeyaml 转 Map + fastjson2），提取 paths×methods→operationId/summary/parameters/requestBody；**$ref 就地递归解析（深度上限 6，环截断为 {}）**；入参校验（openapi 3.x、≤512KB、路径数上限）。产出归一化 ops。
2. **`service/httptool/HttpToolModels.java`（新）**：工具集 normalize+上限（**每智能体 ≤4 工具集、每集 ≤20 ops**、名唯一、拒绝 `wen_qu` 前缀防与 MCP 撞名）；auth 明文→`ConfigCryptoService.encrypt`（值变更才重加密，按工具集 id 匹配保留旧密文）、回显 mask 只留 type/header/hasValue。
3. **`agent/tool/provider/HttpApiToolProvider.java`（新）**：`family()=HTTP_API`；**结构照抄 `McpToolProvider` 的动态回调路径**（每轮从 agent.httpTools 构建 ToolCallback，不走 @Tool holder）。`ToolFamily` 加 `HTTP_API("http_api","HTTP工具", false)`（**blockedWhenApprovalOff=false，同 websearch 口径**——审批 off 档正是嵌入场景需要的无人值守模式）；`ToolAssemblyService.agentFlagFor(:180)` 加 HTTP_API→`tool_http`。描述符：`SideEffect.EXTERNAL`、`guestAllowed=false`、`gateKey="httpTool.enabled"`、`requiresApproval=该工具集的 requireApproval`。工具名 `{集名}_{operationId}` 清洗为 `[a-zA-Z0-9_-]≤64`。
4. **`service/httptool/HttpToolExecutor.java`（新）**：静态共享 JDK HttpClient（**照抄 `SearchHttp.java:23-50` 的模型线程内阻塞惯例**），逐请求超时（工具集 timeoutMs，1s–60s 默认 10s）；URL=baseUrl+path 参数替换（URL-encode）+query 组装；body=JSON.stringify(args.body)；响应读上限 256KB、**给模型的截 16KB**；非 2xx 返回 `HTTP {status}+body` 作为工具结果（让模型自行反应，不抛异常），传输错误抛语义化异常；`httpTool.allowPrivateNetwork=false` 时连接前解析 IP 拒环回/私网/link-local（默认 true 适配自宿主内网场景）。
5. **`model/Agent.java`**：`toolHttp`（:93 邻）、`httpTools`（:150 邻）。
6. **`service/AgentService.java`**：`toEntity(:593)` 加两字段解析（toTri + JSON 数组校验+auth 加密处理）；`updateColumns(:517)` 加两列；**`VERSION_FIELDS(:89)` 登记 `tool_http`/`http_tools`——快照/diff/回滚/市场模板四链路自动生效**（已确认 `diffConfig:896`/`applyConfig:921`/`configJson:876` 全走这个 Map）。
7. **`controller/AgentController.java`**：`POST /agent/http-tools/preview`（body `{spec}`）→ 解析预览（ops 清单+警告），登录态即可（agent 配置面本就在 Key 拒绝名单）。
8. **`ConfigService.defaults()(:863)`**：`httpTool.enabled=true`、`httpTool.allowPrivateNetwork=true`（注释风格照抄 :863-869）；**`config-schema.json`**：同段加两字段（`vif:"tool.enabled"` 级联 + tips 字典键）。

### 前端

9. **`web/src/views/AgentsPage.vue`**：① CAPS 数组（:748）加 `tool_http` switch 条目；② blankForm（:1005）/openEdit（:1708）/save tri()（:1849）四处接线；③ 新增工具集管理块（列表+编辑弹窗）——**抽成独立组件 `web/src/components/agent/HttpToolsEditor.vue`**（AgentsPage 已够大），弹窗交互**照抄 `McpPanel.vue:202-226` 的「粘贴 JSON 导入」先例**（textarea+解析预览+逐条勾选 ops+确认）。

2. **`agent/chat/ChatCommand.java`** 加字段；**`ChatController.chat` builder（:297）** 加一行。旁路调用方（ScheduledJobService/WorkflowEngine/McpServerService/SubAgentBranchRuntime 走 `ChatCommand.of` 最小三要素）不受影响。

## 明确不做（边界，依据已与用户对齐 2026-11-07，记账本遗留债）

- **sysPrompt 每轮模板变量**：真架构代价（常驻实例重建+前缀缓存全灭）；配置级 `{{var}}`（构建期渲染、零缓存代价）是便宜变体，后续可作小增量加。
- **HTTP 工具游客放行**：模式现成（guestMcpServers 先例），但依赖 P3/P4 安全拍板（游客会借凭据调业务 API）；等安全收口同批做。
- **工作流当工具 / webhook 回调 / agent 级记忆**：各为一个同体量设计任务（调用权限模型 / 重试+签名 / 分域模型），排后续批。
- **管道层（计量/scope/CORS/OpenAI 兼容端点）**：计量+scope 是 15 文件级地基工程；CORS 半天级但只服务浏览器挂件批；OpenAI 兼容端点整块新功能。排后续批。
- **专用审计表**：最小且随时可并（出站调用入审计+接 OpsCheckup 审计链），v1 先结构化日志。

## 影响面回归清单（第三道闸）

- **老智能体零变化**：tool_http NULL + http_tools NULL → 不挂新工具、提示词逐字节不变（改造前后工具列表+提示词指纹对比）
- ToolRegistry 启动校验干净（无跨族重名/声明漂移 ERROR 日志）
